你是 Xilinx 7 系列（xc7vx485tffg1157-3）比特流逆向的资深工程师。任务：在既有 INT/BEG/复合码家族复用模型的基础上，厘清 HCLK_CMT 这一类 tile 的 PIP 配置位复用规律，并判定其位映射能否用闭式公式表达；能则给出公式与判据，不能则给出查表方案与条目数上界。

## 已知事实（均已在本项目实测确认，不要重复验证，直接作为推理前提）
- 器件 xc7vx485tffg1157-3，50,176 帧 × 101 字 × 32 位；第 50 字为帧级 ECC（13 位有效），统计与差分时必须排除。
- 地址公式：frame = 块基址 + frame_off；word = 2*(y%50) + parity（>=50 再 +1）；每配置行 5,246 帧。
- INT tile 已完全解决：172 个家族（3,634 条 feature，1,536 条 mux + 2,098 条 BEG/时钟树），覆盖 100%、0 不符；BUFGCTRL_X0Y0..Y31 选择位有闭式公式。
- 受控差分纪律：两个构建之间 PIP 列表必须逐行完全相同，差分只允许落在被测配置位上；不满足即不作结论。
- 64 个 mux 家族复用结构 = 6×4 网格（行帧 16..21、列帧 22..25）；96 个 BEG 家族 = 完全二分图 K(4,5)/K(5,4)，每源固定 2 格；7 个复合码家族 = 3 格 core + 2 个族级附加位。
- 工具：远端 Vivado 2017.2（32 路并发可行 / 单构建 84 s）、RapidWright 2026.1.0（对 HCLK_CMT 返回 getConfigBlock()=null）、本地 bitstream parser。

## 本次目标（仅针对 HCLK_CMT，全器件 PIP 最密 tile：982 条 PIP、平均 23.4 源/目的、最大 48）
1. 每条 PIP 占用几个配置位？逐条判定是 1 位、2 位还是多位编码；按"每目的源数"分组统计位数分布。
2. 多位编码时，位与位之间是什么关系：one-hot / 温度计码 / 二进制 / 分组编码？给出判定依据与实测差分表。
3. 能否给出闭式公式（对标 INT 的闭式解）？给出可判定"能公式化 vs 必须查表"的量化判据（如位模式随源索引的单调性/周期性、家族内位集合的仿射结构、留出法误差为 0），据此下结论；若必须查表，给出所需条目数上界。

## 方法要求（按序执行）
1. 离线摸底先行：从 routing 模板统计 HCLK_CMT 每个目的 wire 的源数量、源命名规律、目的-源拓扑，显式判定是否与 INT 的 8 方向×端线结构同构（给同构/不同构对照表）。
2. 隔离实验设计：每个实验必须构造"只改配置、不改布线"的对照，优先采用以下三类之一并说明选取理由：
   - 同一物理端口的 I0/I1 选择（对标 BUFGCTRL 的寄存器位决定机制）；
   - 同一源的两种等效驱动（DONT_TOUCH + 固定 LOC 的 LUT 输出 vs 直接连）；
   - 成对消元（两构建各改一个变量，再交叉相减）。
3. 每个结论须同时满足：构建回读断言一致（SITE/BEL/part）+ PIP 列表逐行相同；否则该构建数据作废。
4. 差分归因：任何差分若不能被"已知族 + 被测位"完全解释，必须列出残差清单并逐项归因；无法归因即判该结论失败，禁止硬解释。
5. 禁止抽样结论：位集合必须 missing=0 且 extra=0；任何未覆盖的位必须显式列出。
6. 交叉验证：每个结论至少由第二个独立构建或第二个独立脚本复现；仅单次验证的结论一律标注"未验证"。

## 交付物（逐项输出，缺一不可）
1. HCLK_CMT 的 PIP 源集合清单：每个目的 wire 的完整源列表 + 源数量。
2. 每条 PIP 的位数结论表：按"每目的源数"分组，含位数分布与判定依据。
3. 位间关系判定结论（one-hot / 二进制 / 分组 / 温度计码），附实测差分表（构建对、改动位、观测差分、归因）。
4. 公式化可行性结论：能公式化则给公式 + 留出法验证（误差必须为 0）；不能则说明证伪依据 + 查表条目数上界。
5. 与 INT / BEG / 复合码三类的结构对照表（维度：家族数、图结构、每源格数、位数、是否可公式化）。
6. 负结果记录：逐条列出被证伪的假设、证伪所用数据、对应构建/脚本标识。

## 红线
- 只追求可复现，不追求看起来合理。
- 任何结论若无第二个独立构建或第二个脚本交叉验证，必须显式标注"未验证"。
