目标：为 Xilinx 7 系列（xc7vx485tffg1157-3）的配置位编码找出一条【可预测】的生成律，而不是对已有表格的事后拟合。

背景事实（都已实测，不要重复验证）：
1. INT tile 的 PIP 位映射已 100% 解出：172 个 family、3,634 条 (family,source)、3,634/3,634 精确命中，0 例外。
2. 结构分三类：
   - mux 区 64 族：每族 24 源，落在 6(行帧 16..21) x 4(列码 0001/0010/0111/1011，对应帧 25/24/23/22) 的网格上，每族一对相邻位 (B,B+1) + 一个字 parity + 一个行相位。
   - BEG 区 96 族(+时钟 5 族)：每族源 = A 侧格 x B 侧格 的完全二分图 K(4,5) 或 K(5,4)，每源固定 2 格。
   - 时钟/控制 6 族：24 个 3 格 core，源 = core 减一格 或 core 加一个族内固定附加位。
3. 每格被 1..18 个源共用（均值 5.56），跨族零共享。
4. 源->槽位（即 24 个引脚里排第几）不可由线名、方向、字典序推出：同一导线在不同 mux 换槽（122/122），48 个 mux 的槽位表指纹 42 个互异。

要回答的问题（这是全部产出）：
A. 为什么是 6x4，而不是 8x3 或 4x6？这个形状由什么物理量决定（switch box 的引脚分布？mux 树的级数？帧的位预算？）。
B. 为什么 BEG 用完全二分图？A 侧 4 格、B 侧 5 格的差别对应什么硬件差异？
C. 为什么时钟族用「奇偶分字 + one-hot」而不是网格？
D. 三者的共同约束是什么——是不是同一个编码空间的三种投影（例如：所有 PIP 选择共享一套「行帧 x 列码 x 位对」的通用坐标系，只是取子集的方式不同）？
E. 如果共同约束成立，请给出一个生成函数 gen(tile_type, family, source) -> (frame_off, word, bit)，它必须能预测未测量过的 family/源的位位置。

方法要求：
1. 先列候选生成模型，每个模型必须写明它依赖的物理假设，并给出可证伪的预测；
2. 用留出法检验：从 3,634 条里留出至少 200 条（按 family 分组留出，不能随机抽样），模型必须 100% 命中留出集才算成立；
3. 对「源->槽位」这一维度，先判定它是否可由模型导出；若不能，给出判定它属于「器件布线事实」的判据，而不是含糊其辞；
4. 每个候选模型都要给出「如果它错，会看到什么」的反证形态。

红线：
- 不允许把「查表」包装成「规律」；
- 不允许用「统计上大概一致」代替逐条精确；
- 未能解释的部分必须显式标注，不许用「可能」「大概」带过；
- 结论必须能预测至少一条尚未测量的位位置，并给出验证方法。

交付：候选生成律（数学形式）、留出法检验结果、被证伪的候选清单及证伪依据、以及「下一步最小验证实验」清单。
