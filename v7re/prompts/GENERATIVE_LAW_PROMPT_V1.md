# 生成律提示词 V1（预测型，非拟合型）

> 用途：让模型/Codex 在**不重测**的前提下，给出可预测未测 family/source 的生成律。
> 生成方式：草稿 `v7re/prompts/_draft_generative_law.md` → 本地 prompt-optimizer
> `node po.mjs user "<draft>" --template user-prompt-professional`；
> 之后人工订正三处被优化器改错的数字（见文末「订正记录」）。

---

目标：为 Xilinx 7 系列 FPGA（器件 xc7vx485tffg1157-3）的配置位编码，推导出一条
**可预测的生成律**，而不是对已有映射表做事后拟合。所谓「可预测」须满足：
该规律能对**未参与建模**的 `family/source` 组合给出确定的 `(frame_off, word, bit)` 预测值，
且在留出集上 **100% 命中**。

## 背景事实（均已实测，无需重复验证，直接作为建模约束）

1. INT tile 的 PIP 位映射已 100% 解出：**172 个 family、3,634 条 (family, source)**，
   3,634/3,634 精确命中，0 例外。
2. 结构分三类：
   - **mux 区 64 族**：每族 24 源，落在 6（行帧 16..21）× 4（列码 0001/0010/0111/1011，
     对应帧 25/24/23/22）的网格上；每族一对相邻位 (B, B+1) + 一个**字** parity + 一个行相位。
   - **BEG 区（96 族 + 时钟树 5 族）**：每族源 = A 侧格 × B 侧格的完全二分图
     K(4,5) 或 K(5,4)，每源固定 2 格。
   - **时钟/控制 6 族**：24 个 3 格 core，源 = core 减一格，或 core 加一个族内固定附加位。
3. 每格被 1..18 个源共用（均值 5.56），**跨族零共享**。
4. **源→槽位**（24 个引脚里排第几）不可由线名、方向、字典序推出：
   同一导线在不同 mux 换槽 **122/122**；48 个 mux 的槽位表指纹 **42 个互异**。

## 需要回答的问题（逐条作答，不得合并或省略）

- **A.** 为什么是 6×4，而不是 8×3 或 4×6？该形状由哪个物理量决定
  （switch box 引脚分布？mux 树级数？帧的位预算？）——须指明具体物理量并说明它如何约束出 6 和 4。
- **B.** 为什么 BEG 用完全二分图？A 侧 4 格、B 侧 5 格的差别对应什么硬件差异？
- **C.** 为什么时钟族用「奇偶分字 + one-hot」而不是网格？
- **D.** 三者的共同约束是什么——是否同一个编码空间的三种投影
  （所有 PIP 选择共享一套「行帧 × 列码 × 位对」的通用坐标系，只是取子集方式不同）？
- **E.** 若共同约束成立，给出生成函数
  `gen(tile_type, family, source) -> (frame_off, word, bit)`，
  它必须能预测**未测量过**的 family/源的位位置。

## 方法要求

1. 先列候选生成模型，每个写明依赖的物理假设，并给出可证伪的预测
   （若假设成立，应在哪些具体 (family, source) 上观察到什么确定值）。
2. **留出法**：从 3,634 条里留出至少 200 条（**按 family 分组留出，不能随机抽条**），
   模型必须 100% 命中留出集才算成立；须报告留出 family 列表、条数、命中率。
3. 对「源→槽位」先判定能否由模型导出；若不能，给出判定它属于「器件布线事实」的**判据**
   （如槽位表指纹互异数与 mux 数的关系、同一导线换槽的槽位差分布），不得含糊。
4. 每个候选模型都要给出「如果它错，会看到什么」的反证形态（具体到可观测的位坐标偏差模式）。

## 红线

- 不允许把「查表」包装成「规律」；
- 不允许用「统计上大概一致」代替逐条精确；
- 未能解释的部分必须显式标注，不许用「可能」「大概」带过；
- 结论必须能预测至少一条尚未测量的位位置，并给出验证方法。

## 交付

候选生成律（数学形式）、留出法检验结果（含留出 family 列表与命中率）、
被证伪的候选清单及证伪依据、下一步最小验证实验清单
（每条须写明：验证对象、所需测量条目、判定成功的阈值）。

## 订正记录（人工）

prompt-optimizer 的输出里出现三处事实错误，已在上面订正：

| 优化器输出 | 正确值 |
|---|---|
| 「72 个 family」 | **172 个 family** |
| 「同一对导线在不同 mux 换槽（22/122）」 | **同一导线换槽 122/122** |
| 「一个字节 parity」 | **一个字 parity**（word parity） |
