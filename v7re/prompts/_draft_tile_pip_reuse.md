目标：给出 Xilinx Virtex-7 xc7vx485t 上**全部 115 个 tile 模板**的 PIP 复用情况普查——每个 tile 类型里 PIP 到底有没有复用、复用多少、复用发生在哪一层。

## 术语（与本项目一致，不要改写）
- family = PIP 的**目的 wire**（一个 family 就是一组互斥的源，例如 IMUX_L40 有 24 个源）
- feature = (family, source)，一条具体的 PIP
- cell = (frame_off, parity, bit)，一位配置位；cell 也是复用的最小单位
- 复用 = 多个 feature 共享同一个 cell

## 已有事实（直接用，不要重测）
- 数据源：`E:\v7work\_curated_20261021\routing\out_routing\templates\*.json`，115 个模板、70 个含 PIP、共 35,126 条 PIP；每个目的 wire 的源列表是严格字典序。
- 已离线普查过一轮，按「每目的源数」分四类：A 每目 1 源 7,517 条(21.4%)、B ≥85% 单源 8,135 条(23.2%)、C 稀疏多源 3,748 条(10.7%)、D 密集多源 15,726 条(44.8%)。
- INT tile 已实测：172 family / 3,634 feature / 1,598 个 sense=1 cell；每 cell 被 1–18 个源共用、均值 5.56、最大 18；每源占 2 或 4 格。三种结构（6×4 网格 64 族 / 完全二分 K(4,5)·K(5,4) 96 族 / 组-核心-附加位 7 族）已全部解出，位坐标 3,634/3,634 精确。
- 时钟层已解：BUFGCTRL 选择位公式 `f0=7834+5246*(Y//16)`、`w=(93+Y//2) mod 101`、偶数 Y 用 (f0,w,11)+(f0+1,w,3)、奇数 Y 用 (f0,w,27)+(f0+1,w,19)。
- 第 50 字是帧级 ECC，统计必须排除。

## 要交付什么
对 115 个 tile 模板**逐个**给出：
1. PIP 数、family 数、每 family 源数分布（min/median/max）、单源 family 占比；
2. 复用度：每 cell 被多少 feature 共用（分布 + 均值 + 最大）、有多少 cell 只被 1 个 feature 用；
3. 复用发生在哪一层：族级 / 族内格级 / 跨族共享（给出各自计数）；
4. 该类型 PIP 的「一条 PIP 占几位」（已知的填实测，未知的标 unknown，**不要猜**）；
5. 数据来源标注：offline（来自 routing 模板）/ measured（有实测位坐标）/ unknown。

## 输出要求
- 一张总表（115 行，按 A/B/C/D 分类排序），列就是上面 5 项；
- 一张汇总：全器件 PIP 总数、feature 总数、复用度直方图、哪些 tile 类型完全无复用（一条 PIP 一位）；
- 一个结论段：复用是否是 INT 特有、还是普遍现象；如果是普遍现象，复用度与什么相关（每目源数？tile 功能？）；
- 每条结论必须写明证据来源，无法确定的显式标 unknown。

## 纪律
- 只做离线统计（读 routing 模板与已有数据库），**本轮不跑 Vivado**；
- 不要用采样代替全量；数字必须来自全量遍历；
- 坐标系统一用 (frame_off, parity, bit)，转序必须显式；
- 如果某 tile 类型的数据缺失（模板里没有 PIP 或数据库没有该类型），列出来，不要跳过。
