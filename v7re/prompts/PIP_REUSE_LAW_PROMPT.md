## 目标：把"查表"升级为"定律"

分四个层次衡量，**必须明确说明做到第几层**：

* **L1 可查表**：给定 (tile, PIP) 能给出位集。← 目前在这层。
* **L2 可预测**：给一个从未实测过的 family / 源，不跑实验就能算出位集，且实测命中。
* **L3 可解释**：源 → 0/1 pattern 的分配有生成函数（能说出为什么是这个 pattern），
  而不是一张 3,636 行的表。
* **L4 可逆**：给定一段差分（含多条 PIP 叠加）能反解出 PIP 集合，且解唯一。

## 任务（按优先级，逐个做，做完写结论再进下一个）

**T1｜补齐 24 个未测 IMUX family。**
假设：这 12 个 mux（每侧）是 CLBLM(SLICEM) 专属输入，因为基座建在 CLBLL_L(SLICEL) 上够不着。
验证：把基座 LUT 放到 `SLICE_X12`（→ `CLBLM_L_X8`），重跑 tilepipe 一轮 36 个 tag，
看这批 mux 是否出现。**出现 = 假设成立；不出现 = 假设证伪，记录并换思路。**

**T2｜验证非 IMUX 家族的"域内编码唯一"。**
现状：唯一性只有 prjxray 表保证，没有一个源是实测的。做法：每个非 IMUX family 挑 3–5 个源，
按 FAM 语义跑（成本与 famdiff 那轮相同）。任何一条同族两源 pattern 相同 = **重大反例**，
说明该 mux 不可逆或需要额外信息，必须写清。

**T3｜给 pattern 找生成函数（本任务的核心）。**
问：为什么源 S 拿到 pattern P？给出**可证伪的候选**并逐一测，例如：
源在 family 内的序号 → 二进制 / 格雷码 / 独热 / 汉明权重恒定 / 列优先展开；
IMUX 已知有 `parity=(L//4)%2` 的闭式，说明这套编码至少部分是结构化的——找出其余部分。
**禁止**用"查表"当结论。若穷尽后确实无闭式，给出反证材料（例如：同族同序号不同 tile 类型
pattern 无关联、或同 pattern 对应多个无关源），并明确写"L3 不可得，只能建表"。

**T4｜多条 PIP 的线性叠加。**
同一 tile 同时开 N 条 PIP（N=2,3,5），检验 bit = OR/异或 的叠加是否成立，
以及 sense=0 的格在冲突时谁赢。多 PIP 是真实布线常态，这条不成立则 L4 无从谈起。

**T5｜长线家族的块归属（未解项）。**
`SWEEP_DIAGNOSIS.md` 记录 `LV_L0`/`NN6BEG0`/`NW6BEG1` 的位不落在本 tile 的 CLB 列块里
（帧 142/144/147、5389/5392…，word=14,26,38,51,63,…，bit 恒 22，步长约 12）。
旧实验"逐条删除"失效（22 条位集 unique=0）。改做**"只保留一段长线"的对照**，
把一条长线拆成可区分的段。

**T6｜横向铺开。**
非 CLB 列（BRAM/DSP/CMT/IO）的 `prefix(col)` 已知但无实测；BRAM 行带（band 8..14）完全没碰。
每类抽 1–2 列做变体，验证地址律是否同样成立。

## 方法纪律

1. **先判语义再算差分**：PURE / XOR / FAM 三种，用错就会把"基线已有同族 PIP"误判成形状错。
2. **每个结论配一个对照 + 一次反例搜索**：只给正例不算证明。
3. **禁止事后拟合**：候选生成函数必须先写下来再测，不能看完数据再编规则。
4. **差分里出现形状表以外的位 = 模型错**（或另有 PIP 参与），必须查清，不许忽略。
5. **失败要记录**：证伪的假设和失败的实验同样是产出，写进文档。
6. 所有数字必须能被一条命令复现，命令写进文档。
