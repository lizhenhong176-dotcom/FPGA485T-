# T49：PLL 源样本 —— 两字奇偶 one-hot

日期：2026-11-08
远端：`/opt/lzh/v7re/work/hclk6`，8 个构建（PLL0..5 + 两个直连引脚）。

## 1. 样本

```
pin → PLLE2_ADV(@X0Y6，6 个 CLKOUT 全 ÷10、参数逐字相同) → BUFH → FDRE
p0..p5 = CLKOUT0..5
```
Vivado 选中源：`MUX_CLK_PLL0..PLL5`，全部 `->> MUX_CLK_13`。
两个「引脚直驱 FF」设计（`c_a`/`c_b`）**完全不经过 HCLK_CMT**（无相关 PIP），说明 CCIO 组需要别的构造方式。

## 2. 结构（比 MMCM 组干净得多）

PLL 样本在帧 22147 的 word 27–30 **全为 0**（MMCM 样本在那里有 `0xd800d800` 类图案）。
选择位只落在两处：

| 源 | (22144, 51) | (22145, 51) |
|---|---|---|
| PLL0 | bit 25 | bit 31 |
| PLL1 | — | bits 25, 31 |
| PLL2 | bit 26 | bit 31 |
| PLL3 | — | bits 26, 31 |
| PLL4 | bit 27 | bit 31 |
| PLL5 | — | bits 27, 31 |

### 解读

- **word 22144 = 偶数号源**（0/2/4），**word 22145 = 奇数号源**（1/3/5）；
- 两字都用 bits 25–27 做 **one-hot**，位置 = `n // 2`；
- `(22145, 51)` 的 **bit 31 = 使能/有效**（PLL 样本恒置，MMCM 样本只在部分置位）。

即编码是「**奇偶分字 + 每字 3 位 one-hot**」：

```
PLL n:  字 = 22144 + (n & 1)，位 = 25 + (n >> 1)
```

6 个样本全部吻合（0/1/2/3/4/5 → 字位组合无重复）。

## 3. 与 MMCM 的差异

MMCM 样本除了 22144/22145 的字位，还额外改动了 **帧 22147 的 word 27–30**（8 位置 one-hot）、
以及 22144/51 的 bit 29、31。原因很可能是：

- MMCM 输出在进入 HCLK_CMT 之前要先选「哪个 CMT 实例的哪路输出」，
  这段多出来的字段属于 CMT 自身的交叉开关，而不是 HCLK_CMT 的 MUX_CLK_k；
- PLL 输出走的路径更直接，所以只暴露 MUX_CLK_k 的选择位。

## 4. 目前的编码模型

`MUX_CLK_k` 的 48 个源可分为 5 类，每类各自的编码方式：

| 类 | 源数 | 观测到的编码 |
|---|---|---|
| `MUX_CLK_PLL0..7` | 8 | 奇偶分字 + 3 位 one-hot（**已解**） |
| `MUX_CLK_MMCM0..13` | 14 | 同上 + CMT 交叉开关字段（**部分**） |
| `CK_BUFHCLK0..11` | 12 | 未测 |
| `CK_IN4..13` | 10 | 未测 |
| `CCIO0..3` | 4 | 直连设计不经过 HCLK_CMT，需另找构造 |

## 6. 补测 PLL6/PLL7：失败（`/opt/lzh/v7re/work/hclk7`）

原计划在 `PLLE2_ADV_X1Y6` 上取 CLKOUT0/2/5，期望看到 `MUX_CLK_PLL6/7`。结果：

| 样本 | 选中源 | 与 p0 的差异 |
|---|---|---|
| q0 (X1Y6, CLKOUT0) | **无 HCLK_CMT PLL PIP** | 164 格 / 多帧（16830…） |
| q1 (X1Y6, CLKOUT5) | 同上 | 163 格 |
| q2 (X1Y6, CLKOUT2) | 同上 | 164 格 |

原因：`X0Y6` 与 `X1Y6` **不在同一 CMT 列**。X1 列的路由走
`CMT_TOP_L_UPPER_T_X305Y356` 那一族 tile，输出的 HCLK_CMT 是另一个 tile、
落在另一批帧上，所以与 X0 列的样本不可比。

**结论**：单个 CMT 列只有一个 PLL 站点（每列 7 个行位，每行一个 PLL/一个 MMCM），
`PLL0..5` 的 6 个 CLKOUT 已被一次测完；**`PLL6/PLL7` 需要来自同一列的另一路源**，
现有构造无法产生。

## 7. 诚实的能力声明

- `MUX_CLK_PLL0..5` → `(字 22144+(n&1), 位 25+(n>>1))`：**6 个样本自洽，无例外**；
- 但 8 个源只覆盖 6 个，公式里「8 个位置」的后两位（PLL6/PLL7）**没有实测支撑**；
- 因此该公式应标注为 **部分验证**，不能直接当作全组定律。
