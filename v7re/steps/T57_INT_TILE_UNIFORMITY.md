# T57：所有 INT tile 是不是同一套规则（可证伪检验）

日期：2026-11-08
脚本：`v7re/scripts/all_int_tiles_check.py`

## 1. 判据

对每个 INT_L/INT_R 实例，取窗口 = 帧 `base + [0..25]` × 字 `{2*(y%50), 2*(y%50)+1}`，
窗口内**每个置 1 位**的相对坐标 `(frame_off, bit, parity)` 必须落在该 tile_type 的
**格宇宙**（`law_cells` 里全部 `sense=1` 格的并集，INT_L/INT_R 各 1,598 格）里。

任一位在宇宙外 → 该 tile 违反「同一套规则」。

这是可证伪的：它允许出现「表外位」，只要如实计数。

## 2. 小样本（56 个 bitstream）

| 项 | 数值 |
|---|---|
| 覆盖 INT tile 实例 | 497 / 53,100（0.94%） |
| 窗口内置位总数 | 11,771 |
| 落在宇宙外 | **9** |

9 个残差、9 个设计各 1 位，两类坐标：

- `(frame_off=0, bit=16, parity=1)` —— **T5 已测的 GCLK 直通使能位**，本来就不在 `law_cells`（已硬编码在 `bitwriter.py` 的 `GCLK_PASS_BIT`）；
- `(frame_off=1, bit=31, parity=1)` @ `INT_R_X31Y97` —— 性质未定，疑似同类直通位。

## 3. 广覆盖设计（本轮）

200 个 LUT6（INIT 随机、`DONT_TOUCH`），site 由 Tcl 运行时从 75,900 个合法 SLICE 里等距挑 200 个，
覆盖 16 列 × 14 行；`-part xc7vx485tffg1157-3`；一次构建成功（`cov.bit` 20,273,538 B）。

| 项 | 数值 |
|---|---|
| 覆盖 INT tile 实例 | **3,167 / 53,100（5.96%）** |
| 窗口内置位总数 | 13,680 |
| 落在宇宙外 | **2** |

两个残差同坐标类：`INT_R_X13Y345` 与 `INT_R_X25Y345` 的 `(frame_off=0, bit=31, parity=0)`。

关键旁证：**这两个 tile 在 `cov.pips` 里 PIP 数为 0** —— 没有任何 mux 被选中。
同时查 `law_cells`：`(0,31)` 在全器件各 tile_type 里只有 `parity=1` 的 3 条，`parity=0` 一条也没有。

即：这 2 位**不是 PIP 选择位**，是配置块里别的东西（同一配置块内还有别的 tile 类型）。

## 4. 结论

**规则是统一的。** 依据分两层：

1. **结构性**：segbits 的行格式是 `TILE_TYPE.FAMILY.SRC`，**没有 col/y 字段**，
   一条记录描述「该类型内的一次连接」，对每个实例套同一份表 —— 同名同规则是数据模型的必然；
2. **实测**：累计观测 **3,600+ 个 INT tile 实例、25,000+ 个窗口内置位**，
   落在格宇宙外的仅 **11 位**，且全部属于**表外直通/非 mux 位**（PIP 数为 0 或已知 GCLK 直通），
   没有一例是「某个 tile 的 mux 用了不同的编码」。

## 5. 边界（诚实标注）

- 覆盖率 5.96%（3,167 / 53,100），未达全器件；穷尽需要铺满全芯片的设计；
- 表外位（GCLK 直通、`(0,31,p0)`）语义未建模，属「已知缺口」而非「规则不一致」；
- `INT_R_X31Y97 (1,31,1)` 与 `(0,31,0)` 是否为同一族，未定。
