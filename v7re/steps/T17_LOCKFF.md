# T17：LOCK_PINS 确认通过 + FF.INIT 位定位

日期：2026-11-06
两次实验共 18 个构建（每构建回读 SITE/BEL/INIT），远端 `/opt/lzh/v7re/work/lockff`。

## 1. LOCK_PINS 确认：布局确实全局统一

两个不同行、同一 BEL（A6LUT），都加 `set_property LOCK_PINS {I0:A1 I1:A2 I2:A3 I3:A4 I4:A5 I5:A6}`，
各造 `INIT=1<<k`（k=1,2,4,8,16,32）：

| k | `SLICE_X12Y4` 归一化格 | `SLICE_X12Y20` 归一化格 | 相同 |
|---|---|---|---|
| 2 | (帧+2, 位14) | (帧+2, 位14) | ✅ |
| 4 | (帧+2, 位13) | (帧+2, 位13) | ✅ |
| 8 | (帧+0, 位15) | (帧+0, 位15) | ✅ |
| 16 | (帧+2, 位11) | (帧+2, 位11) | ✅ |
| 32 | (帧+2, 位7) | (帧+2, 位7) | ✅ |

**5/5 逐项相同，位置集合完全相同**（差异只在 word：row4 用 word 8、row20 用 word 40，符合 `2*(y%50)+parity`）。

结论：**T16 的判断成立 —— 物理布局与行/列无关，之前的差异全部来自未锁引脚导致的输入置换。**

## 2. FF.INIT 位：单比特，干净

基线 `F0`（`SLICE_X12Y20`：A6LUT INIT=1 + AFF `FDRE(CE=1b1, R=1b0)`），
对照 `F1`（同一设计，仅 `FDRE #(.INIT(1'b1))`）：

```
新增 0 格，消失 1 格：frame 31783 word 40 bit 3
```

即 **AFF 的 INIT 位 = (块基址+67, word 40, bit 3)**，`INIT=0` 时该位为 1，`INIT=1` 时清零。
单比特、可逆、无副作用 —— 这是 CLB 里 FF 的第一条可靠映射。

## 3. FF 的 CE / 同步复位 / 置位：本轮没测出来

`F2`（CE 接 `ce` 引脚）、`F3`（R 接 `rst`）、`F4`（FDSE）、`F5`（FDPE）与基线的差异都是
**47–49 新增 / 15–18 消失**，且大量落在 INT tile 的布线上（帧 32371/32373/32500 等）。

原因很清楚：把 CE/R/S 从常量改成真实引脚，**网表与布线都变了**，差分里混进了布线位，
无法把 FF 的配置位单独分离出来。

## 4. 干净的做法（下一步）

保持引脚与布线完全相同，只换原语类型：

```
G0: FDRE  (.CE(1'b1), .R(1'b0))     ← 同步复位，复位脚接常量
G1: FDSE  (.CE(1'b1), .S(1'b0))     ← 同步置位，置位脚接常量
```

两者都只有「CE=常量 + R/S=常量」的 tie-off 连线，布线应当完全一致，
差分就只剩「同步复位 vs 同步置位」的那一两位。CE 位同理可用
`FDRE` 的 `CE` 接常量 vs 接另一个常量源来试（或比较 `FDRE` 与 `FDRSE` 的默认态）。
