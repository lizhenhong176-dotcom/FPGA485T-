# T48：HCLK_CMT 选择位枚举（7 个 MMCM 输出）—— 两段式编码

日期：2026-11-08
远端：`/opt/lzh/v7re/work/hclk5`，8 个构建（7 输出 + 1 换 site），8 路并发。

## 1. 设计

```
pin → MMCME2_ADV(LOC=MMCME2_ADV_X0Y6，7 个 CLKOUT 全 ÷10、参数逐字相同) → BUFH → FDRE
k0..k6 = CLKOUT0..CLKOUT6 → BUFH
```

MMCM 配置位七份完全一致，唯一变量是「哪个 CLKOUT 接到 BUFH」。
Vivado 实际选中的 HCLK_CMT 源：

| 设计 | 输出 | 选中源 |
|---|---|---|
| k0 | CLKOUT0 | `MUX_CLK_MMCM0` |
| k1 | CLKOUT1 | `MUX_CLK_MMCM2` |
| k2 | CLKOUT2 | `MUX_CLK_MMCM4` |
| k3 | CLKOUT3 | `MUX_CLK_MMCM6` |
| k4 | CLKOUT4 | `MUX_CLK_MMCM8` |
| k5 | CLKOUT5 | `MUX_CLK_MMCM9` |
| k6 | CLKOUT6 | `MUX_CLK_MMCM10` |

## 2. 差分（与 k0 比）

| 对比 | 数据格 | 帧 |
|---|---|---|
| k0→k1 | **2** | 22144, 22147 |
| k0→k2 | 4 | 22144, 22145, 22147 |
| k0→k3 | 4 | 22144, 22145, 22147 |
| k0→k4 | 4 | 22144, 22145, 22147 |
| k0→k5 | 4 | 22144, 22145, 22147 |
| k0→k6 | 3 | 22144, 22147 |

全部集中在**帧 22144/22145/22147**（word 27–30、51）。换源只动 2–4 格。

## 3. 原始字值（两段式结构）

### 第一段：帧 22144 word 51，bits 25–31

| 源 | 值 | 置位 |
|---|---|---|
| MMCM0 | `0x84000000` | 26,31 |
| MMCM2 | `0x88000000` | 27,31 |
| MMCM4 | `0x02000000` | 25 |
| MMCM6 | `0x04000000` | 26 |
| MMCM8 | `0x08000000` | 27 |
| MMCM9 | `0x00000000` | — |
| MMCM10 | `0x22000000` | 25,29 |

### 第二段：帧 22147 word 27–30，bit 9 / bit 25（两半各一位）

| 源 | 出现位置 |
|---|---|
| MMCM0 | w29 高半（bit25） |
| MMCM2 | w29 低半（bit9） |
| MMCM4 | w28 高半 |
| MMCM6 | w28 低半 |
| MMCM8 | w27 高半 |
| MMCM9 | w30 低半 |
| MMCM10 | w27 低半 |

## 4. 结构判断

- **第二段是 8 个位置的 one-hot**：4 个 word（27/28/29/30）× 2 个半区（bit 25 / bit 9）= **8 组**。
  7 个样本恰好落在 7 个不同组上，无重复。
- **`48 = 8 组 × 6`**：与 `MUX_CLK_k` 的 48 个源正好整除。
- **第一段的 bits 25–27** 是组内序号（观测到 0/1/2/4），位 29、31 是额外的类标记位
  （MMCM0/2 带 bit31，MMCM10 带 bit29，MMCM4/6/8 两者皆无）。
- 另有一处 `(22145,51) bit30`：MMCM4/6/8/9 置位，MMCM0/2/10 不置位 —— 与「输出编号是否 ≥2」不严格对应，
  更像第三个维度（可能是「是否经过 BUFH 直连」或 CMT 内部的旁路位）。

## 5. 结论与缺口

**已确定**：换一个 HCLK_CMT 源，位流只动 2–4 格，且位落在固定的两段结构里（22144/51 与 22147/27–30）。
**未确定**：组的划分规则（哪 6 个源属于同一组）、类标记位的含义。

要闭合，至少还需要以下样本：
1. 同组 6 个源各测一次（例如把 6 个 CLKOUT 组合成同一组的假设验证）；
2. `CK_BUFHCLK0..11` 组（用 BUFG 直驱）；
3. `CCIO0..3` 组（输入引脚直驱 HCLK_CMT）；
4. `MUX_CLK_PLL0..7` 组（PLL 输出）。

每样本 2 个构建，32 路并发下整批 ≤ 5 分钟。
