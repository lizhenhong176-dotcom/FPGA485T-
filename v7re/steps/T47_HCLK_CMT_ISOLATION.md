# T47：HCLK_CMT 隔离成功 —— 换源只动 2 格

日期：2026-11-08
远端：`/opt/lzh/v7re/work/hclk4`（3 个构建，3 路并发，约 3 分钟）

## 1. 实验设计（关键突破）

三个设计**完全相同**，只有「MMCM 哪个输出喂 BUFH」不同：

```
pin → MMCME2_ADV(CLKOUT0/1/2 都是 ÷10，参数逐字相同) → BUFH → FDRE
g0: BUFH.I = CLKOUT0
g1: BUFH.I = CLKOUT1
g2: BUFH.I = CLKOUT2
```

MMCM 配置位完全一致 → 差分中只有 HCLK_CMT 的 mux 选择与 MMCM→HCLK_CMT 的连线不同。

## 2. 结果：PIP 只差一行，配置只差 2 格

| 对比 | 数据差格 | PIP 差异 |
|---|---|---|
| `g0` vs `g1` | **2 格 / 4 位** | 仅 `HCLK_CMT_MUX_CLK_MMCM0/-2 ->> MUX_CLK_13` 一行 |
| `g0` vs `g2` | **4 格 / 6 位** | 同上，换成 MMCM4 |

三个设计的 PIP 行数完全相同（`193/193/193`），HCLK_CMT 侧只有一条 PIP 不同。
这在本项目里是**第一次对 HCLK_CMT 做到干净隔离**。

## 3. 差分位（以 g0 为基线）

```
g1: (32636, word51, bits 26,27)  (32639, word29, bits 9,25)
g2: (32636, word51, bits 25,26,31) (32637, word51, bit30)
    (32639, word28, bit25) (32639, word29, bit25)
```

**全部落在帧 32636–32639**，与阶段二定位的 CMT 帧簇相邻但更精确（不是 35528–35585 那一簇）。

## 4. 原始字值（供解码）

| 位置 | g0 (MMCM0) | g1 (MMCM2) | g2 (MMCM4) |
|---|---|---|---|
| (32636, 51) | `0x84000000` | `0x88000000` | `0x02000000` |
| (32637, 51) | `0x0` | `0x0` | `0x40000000` |
| (32639, 28) | `0xd8009010` | `0xd8009010` | `0xda009010` |
| (32639, 29) | `0xda00d800` | `0xd800da00` | `0xd800d800` |

`(32639, 28/29)` 出现明显的高低位整段互换（`0xda00` ↔ `0xd800`），
提示这里是**两个独立的 16 位字段**，而非单一二进制字段。

## 5. 观察与下一个判据

- 三个样本里 `MMCM0/2/4` 是**同一个 MMCM 的三个输出**（CLKOUT0→MMCM0、CLKOUT1→MMCM2、CLKOUT2→MMCM4），
  所以位模式里混着「实例编号」和「输出序号」两个维度；
- 要拆开这两个维度，必须补一个「**不同 MMCM 实例**」的样本（例：把 MMCM 放到另一个 `LOC`）。

## 6. 下一步（枚举）

1. 补 4 个不同 MMCM site 的样本 → 分离「实例」维度；
2. 用 CLKOUT3–6 补输出序号 3–6；
3. 用 BUFG 直驱 vs BUFH 直驱补 `CK_BUFHCLK*` 组；
4. 每个样本 2–3 个构建，32 路并发下整批 ≤ 5 分钟。

## 7. 结论

**HCLK_CMT 的 mux 选择位是可以逐个测出来的**：换一个源，位流只动 2–4 格，
且 PIP 列表仅一行不同。这满足项目一贯的「受控差分」判据。
