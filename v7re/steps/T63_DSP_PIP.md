# T63：DSP48 PIP 编码实测 —— 基本 1 格（one-hot），带"零值默认"

日期：2026-11-09
实验：`/opt/lzh/v7re/work/dsppip3`（9 个构建，全部 `CHK_SITE=DSP48_X0Y138`，`-part xc7vx485tffg1157-3`）

## 1. 结果

| 切换 | 置 0 时的格 | 置 1 时的格 | 变化 |
|---|---|---|---|
| CEAD | (21494, 92, 31) | (21495, 92, 30) | 1 关 1 开 |
| CEALUMODE | (21494, 92, 18) | (21495, 92, 19) | 1 关 1 开 |
| CED | (21495, 93, 8) | (21494, 93, 8) | 1 关 1 开 |

| CECTRL | (21489, 95, 14) + (21493, 95, 14) | 无 | 2 关 0 开 |
| CEM | (21488, 95, 9) + (21492, 95, 9) | 无 | 2 关 0 开 |

单次切换最多动 **2 格**，没有任何一族出现 3 格以上。

## 2. DSP tile 的帧布局

`DSP48_X0Y138` 的配置落在 **帧 21488–21495（相对 0–7，共 8 帧）**；
同一 tile 的另一个站点占 21480–21487。底座置位格数：帧 21488/21492 各 52/125 格（其余站点 12–27 格），
与"每站点 8 帧"一致。

## 3. 两种编码形态

**形态 1：单格 one-hot（CEAD / CEALUMODE / CED / CEINMODE）**
置 0 与置 1 各有一个格，且**位置不同**（甚至跨帧）→ 一族两格，任一时刻只有一个置 1。

**形态 2：零值默认（CECTRL / CEM / CEP / CEC）**
置 0 时有 1–2 格，置 1 时**一格都没有** → 该 PIP 的"1"状态由**缺省**表示，不占位。
这正是 prjxray 里 `kind='always'` 那类零值状态的成因。

## 4. 与离线形状预测的对照

`tile_pip_lawscan` 预测 DSP：每源格数 `{1: 428, 2: 4, 3: 4}`，平均 5.5 源/族。
实测 8 族全部落在 1–2 格，且 4 族呈现"1 格的 0 态 + 0 格的 1 态"（等价 1 格），
与预测一致：**DSP 的 PIP 基本是"一条 PIP 一个位"**，不需要 INT 那种二维寻址。

## 5. 结论

| tile 类型 | 一条 PIP 几位 | 编码形态 |
|---|---|---|
| INT | 2 或 4 | 行列二维寻址 |
| BRAM（预测） | 1 或 2 | 半 one-hot |
| **DSP（实测）** | **1（少数 2）** | **one-hot + 零值默认** |
| CLB 站内（预测） | 1 | one-hot |

DSP 的编码复杂度远低于 INT：**没有复用问题**（1 源 ≈ 1 格），因此也不需要"复用规律"这一层分析。
