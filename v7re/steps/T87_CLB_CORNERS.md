# T87 CLB 边角位收口（7 个构建）

日期：2026-11-11　器件：xc7vx485tffg1157-3　块基址 31752（SLICE_X12Y20）

| 设计 | 内容 | 结果 |
|---|---|---|
| `p_cy1` | `CARRY4 .CYINIT(1'b1) .CI(1'b0)` | OK |
| `p_cypin` | `CARRY4 .CYINIT(a)`（输入脚直驱） | OK |
| `f_fdre_bff` | FDRE 在 `SLICE_X12Y20/BFF` | OK |
| `f_ldce_bff` | LDCE 在 `BFF` | OK |
| `c_ce_lut` | FDRE，CE 由 `B6LUT` 输出驱动 | OK |
| `r_ram_wepin` | `RAM32M`，`WE=we` 引脚 | OK |

## 2 BFF 上的一致性检验（最干净的一组）

`f_fdre_bff` vs `f_ldce_bff`：**全芯片 1 移除 / 2 新增**

```
移除: (0, 41, 16)          ← FFSYNC（与 AFF 上完全相同）
新增: (1, 41, 19)          ← CLKINV
      (30, 41, 0)          ← LATCH
```

⇒ 这三个位是**slice 级**的，不随 AFF/BFF 变；`LATCH` 由候选升为**确认**。
（SR 位没出现，因为两份的 `R/CLR` 都是 `1'b0`——与 T85 的 3 位结论无矛盾。）

## 3 CE 的位：4 位稳定 + 3 位随源变

`d_cepin`（CE 来自引脚）vs `c_ce_lut`（CE 来自 B6LUT 输出）：

```
移除（只随引脚那份有）: (8,39,16) (13,39,17) (19,41,1)
```

而这 4 位在两份里都在：

```
(1,41,7) (23,41,0) (24,41,0) (25,41,0)
```

⇒ `CEUSEDMUX` 的最强候选是 **`(1,41,7)`**（CE 用/不用时切换、与 CE 源无关）；`(23,41,0)(24,41,0)(25,41,0)` 是连续三帧的 3 位模式，疑为 CE 的**目标选择**编码。
`(8,39,16)(13,39,17)(19,41,1)` 只在「CE 由引脚来」时置位，属路径相关位。

## 4 PRECYINIT：常量 1 档确定，其余未定形

- `p_ci1`（T86，`.CI(1'b1)`）与 `p_cy1`（`.CYINIT(1'b1)`）**都**置 `(0,40,12)`；
- `p_cypin`（`.CYINIT(a)`）不置该位，但差分 170/116 格（布线噪声大）。

⇒ `(0,40,12)` = 「进位初值取常量 1」档。prjxray 的 `PRECYINIT` 是 3 位字段（CY0/INIT0/INIT1），另两档的位号尚未定位——`CYINIT` 走专用布线，换档必然改布线，单靠差分分不出来。

## 5 SMEM 的 WEMUX：未定形

`r_ram_we1`（`WE=1'b1`）vs `r_ram_wepin`（`WE=we`）：8 移除 / 59 新增，CLB 块内 3/13 格，噪声大于信号。

候选（未定）：`(1,40,13)`（只 we1 有）、`(0,40,14)(0,42,11)(1,42,14)`（只 wepin 有）。
⇒ `WEMUX` / `WA7USED` / `WA8USED` **本轮没拿到**，需要新构造（例如让 WE 恒 0 但 RAM 仍然推断出来）。

## 7 边界

- 全部只在 `SLICE_X12Y20`（grid_col 20，Y=20 上半区）实测；BFF 只做了 LATCH/FFSYNC 两点。
- `c_ce_lut` 与 `d_cepin` 的对照里，CE 源不同也带来了 LUT 布局变化（`u_ce` 占了 B6LUT），所以 4 位"稳定"结论有一个混杂变量，需再用「CE 来自另一个引脚」复核。
- 分布式 RAM 那组噪声过大，不作结论。
- V7 帧偏移与 prjxray A7 的偏移体系不同，不能直接套 A7 位号。
