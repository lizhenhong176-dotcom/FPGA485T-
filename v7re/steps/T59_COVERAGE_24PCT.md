# T59：覆盖率 24.36% 的双检验（800 LUT 设计）

日期：2026-11-09
设计：`_tilecov2/`（800 个 LUT6，INIT 随机、`DONT_TOUCH`，site 由 Tcl 从 75,900 个合法 SLICE 等距挑 800 个；
`-part xc7vx485tffg1157-3`；stride=90）。产物 `cov2.bit` / `cov2.pips`（1.8 MB）。

## 1. 格宇宙残差检验

| 项 | 数值 |
|---|---|
| 覆盖 INT tile 实例 | **12,937 / 53,100（24.36%）** |
| 窗口内置位总数 | 64,326 |
| 落在格宇宙外 | **20（0.031%）** |

20 个残差全部集中在高两位、parity=0：

| 分组 | 条数 |
|---|---|
| `(frame_off 0, bit 31, parity 0)` | 15 |
| `(frame_off 0/1, bit 30, parity 0)` | 5 |
| 按 tile_type | INT_R 15 / INT_L 5 |

**14 / 20 个残差 tile 的 PIP 数 = 0**（另 6 个有 1–13 条）。即绝大多数残差出现在
「没有任何 mux 被选中」的 tile 上 —— 与 mux 语义无关。

## 2. 线长编码律检验

| 检验 | 结果 |
|---|---|
| A 名字一致性（列码要求的线长类别 == 源名长度） | **5,535 / 5,535 一致，0 反例** |
| B 位一致性（预测列帧格在真实位流为 1） | **5,184 / 5,184 = 100.00%** |

规模比上一轮大 8 倍（上一轮 661/648，本轮 5,535/5,184）。

## 3. 两轮合并结论

| 覆盖率 | tile 数 | 窗口位 | 宇宙外 | 线长律命中 |
|---|---|---|---|---|
| 5.96% | 3,167 | 13,680 | 2 | 648 / 648 |
| **24.36%** | **12,937** | **64,326** | **20** | **5,184 / 5,184** |

- **mux/BEG 语义：零反例**（线长律 5,832/5,832 累计，全部命中）；
- **表外位：22 个**（两轮合计），全部落在 `bit 30/31`、`parity 0`、多数在 PIP 数为 0 的 tile 上；
- 没有一个反例是「某 tile 的 mux 用了不同编码」。

## 4. 表外位的性质（未定，但已收窄）

- `law_cells` 里 `(frame_off=0, bit=31)` 只有 `parity=1` 的 3 条（`LH12` 族），`parity=0` 一条没有；
- 残差 tile 多数 PIP 数为 0 → 不是 mux 选择；
- 全部是每字最高两位 → 与「长线/全局走线经过该 tile」的标记形态一致。

结论：这是**同一块配置里非 INT-mux 的位**（长线直通/标记），不是规则不一致。

## 5. 边界

- 24.36% 覆盖，仍非穷尽（穷尽需铺满全芯片，预计 4,000+ LUT）；
- 表外位语义未建模；
- 无方向类别名的源（1,440 例中 779 例）不参与线长律检验。
