# T3 根因分析：同 family 跨列为什么会出现「两个一样的」

日期：2026-11-08　｜　探针：`v7re/steps/t3_hypothesis_probe.py`（只读，不引用 T2/T56 中间变量）
原始输出：`v7re/steps/t3_probe_out.txt`（184 行，下文所有引用形如 `t3_probe_out.txt:130`）
数据：`_full8.bit`（20,273,538 B）+ `v7re/steps/t2b_full8_decode.fasm`（191 非空行）

---

## 0. 一句话结论

**「两个一样的」是同一张不含 tile 坐标的格表被同一个解码循环应用到两个 tile 实例上的结果**：
物理层它由「块基址 + 块内偏移」的 CRAM 寻址保证（预期相同），口径层它由解码器
`v == obs` 的精确匹配规则保证（190/190 实例，`v7re/scripts/fasm2bit.py:274`），
两层各自都足以独立造成「两处相同」。判据 `missing=0 且 extra=0` 因此在同类型 tile 之间
**恒成立**，它证明的是「表与该位流自洽」，**不是**「两次独立观测吻合」。

## 1. 先锁定：这「两个」到底指哪一处（三候选判定）

| 候选 | 定义 | 本轮实测 | 判定 |
|---|---|---|---|
| **A** 两份远列设计的归一化格集合 | 用户原提议：同 family 在 col8 与 col32 各构一个设计 | 该实验**从未构建**；现有数据里 IMUX_L34 跨 col8/col32 的 `(family,src)` 配对 **0 条**（`t3_probe_out.txt:153-177`） | **对象不存在 → 不能作为本轮被解释的现象** |
| **B** c08/c20 镜像对照的两行 | CLB INIT，46 位，rel 32..35 | 已由 T1 判死：唯一零差映射是 4-循环 σ，不是镜像；与 PIP 无关 | 属 CLB 对象，机制为 σ（T1:§3-B） |
| **C** 同一批位被重复计数 | 一处位被两条 PIP 各记一次 | 76 个 tile 内两两 PIP 格相交 **0**、同位 ≥2 声明 **0**（`t3_probe_out.txt:92-93`） | **在本 artifact 内不成立** |
| **A′**（我在数据里找到的真实同类现象） | 同一 `(tile_type, family, src)` 在两个**不同 base / 不同列**的 tile 上，整窗归一化后完全相同 | `NW6BEG0.WW4END0`：`INT_L_X12Y16`(col12,y16,base 31888) vs `INT_L_X14Y15`(col14,y15,base 31960)，Δbase=72、Δcol=2、Δy=−1，整窗 rel 相同（`t3_probe_out.txt:135,138`） | **存在，且是本轮唯一可被完整解释的「两个一样的」** |

**结论**：能落到证据上的解释对象只有 **A′**。用户举例的 `IMUX_L34` 在现有数据里
**不能**构成 A′（详见 §3.4），B/C 各有独立机制、不能混用。

## 2. 假说检验表（每条含「若成立必然观测到」的可证伪预测）

### H1 同 tile_type 相对坐标可复用 → 预期相同

- **P1a**：Δbase≠0 的组内，归一化格集合全等。→ 实测：跨 base 的对 **25/187** 相同（`t3_probe_out.txt:180`）。
- **P1b**：Δbase≠0 的组内，**绝对**格集合必不全等。→ 实测 **187/187 全部不全等**（`t3_probe_out.txt:49-54`，`abs=False` 覆盖全部 187 对）。
- **P1c**：若表完整，窗口内每个置位位都应被某条已解 PIP 覆盖（残差=0），并且在**每一列**都成立。→ 实测：17 列、76 tile、458 位置位，**残差 0 位**（`t3_probe_out.txt:61-79`）。
- **P1d**：同一签名（同一批 PIP）的 tile 对，整窗 rel 必相同。→ 实测 **46/46**（`t3_probe_out.txt:144`）。

**判定：H1 支持**，但强度必须分层（这是本轮最重要的方法学结论）：

| 证据 | 是否独立于解码器 | 说明 |
|---|---|---|
| 46/46 同签名对相同 | **不独立** | 见 §3.1，由 `v==obs` 定义性推出 |
| 25/187 跨 base 对相同 | **不独立** | 同上（签名不同则 rel 不同，签名相同则必同） |
| 残差 0（17 列） | **独立** | 不预先限制在 family 域内，全窗口扫描；若存在未建模的列相关项，远端列必然出现残余位 |
| T2 的「每组 rel 种类=1」 | **不独立（循环）** | 见 §6 errata-1 |

### H2 归一化抹掉绝对坐标差异 → 假相同

- **P2a**：若相同是归一化凭空造的，则不同配置应被抹成同一 rel（过度坍缩）。→ 实测：53 个不同签名 ↔ 53 个不同 rel，**坍缩对 0**（`t3_probe_out.txt:58-60,147`）。
- **P2b**：不做归一化时应大面积相同。→ 实测：绝对坐标相同的对 **0/240**（`t3_probe_out.txt:57`）。
- **P2c**：换一种（错误的）归一化，相同应大面积消失。→ 实测：不归一化 **0/30**、用绝对 word **0/30**、正确归一化 **6/30**（`t3_probe_out.txt:81-87`）。
- **P2d**：镜像类变换（帧镜像 25−fo / 67−fo、parity 翻转、bit 镜像 31−b）若参与成因，应给出与正确归一化**不同**的判别结果。→ 实测：**各 6/30，与正确归一化完全相同**（`t3_probe_out.txt:83-87`）。

**判定：H2 作为「过度坍缩」被排除**（P2a/P2b/P2c 全部反向）；
但 **P2d 揭示了一个必须写进结论的限定**：镜像/翻转是对每个 tile 独立施加的双射，
它保持「组内相等」，因此**这类假说在该数据上不可证伪**——不能拿「镜像也对」当证据，
只能说「在已成立的同一性映射下，镜像属多余假设」（奥卡姆）。

### H3 同一位被多条 PIP 复用 / 重复计数 → 计数假相同

- **P3a**：law 表级应存在复用。→ 实测：distinct(family,cell)=3204，(family,src) 行 17800，**复用 5.56×**（`t3_probe_out.txt:91`）——与 T1/C 的 5.56× 独立吻合。
- **P3b**：若重复计数造成现象，同一 tile 内两条已解 PIP 的格必相交。→ 实测：**相交 tile 0/76**（`t3_probe_out.txt:92`）。
- **P3c**：同一 tile 内同一位被 ≥2 条 PIP 声明。→ 实测 **0 格**（`t3_probe_out.txt:93`）。

**判定：H3 在 law 表层成立、在本 artifact 的观测层被排除**。原因是 mux 互斥：
一个 mux 只有一个源被点亮，表中同族源共享格（5.56×）在物理上不可能同时置位。

### H4 行/列镜像或位序对称 → 成对出现

- **P4a**：若成因是镜像，组内应只有少数「镜像对」相同，而不是全部两两相同。→ 实测组大小分布 `{2:20, 3:2, 4:3, 5:1, 6:2, 13:2}`，13 tile 组有 C(13,2)=78 对（`t3_probe_out.txt:98-99`）——「两个」是抽样，不是结构上限。
- **P4b**：列镜像 c ↔ 33−c 应命中。→ 实测 **0/30 组**（`t3_probe_out.txt:100`）。
- **P4c**：bit 序 b ↔ 31−b 应对称。→ 实测 458 个置位格中仅 **72 个（15.7%）** 对偶也置位（`t3_probe_out.txt:101`），不构成 32 位对称。

**判定：H4 排除**（P4b/P4c 反向；P4a 显示「成对」是组合数而非镜像结构）。

### H5（补充，计数口径变体）同一个错数在两处同时出现

- **P5a**：191 与 77 这两个数应能由「把 1 行 CLB INIT 当成 PIP」一次解释。→ 实测：FASM 非空行 191、PIP 190、带 PIP 的 tile 76（`t3_probe_out.txt:4`）；差各为 1，且 191−190 的那 1 行是 `SLICE_X12Y20.ALUT=0x…01`。
- **P5b**：该错值应在文档中出现两次（复制传播）。→ `STATUS.md:3550` 与 `STATUS.md:3582`。

**判定：H5 成立，但它只解释「同一个数字出现两次」，不解释格集合相同**——两者必须分开处置。

## 3. 直接机制（口径层 + 编码层）

### 3.1 口径层：判据的两边由同一张表构造

判据 `missing=0 且 extra=0` 的实现是：

```
obs  = { c ∈ domain(family) : bit(base+c.fo, word(y,c.par), c.bit) = 1 }
解码  = [ s | cells_of(tt,family,s) == obs ]        # fasm2bit.py:274  v == obs
extra = obs − cells_of(...)  = ∅                    # 因为输出条件就是相等
missing = cells_of(...) − obs = ∅                   # 同上
```

- 输出源的格集合**按定义**等于域内实测位集合，所以 `E ⊆ rel` 恒成立：
  **190/190 实例满足 `E == rel ∩ family域`**（`t3_probe_out.txt:127`）。
- 因此 T2 的「每个组合内相对格集合只有 1 种」**不可能取到第 2 种**：
  它把 `E` 与 `rel` 求交（`v7re/steps/t2b_pair_detail.py:80-81`），而 `E` 不含 tile 坐标、恒为常量，
  且 `E ⊆ rel` 已由解码器保证 → `E ∩ rel ≡ E`。
- 「同时出现两个一样的」= 解码循环依次遍历 76 个 tile，**同一张表在两个窗口各命中一次**。
  「同时」是循环的副产品，「一样」是同一常量被打印两次。

### 3.2 编码层：块基址 + 块内偏移

```
frame = tile_base(col, band, y) + frame_off      # 实例项：base
word  = 2*(y % 50) + parity                       # 实例项：y
bit   = bit                                        # 纯块内
表键  = (tile_type, family, src)                   # 无任何实例坐标
```

`cells_of()` 的入参只有 `(ttype, family, src)`（`v7re/scripts/fasm2bit.py:113`），
`law_cells` 表的列是 `tile_type, family, src_wire, frame_off, bit, sense, parity, src_index`——**没有 col / y / base**。
于是同一 `(tt, family, src)` 在任意同类型实例上占据相同的块内三元组 `(frame_off, parity, bit)`；
两个实例的差别只剩 `base` 与 `2*(y%50)`，而这两项正是归一化减掉的东西。

→ **物理上本来就该相同**，这就是「预期相同」，不是数据里的巧合；反过来说，
要让两个远列实例**不同**，表里必须存在一个列相关项，而残差 0（17 列）说明没有。

### 3.3 为什么是「两个」而不是「N 个」

30 个多实例组，组大小 `{2:20, 3:2, 4:3, 5:1, 6:2, 13:2}`，组内对数 **240**（`t3_probe_out.txt:9-10`）。
任取一对都是 240 中的一条；「两个」只反映你看的那一对，不反映结构上限。

### 3.4 用户举例的 `IMUX_L34`：在这份数据里**不构成**「两个一样的」

| 组 | 两端 | 整窗是否相同 | 不同的原因 |
|---|---|---|---|
| `BYP_BOUNCE0` | X32Y10 / X32Y6 | ✗ | 前者多一条 `SL1BEG3.SS6END3`（+2 位） |
| `FAN_BOUNCE7` | X32Y12 / X32Y8 | ✗ | 后者多一条 `NW6BEG0.NN6END0`（+2 位） |
| `SL1END1` | X32Y11 / X32Y7 | ✗ | 前者用 `NW6BEG0.NN6END0`，后者用 `WW4BEG0.NN6END0` |
| `SR1BEG_S0` | X32Y13 / X32Y9 | **✓** | 两端 PIP 集完全相同 → 整窗完全相同 |
| `WR1END1` | 仅 X8Y20 | — | 远列那端只出现 1 次，无配对 |

（`t3_probe_out.txt:153-177`）

三个必须说清的事实：
1. 4 组**全部在 col32、同一 base 32568、Δy=4**——是**行方向**（同列不同行），不是列方向。
2. 其中 3 组在**整窗层面并不相同**；只有 `SR1BEG_S0` 组整窗相同。
3. `WR1END1` 在 col8 出现、在 col32 不出现——所以「同 family 跨远列」的 `(family,src)` 键为空，
   按 (family,src) 比会「共有键=0」判据空洞（T1 §3-A 已预警，本轮实测确认）。

## 4. 因果链（一句话逐段可复核）

```
① CRAM 布局：块基址 + 块内偏移（law_cells 无 col/y 列）        → 同一 feature 在同类型实例上块内地址相同
② 归一化：减 base、减 2*(y%50)                                 → 剥掉唯一两个实例项
③ 解码：v == obs 精确匹配                                      → 输出源的格集合 ≡ 域内实测位集合（190/190）
④ 判据：missing/extra 两边都由同一张表算                       → 恒为 0
⑤ 「两个」：一次 decode 遍历 76 tile，同一表命中两次            → 同一常量被两次打印
```

①②是「预期相同」（编码层），③④是「口径必真」（表示层）。**二者同时成立**，
这才是「为什么会同时出现两个一样的」的完整答案：它是同一个必然性的两种表述，
不是两个独立证据互相印证。

## 6. Errata（对上游产物的两处更正，均附实测）

**errata-1（方法）：`t2b_pair_detail.md` §0「每个组合内相对格集合取值种类 [1]」是定义性恒真，不能作为可移植性证据。**
`t2b_pair_detail.py:80-81` 先取表常量 `E`（无 tile 坐标），再 `E & rel`；而 `E ⊆ rel` 由
`fasm2bit.py:274` 的 `v == obs` 保证（实测 190/190，`t3_probe_out.txt:127`）。
→ 该统计量的取值集合必然只有 1 个元素。真正有信息量的是 `t2b_pair_detail.py:87` 的
`assert rel == U`（窗口实测 == 各 PIP 格并集），本轮把它扩到**全窗口、不预限域**后仍为 0 残差
（`t3_probe_out.txt:61-79`），这才是独立证据。

**errata-2（口径）：`t2b_pair_detail.md:416` 与 `:424` 的「同 base 两端是同一批绝对位」不成立。**
18/18 个 Δbase=0 组的两端 **y 不同**（如 `IMUX_L34.BYP_BOUNCE0`：y=10 与 y=6，同 base 32568），
绝对 word 由 `2*(y%50)+parity` 给出，故绝对位集合**不同**（`t3_probe_out.txt:104-123`，全部 `abs种类=2` 或 `=3`）。
正确表述应为：**这些对是行方向（同列不同行）的非平凡一致**——它们恰恰是可移植性的正面证据，
而不是 T2 所说的「必然结果、不能当证据」。T2 把最强的一类证据误判成了最弱的一类。

## 8. 剩余不确定项（缺什么数据）

1. **A 的原始构想仍未执行**：col8 与 col32 各构一个**同一 `(family,src)`** 的设计（如 `IMUX_L34.SR1BEG_S0`），
   才能把「跨远列」从 A′ 的 Δcol=2 推到 Δcol=24。当前数据不能替代。
2. 现有**跨列 PIP 独立差分**最强证据来自 `step03_pip/CROSS_TYPE_RESULTS.md`（INT_L_X6Y11 vs INT_R_X9Y11，
   col 6 vs 9，帧窗 +108，**same=792 / diff=0**）与 `CROSS_TILE_RESULTS.md`（同列不同行 Y11 vs Y21，
   150/150）；`RESULTS.md` 的 Y=20…60 系列给出 word≈2*(Y−区域起点)+k、bit 恒 b7 的行方向实测。
   这些是真实构建的差分，非表推导，但它们覆盖的是行方向与跨类型，**不是 col8 vs col32 同族**。
3. `_full8.bit` 只有 6/30 组整窗全等，其中跨列仅 1 对（Δcol=2）——样本对「远列」不足。
