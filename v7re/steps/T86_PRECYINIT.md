# T86 PRECYINIT / 进位初值：CI 常量选择是 1 位

日期：2026-11-11　器件：xc7vx485tffg1157-3　站点：SLICE_X12Y20（块基址 31752）

## 1 构造

两个设计完全相同，只差 `CARRY4` 的 `.CI` 常量：

```
CARRY4 u_cy (.CO(co), .O(so), .CI(1'b0 或 1'b1), .CYINIT(1'b0),
             .DI({a,b,c,1'b0}), .S({a,b,c,1'b1}));
```

`LOC SLICE_X12Y20` 固定，输出 `o = co[3] ^ so[0]`，引脚全部固定。

## 2 结果：全芯片只差 1 格

```
p_ci0 (CI=1'b0) vs p_ci1 (CI=1'b1)
(帧 31752, word 40, bit 12)      CI=1'b1 时为 1
```

390 vs 391 格，**移除 0 / 新增 1**，无布线差异。

## 3 与 prjxray 的关系

prjxray `SLICEL_X1` 的 `PRECYINIT` 是 **3 位字段**（`INIT0/INIT1/CY0` 三种取值的组合编码）。本次只把 `CI` 从 0 换成 1，拿到其中**一个位**；另两位（`CYINIT` 选项、`INIT` 项）未测，需再构造 `CYINIT=1'b1` 与 `CYINIT=ci_net` 两档。

## 4 A5FF / A5FFMUX：未能隔离

- 已有 `f_o5`（FF.D=.O5()）vs `f_o6`（FF.D=.O6()）的差分是 `(30,40,0)` 单位，但那是 `AFFMUX` 的 O5/O6 档位（T83），**不是 A5FF**。
- `A5FF` 语义是「A5 位置的 FF 是否使用」，`A5FFMUX` 选 `IN_A`（A5 输入直通）还是 `IN_B`（O5 输出）。要用 IN_A，必须让 FF.D 直接吃 A5 引脚，这会把整条输入网换掉（上轮 `f_ax` 已证明噪声 40+ 格跨 700 帧），**本轮没有拿到**。

## 5 累计：CLB 站内已定位的 V7 位（块基址 31752）

| 特征 | 位置 | 极性 |
|---|---|---|
| `FFSYNC` | `(0, 41, 16)` | 1=同步复位 |
| `CLKINV` | `(1, 41, 19)` | 1=时钟反相 |
| `AFFMUX` O5/O6 | `(30, 40, 0)` | 1=O5 |
| `AOUTMUX` 4 位 | O5：`(3,40,8)(4,40,10)(6,41,4)(7,41,5)`；O6：`(3,40,4)(4,41,10)(6,41,8)(7,40,5)` | — |
| SR 使用 | `(1,41,2)(1,41,3)(1,41,9)` | 1=使用 |
| CE 使用 | 候选 `(1,41,7)` + 6 格待定 | 1=使用 |
| LATCH | 候选 `(30, 41, 0)` | 1=锁存 |
| `PRECYINIT`（CI 常量） | `(0, 40, 12)` | 1=CI 取 1 |

## 6 边界

- 全部只在一个 site（`SLICE_X12Y20`，grid_col 20，Y=20 上半区）实测。
- `CE`(7 格)、`LATCH`、`PRECYINIT` 的另一位 都是候选或部分，未做第二组独立对照。
- SMEM 的 `WA7USED/WA8USED/WEMUX` 未测（需 RAM32M/RAM64X1）。
