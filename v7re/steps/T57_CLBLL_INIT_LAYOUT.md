# T57：CLBLL_L 的 LUT INIT 布局（第二个 tile 类型，已独立实测）

日期：2026-11-08
样本：`SLICE_X8Y20`（CLBLL_L，`grid_col=16`，块基址 **31680**，`SLICEL.A6LUT`）

## 1. 为什么必须单独测

T54 用 CLBLM 的表去预测 CLBLL 的 INIT，结果 **13 缺 / 13 多**——两者布局不同。
本轮用 CLBLL 自己的 64 个单最小项构建（`_clbll/s00..s63` + 基线 `_clbll/b00`）重建布局。

## 2. 结果：64 格全覆盖，帧只占 4 帧

- **64 个构建各只产生 1 个新格**，64 格互不相同（无一例外）；
- 全部落在 **word 40**，帧 **31712–31715**（相对块基址 **32..35**）；
- 位域横跨 **bit 0..15**（16 位 × 4 帧 = 64）。

## 3. 验收：随机值精确命中

用 `INIT=0xDEADBEEFCAFEBABE`（46 位为 1）预测置位集合，与真实差分比对：

```
实测 46 位 / 预测 46 位
预测有实测无: 0
实测有预测无: 0
```

## 4. 与 CLBLM 的关系

| 项 | CLBLM_R（col 33） | CLBLL_L（col 16） |
|---|---|---|
| 相对帧 | **32..35** | **32..35** |
| word | 40 | 40 |
| 位域 | 0..15 | 0..15 |
| 索引 → (帧,位) 的排列 | 见 T19 公式 | **不同**（本表） |

即：**帧偏移与字是通用的，索引到位的排列是 per-tile-type 的。**
这与「PIP 的行映射 per-family 固化、列码可算」是同一种边界形态。
