# T45：BUFGCTRL 接入解码器 —— 闭环验证（B 任务）

日期：2026-11-08
新增 `v7re/scripts/clk_mux_bits.py`；`v7re/scripts/fasm2bit.py` 增加 BUFGCTRL 双向支持。

## 1. 编码（实测）

```
SEL=I1 → A=1, B=0
SEL=I0 → A=0, B=1
```
A/B 由 T43 公式给出：`f0=7834+5246*(Y//16)`、`w=(93+Y//2) mod 101`，
偶数 Y：`A=(f0,w,11) B=(f0+1,w,3)`；奇数 Y：`A=(f0,w,27) B=(f0+1,w,19)`。两对 one-hot。

## 2. FASM 语法

```
BUFGCTRL_X0Y16.SEL=I0     # 或 =I1
```

## 3. 验证（三项）

### 3.1 解码正确

| 位流 | 解出的行 | 与 RTL 一致 |
|---|---|---|
| `g16_s0`（S0=1,S1=0 → 选 I0） | `BUFGCTRL_X0Y16.SEL=I0` | ✅ |
| `g16_s1`（S0=0,S1=1 → 选 I1） | `BUFGCTRL_X0Y16.SEL=I1` | ✅ |

### 3.2 自身回写幂等

`g16_s0` 解码 → 回写：**改动帧 0**，sha256 与原件完全相同
（`C8621C0D…F31A17`）。

### 3.3 跨设计复现（关键）

把 FASM 里的一行 `SEL=I0` 改成 `SEL=I1`，用 `g16_s0.bit` 作基底重新生成，
与 **Vivado 独立生成的 `g16_s1.bit`** 逐帧对比：

- **帧级差异：0 格 / 50,176 帧**（含 word 50 的 ECC，全部一致）；
- **字节级差异：6 字节** —— 2 字节时间戳（`12:31` vs `12:32`）+ 4 字节尾部 CRC。

即：**配置数据与 Vivado 完全一致，只剩时间戳和 CRC**。

## 4. 能力边界

| 项 | 状态 |
|---|---|
| BUFGCTRL 选择位 解码/写入 | ✅ 全 32 site（公式） |
| 与 Vivado 产物逐帧一致 | ✅ 0 差异 |
| 尾部 CRC 重算 | ❌ 未解决（与 T32 同一个缺口） |
| BUFGCTRL 其它功能位（IGNORE/CE） | 只测了 IGNORE0 = `(13080,0,bit1)`，未接入 |

## 5. 结论

B 任务完成：**INT 布线 + CLB INIT + GCLK + BUFGCTRL 四层已经接进同一条 FASM 管线**，
并且能做到「改一行 FASM，得到一个与 Vivado 等价的设计」。
剩下的唯一系统性缺口是尾部 CRC。
