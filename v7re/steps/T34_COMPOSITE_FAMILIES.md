# T34：复合码族破解 —— 4 组 × (3 格 core + 单附加位)，覆盖率 100%

日期：2026-11-07
对象：`CLK_L0`、`CLK_L1`、`CTRL_L0`、`CTRL_L1`、`GFAN0`、`GFAN1`（各 16 源）+ `LV_L0`（10 源）

## 1. 观察到的结构

这 6 个族里，16 个源分成两类：8 个「2 格源」和 8 个「4 格源」。
把 2 格源两两求并集，恰好得到 **4 个 3 格 core**，且满足：

```
每个 core C：
  2 个源 = C \ {某一格}          （2 格）
  2 个源 = C ∪ {某个附加位}       （4 格）
```

**6 个族 × 4 组 = 24 组，全部满足；8 个 4 格源在每个族里 100% 被解释。**

举例（`CLK_L0` 第 1 组）：

```
core = {(0,0,25), (0,0,26), (1,0,24)}
  GCLK_L_B1 = core \ {(0,0,25)}
  GCLK_L_B2 = core \ {(1,0,24)}
  GCLK_L_B0 = core ∪ {(1,0,20)}
  FAN_BOUNCE5 = core ∪ {(1,0,21)}
```

其它族同构：

| 族 | 4 组 core（每组 3 格） | 附加位 |
|---|---|---|
| `CLK_L0` | 4 组，见上 | `(1,0,20)`、`(1,0,21)` |
| `CLK_L1` | 4 组 | `(1,0,29)`、`(0,0,29)` 等 |
| `CTRL_L0` | 4 组 | `(1,1,6)`、`(0,1,7)` 等 |
| `CTRL_L1` | 4 组 | `(1,1,4)`、`(1,1,9)` 等 |
| `GFAN0` | 4 组 | `(1,0,9)`、`(0,0,11)` 等 |
| `GFAN1` | 4 组 | `(1,0,13)`、`(0,0,18)` 等 |

**「附加位」的规律**：它不随源变化，而是每个 core 固定拥有 2 个附加位，
4 格源就是在 core 上多点亮其中一个 —— 即附加位是「第二级选择」的编码，
与第一级（core 的 3 格）正交。

## 2. 为什么不是完全二分

真正的纯二分层（BEG 96 族 + 时钟树 5 族）里，源 = 一条边 = A 侧一格 ⊕ B 侧一格（正好 2 格）。
复合族里 core 是 3 格：两个「选一侧」的位 + 一个「公共使能」，因此
2 格源 = core 少点一位，4 格源 = core 多点亮一个附加位。
**这不是退化，而是两级 mux 的编码**：第一级选 in-tile 输入，第二级选跨 tile 直通。

## 4. 诚实的边界

- **前 160 族**（mux + BEG + 时钟树）是**生成式**：给定 `(family, src)` 用公式/二分结构算出位，不需要查表；
- **后 7 族**是**结构已知、槽位查表**：core 与附加位的规律已经找到（这让 106 条 feature 的语义清楚了），
  但「哪个源对应哪个 core/附加位」仍来自器件布线图，与 BEG 的源→边映射同一性质。

因此「覆盖率 100%」指的是**模型能精确复现全部 3,634 条 feature 的位**，
其中 97.1% 由几何定律生成，2.9% 由「结构 + 槽位表」表达。
