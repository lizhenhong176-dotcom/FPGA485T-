# T83 AFFMUX：O5/O6 选择是 1 位，不是 4 位 one-hot

日期：2026-11-11　器件：xc7vx485tffg1157-3　站点：SLICE_X12Y20（SLICEM.A6LUT + SLICEM.AFF，块基址 31752）

## 1 结论

`AFFMUX`（FF 的 D 选择）在 V7 上**不是** 4 位 one-hot。实测 O5 与 O6 两个源之间只差 **1 个配置位**：

```
(f帧 31782 = 块基址 31752 + 30,  word 40,  bit 0)
O6 → 0     O5 → 1
```

两个设计的全部格数：O6 = 319，O5 = 320，**差分 = 移除 0 / 新增 1**，且回读 `BEL=SLICEM.A6LUT FF=SLICEM.AFF SITE=SLICE_X12Y20` 一致。

## 2 与 prjxray A7 结构一致

`segbits_clblm_l.db` 里 `SLICEL_X1.AFFMUX` 是 **4 位字段**，编码 6 个源（不是 one-hot）：

| 源 | `30_04` `31_00` `31_01` `31_02` |
|---|---|
| AX | 0 0 1 0 |
| CY | 0 1 0 1 |
| XOR | 0 0 0 1 |
| F7 | 0 1 1 0 |
| **O5** | 1 **1** 0 0 |
| **O6** | 1 **0** 0 0 |

O5 与 O6 **只差 `31_00` 一位** —— 与本次 V7 实测「只差 1 位」完全吻合。所以 V7 的 `(块基址+30, 40, 0)` 就是 A7 `31_00` 的对应位。

注意极性：bit = 1 → O5，bit = 0 → O6（default 为 O6）。

## 3 一条失败的对照（如实记录）

想再取一个源（AX，走 bypass）做第二点：设计 `f_ax`（`always @(posedge clk) q <= a;`，输入脚直连 FF）。
构建成功（回读同样 SITE/BEL），但差分 **40+ 格、跨 700+ 帧** —— 因为 `q <= a` 换了整条网，路由全变。

⇒ AX 走 bypass 的构造是**可行的方向但必须配合更严的闸门**（同网不同源），本轮没做到。`AFFMUX` 的另外 3 位（`AX`/`CY`/`XOR`/`F7` 区分）仍未测。

## 4 对「CLB 里有些不占配置位」的确认

本次与 T68/T82 合起来，CLB 里「不占位」的三类已经清楚：

| 对象 | 配置位 | 证据 |
|---|---|---|
| `CLBLM_L_A <- A1..A6`（LUT 输入 mux） | **0** | T68：换 `LOCK_PINS` 只改 INT 侧 IMUX |
| `CLBLM_BYP0 -> CLBLM_L_AX`（旁路） | **0** | T82：prjxray segbits 中无 BYP 行 |
| `AFFMUX` 的 O5/O6 选择 | **1**（不是 4） | 本次实测 |

## 5 边界

- 只测了 O5/O6 一对；`AX/CY/XOR/F7` 的位未定位（构造难点在「换源不动布线」）。
- 未验证该位在不同 slice（X0/X1）、不同行/列上是否同一相对坐标。
- `AOUTMUX`（4 位，`30_05/31_07/31_09/31_10`）与 `A5FFMUX`（1 位）未测。
