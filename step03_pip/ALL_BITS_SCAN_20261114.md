# 全量活跃实例扫描：本地 92 个位流上"规律是否生反例"

> 目的：回答审稿人式问题"这条规律在多少实例上验过、有没有反例"
> 脚本：`step03_pip/_q_all_bits_scan.py`｜结果：`step03_pip/out/all_bits_scan.json`
> 运行日期：2026-11-14｜判据来源：`v7re/scripts/tamper_localize.py`（L1 未解释位 / L2 槽位违例）
> 标注：【数据事实】= 本次实测；【推断】= 解释性

---

## 1 一句话结论

【数据事实】本地 **92 个位流**、**7,453 次活跃 tile 扫描**（去重 **1,965 个不同 tile**，占 INT 实例 53,100 的 **3.70%**）、**32,350 个置位**上：**L2 槽位违例 0**；L1 未解释位 576 个（占 1.78%），其中 **558 个（96.9%）落在 3 个已知标记格**，其余 **18 个**散在 5 个格、全部出现在手工单 PIP 探针设计里，**真实设计（`tamper/ref/ref.bit`）零反例**。

⇒ 可以写进论文的一句：**"在 7,453 次实例扫描中 L2 零违例（95% 上界 0.040%）；L1 表外位仅出现在已知未建模的帧 0–7 标记区，且仅出现于手工探针，未出现在自动化布局产出的设计上。"**

## 2 方法与口径

| 项 | 取值 | 说明 |
|---|---|---|
| 判据 L1 | 置位未被任何命中族解释 | `World.explain()`，只扫 `frame_off 0..25`（`HI=26`） |
| 判据 L2 | 槽位编码合法性 | `World.slot_violations()`：一热 ≤1 行、有行⇒码 ∈ {1,2,7,11}、有码⇒有行 |
| 活跃 tile 定义 | 该 tile 在 `word_of(y,0/1)` 上帧 0..25 有任一置位 | 全零 tile 不计入（不可能产生反例） |
| 位流来源 | 工作区 + `tamper/ref/` + `E:\v7work`（递归），≥1 MB | 共 92 个；跳过 1 个无同步字的 `rw_test.bin` |
| 上界公式 | rule of three：0 反例时 95% 上界 = 3/n | n = 7,453 次扫描 → 0.040% |

### 3.1 未解释位的完整分布（10 个格）

| `(frame_off, bit, parity)` | 次数 | 性质 |
|---|---|---|
| `(1, 0, 0)` | 269 | 已知标记格（时钟/布线标记），白名单 |
| `(1, 1, 0)` | 269 | 同上 |
| `(0, 16, 1)` | 20 | GCLK 直通位（`STATUS` §35 已定位） |
| `(1, 7, 1)` | 5 | 【数据事实】帧 1 旁路标记位，`T5_BITWRITER.md` §b1 反证已记录 |
| `(1, 3, 1)` | 5 | 同上 |
| `(1, 31, 0)` | 2 | 同区（帧 1）标记位 |
| `(1, 24, 1)` | 2 | 同区 |

| `(7, 7, 0)` | 1 | 同族现象，帧 7 |

【数据事实】18 个非白名单位分布在 10 个文件：`_c3 / _c3_rt / _c4 / _c4_rt / _c5 / _c0_to_c3 / _g16_edit / _rt_g16_s0 / _resynth / _s8v0`——**全部是手工构造或手工改写的单 PIP 探针**，没有一个是 `tamper/ref/ref.bit` 这类自动化布局产物。

【推断】这些位是"该 tile 被占用"的旁路/时钟标记，属模型外字段（`law_cells` 只建模 feature→bit，不建模 tile 级标记），与规律无关。

## 4 这份证据能说什么、不能说什么

**能说**
1. 在 1,965 个不同 tile、32,350 个置位上，**槽位编码律零反例**。
2. 未解释位高度集中（3 格覆盖 96.9%），且**不出现在自动化设计上**——说明它不是"规律随机失效"，而是"已知的模型外字段"。

**不能说**
1. 不能说"覆盖了全部 26,550 个实例"——只覆盖 3.70%。
2. 不能用它证明跨 tile 类型普适（92 个位流全是 INT 相关设计）。
3. 未解释位 18 个虽然集中在帧 0–7，但**尚未逐位归因**到具体的标记语义（只有 T5 对 `(1,7,1)/(1,3,1)` 做过反证实验）。
