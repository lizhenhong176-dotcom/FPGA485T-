# S69 · 定向设计归属实验：66 格中 9 格已实测归属

日期：2026-11-12　远端：`/opt/lzh/step19/hc/`（本地 `E:\v7work\hc\`）

## 0. 方法

每种功能做一个最小设计，**在两个不同 LOC 各建一份**（`SLICE_X8Y11` / `SLICE_X10Y20`；RAM/SRL 用两个 SLICEM `SLICE_X10Y20` / `SLICE_X6Y11`），并与同 LOC 的 `plain`（LUT6+FDRE 基线）逐位差分；只保留落在 66 格坐标上的差异，再**按 (off, parity, bit) 取两位置交集**。

- 10 + 6 次构建，14/16 成功（`ram32m`/`srl32` 在 SLICEL 上失败，改用 SLICEM + Verilog `LOC` 属性后成功）。
- 两个 LOC 的 hole 集合**完全相同**（ram32m 7/7、srl32 5/5、c4_inc 3/3、c4_casc 3/3）⇒ 归属可信。

## 2. 归属判定

| 坐标 | 归属 | 依据 |
|---|---|---|
| `(1,1,19)` | **CARRY4 存在**（进位链使用标记）| 只在 CARRY4 单链设计出现，RAM/SRL/时钟都没有 |
| `(0,0,12)` | **`PRECYINIT`=1** | 只在 `CYINIT=1` 的级联设计出现；与 S5 差分实测 `(0,40,12)` **完全一致** |
| `(0,0,4)` | **`ALUT` 分布式 RAM 模式** | 只在 RAM32M 出现；CLB 表 `ALUT` 同坐标 |
| `(0,0,24)` | **`BLUT` RAM 模式** | 同上（`BLUT`）|
| `(0,0,28)` | **`CLUT` RAM 模式** | 同上（`CLUT`）|
| `(1,1,27)` | **`DLUT` RAM 模式** | 同上（`DLUT`）|
| `(1,0,23)` | **`WEMUX`** | RAM32M 命中；CLB 表 `WEMUX` 同坐标 |
| `(0,0,0)` | **`ALUT` SRL 模式** | 只在 SRLC32E 出现（SRL16E/32E 用 A6LUT）|
| `(0,0,20)` | **`BLUT` SRL 模式**（推断）| 只在 SRLC32E 出现 |
| `(0,1,16)` | **`SLICE_USED`（通用标记）** | CARRY4 / RAM / SRL **三种都命中** ⇒ 不是功能专属 |
| `(1,0,7)` | **`LUT_OUT_USED`（通用标记）** | 同上三种都命中 |

**关键修正**：`(0,1,16)` 和 `(1,0,7)` 此前分别被 S52 命名为 `FF_USED_IN_SLICE` / `A5FF`，本次三组独立设计（都没有 FF、没有五输入 LUT）**全部命中** ⇒ 它们是「该 slice 有逻辑在用」的通用标记，与 FF/五输入 LUT 无关。

## 4. 附带结论

- **BUFG 时钟设计在这 66 格里 0 命中** ⇒ S68 里 `(1,0,31)` 与 PLL/BUFG 的 3.5× 相关是**伪相关**（来自其它设计特征），时钟网络不占用这些格。
