在保留 V1 全部要求的前提下，追加 4 条：

1. 加一节「5 分钟口头版」：≤600 字，可以直接念，顺序是 目标 → 最强结果 → 最硬缺口 → 下一步；不要表格，不要术语堆叠。
2. 加一节「最可能被追问的 3 个问题 + 应答」：每个问题给 3 句话以内的回答，答案必须引用 V1 证据表里的具体数字。
3. 加一节「如果只能展示一张表，展示哪张」：指定一张表并说明为什么它最能说明进度，同时给出这张表的完整内容。
4. 所有「已完成」的条目后面必须跟一个复算入口（脚本名、表名或文档小节号），没有复算入口的条目要显式标注「无可复算入口」。

另外：汇报稿里凡出现「我们首次/率先/唯一」这类说法，必须紧跟着给出「检索/对比证据」；给不出就不许写。
