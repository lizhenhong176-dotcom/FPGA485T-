# 背景事实（写入计划时须作为基线陈述，并标注证据指针到文件:行号）

- 目标器件与平台：XC7VX485T / VC707。
- INT tile 的 PIP 定律（mux feature → 配置位）已闭环：172/172 家族、3,634 条 feature、精确命中 3,634、未覆盖 0、不符 0；复算命令为 `v7re/scripts/verify_all_pip.py --tile-type INT_L`。
- 复合码族用「组模型」表达：24 组 core + 12 个附加位 + 96 条「源→槽位」映射；模型文件为 `v7re/steps/composite_groups.json` 与 `T35_COMPOSITE_GROUP_MODEL.md`。
- **关键口径（必须原样写入计划）**：每条源的实际位集 = 模型集 ∪ 该族 4 个恒定 cell；若遗漏恒定 cell 并回，照公式手算会得到不符率 100%。
- 位语义层已闭环：解码 → 重写 → 逐字节幂等。
- 数据层未接上：`site_frames` 表中 INIT 部分仍错误（索引标签被置换、X1 未测、BLUT/CLUT/DLUT 共 727 万行已删除以防留错数据），故解码器尚不能输出完整网表。
- 「自研」边界须在计划中点明：形状表来源是 prjxray artix7 segbits、跨家族沿用，见 `step03_pip/REUSE_RULES.md:8`；A 轨要收口的原点见 `v7re/steps/T3_PIP_REUSE_LAW.md` §9.2（12 个复合族当时记为「主码+附码、跨 parity、未闭合」）。
