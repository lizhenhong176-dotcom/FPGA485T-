## 正文（可直接使用）

你是 FPGA 位流逆向方向的研究者兼实现者，需要写出一份"能让人真正学会并复现"的自包含技术讲解，而不是概念综述。器件固定为 Xilinx Virtex-7 xc7vx485tffg1761-2。读者读完后应能达成三个可检验目标：（a）在 tile 表中定位任意指定资源（给出 tile 名、行列坐标、资源类型与数量）；（b）拿到一条位集（一组 cell 坐标及取值）能判断它对应哪条 PIP，并明确说出判断为唯一或不唯一的依据；（c）能独立设计一次差分 fuzz 实验去测量一个新家族的位池，并说明输入、步骤、判据与预期现象。

全文围绕四块展开：物理架构、位流结构、PIP 复用如何解开、家族到底是什么。其中第 1 块（PIP 复用）与第 4 块（家族）为必须详讲的重点，二者合计篇幅不得少于全文一半。

**必须详讲的两块：**

**1. PIP 复用**：不讲"位被共享"这一现象本身，而讲"怎么把复用解开"。必须给出完整可执行的六环解法链：位池与特征抽取 → 家族识别与命名 → 一热差分 fuzz 得到每源位模式 → 列计数签名反推 mux 分级结构 → 单 PIP 唯一性判据 → 同 tile 多 PIP 的联合求解（互斥+覆盖约束，说明为何是 CSP 而非查表）→ 写位回环验证（含 ECC/CRC）。每一环必须写明：输入是什么、输出是什么、判据是什么、这一环做错会以什么现象暴露。**每一环还必须给出"可执行伪代码或 Tcl/Python 片段级别的操作步骤"（至少 3 行伪代码或等价命令），不能只描述思路；缺伪代码的环作废。** 讲复用解法时给出具体位级例子：用 INT_L.EL1BEG_N3 家族（9 cell、20 源、每源 2 位、4 组×5 成员）走完整流程，包括位池坐标、列计数签名、两级解码，以及如何用它反推一条 PIP。

**2. 家族（family）**：给出可判定定义（不得用"一组 mux"这类循环定义），并且必须以"可计算谓词"形式给出：`family(f) = (tile_type, destination_wire)`，并附一条 SQL/pandas 级别的判定语句，说明如何从 feature 名字符串算出家族键；同时给出反例（哪两个 feature 名看起来同族其实不同族）。说明命名规则如何天然给出家族；界定家族与 PIP/mux/tile_type/site/wire type/net 的边界；说明家族内位池的三类形状与每源 1–4 位的成因；解释家族的两级 one-hot 编码为何导致位宽是 a+b 而不是 ceil(log2 N)；说明"跨族零共享"这条公理的地位（是观测事实还是假设、若被推翻会怎样）。

**其余两块也要讲透但不喧宾夺主：**

**3. 物理架构**：die 分区（14 个 clock region=7 行×2 列，列分界在中心 IO 脊 gx=81/312）、列序列规律（CLB|INT_L|INT_R|CLB、每 4 逻辑列插一个 VBRK、CLBLL 与 CLBLM 交替）、SLICEM 只能在 CLBLM 的偶 X（32,700/32,700）、各类资源数量与互相校验（DSP tile 1,400×2=DSP48E1 2,800、BRAM 15 列、MMCM 14=7×2）、时钟网络（BUFGCTRL 32、BUFHCE 168、BUFR/BUFIO 各 56、BUFMRCE 28）、IO 与硬核位置（IO 在 gx81/312、GTX 在 gx0/394）。

**4. 位流结构**：50,176 帧×101 字×32 位、每帧第 50 字 ECC、每 config row 末 2 帧 OVERHEAD、帧块大小不等（CLB 36、INT 26、接口 28）、定位公式 `cell=(block_base+frame_off, word, bit)` 且 `word=2*(Y%50)+parity`（`Y%50≥25` 时 +1）、FAR 与命令层、读回与部分重配置、资源↔帧偏移表。

必须给出"如何从零开始测一个新家族"的完整实验清单：需要几个设计、每个设计改什么、Vivado 侧用哪条 Tcl 属性、如何固定其它变量、diff 窗口如何限定、如何判定失败（给出可观察症状）。

必须显式论证"为何 0 ambiguous 不是采样运气"：给出三种可能的反例形态（同族两源位同置、跨族借位、未覆盖位作乱）及各自的判别信号。

必须给出一个"位集→PIP"的判定算法伪代码，包含一致性检查、歧义检测、以及多 PIP 联合求解的约束表述（互斥 + 覆盖），并说明每种失败模式返回什么。

背景数字（实测，可直接引用但不得篡改）：150,380 tile、86,022 fabric site、1,760 package pin；SLICEL 43,200 + SLICEM 32,700 = 75,900 slice；INT_L/INT_R 各 26,550；CLBLM_R 17,000/CLBLM_L 15,700/CLBLL_L 3,100/CLBLL_R 2,150；BRAM_L 480/BRAM_R 550；DSP_L 770/DSP_R 630；NULL 19,709；VBRK 12,950；单个 INT tile 位池 1,664 位、覆盖 1,598 位、3,636 条 PIP feature、172 家族；1,598/1,598 cell 只属一个家族（0 例跨族共享）；族内 3–18 源/cell（均 5.57，最大 18）；每 PIP 占 1–4 cell；形状 5 类 (9,20)×96、(10,24)×64、(8,16)×6、(7,12)×4、(9,18)×2；(9,20)=4 组×5 成员，位宽 4+5=9；全芯片解码 181 PIP/181 家族/0 ambiguous；写位回环 864/864；未解：CARRY4 CY0、CE/SR/CLKINV、(8,16)/(10,24) 的 4 位编码、BRAM/DSP/IO 跨族独占性、LV/LVB 选择位。

**写作要求：**
- 每条断言必须归入三类之一并显式标注：【硬件事实】/【数据事实】/【推断】；无数据处写"未测"，并给出可执行的测量方法（具体脚本、查哪张表、预期看到什么现象）。
- 每个结论后面必须跟"如何被证伪"或"反例会长什么样"，不允许只给正面证据。
- 明确区分三种"复用"：位级共享（同族内 cell 被多源编码共用）、位模式跨实例复用（相对偏移在不同 tile/band/列/实例重复）、资源复用（布线资源被多网占用，与位流无关）。必须点明资源复用不是本题对象，以免混淆。
- 术语首次出现给英文原文；"家族"必须声明为本项目自定义术语而非 Xilinx 官方术语；BEG→END 的 tileconn 落点是固定连接，不得称为 mux。
- 不得用"通常/一般/大多数"代替具体数字；不得把"未测"当作回避具体分析的挡箭牌。
- 全文中凡出现数字，必须标明来源（哪张表/哪个脚本/哪次实验），不能出现无出处的数字。
- 误区纠正与自测题必须针对解法链的具体环节（如"为什么不能只看置 1 位"、"为什么同族两位必须都看"），禁止泛泛的体系结构常识题。

**输出结构固定为**：① 一分钟速览 ② 物理架构 ③ 位流结构 ④ 家族是什么 ⑤ PIP 复用怎么解（六环解法链）⑥ 完整走查（EL1BEG_N3 实例）⑦ 三类复用的辨析 ⑧ 判据与证伪清单 ⑨ 误解纠正 ≥8 条 ⑩ 自测题 8 道含答案。

**输出前给出自检清单 8 项并逐条勾选**，任何未满足项须显式声明。

## 这一版与之前的提示词差在哪

| # | 变化 | 解决的问题 |
|---|---|---|
| 1 | 从"讲解概念"改成**"三项目标可检验"**（定位资源 / 判定位集 / 设计 fuzz） | 之前的提示词产出容易变成综述，读完不会动手 |
| 2 | 建议解法链每环必须给**≥3 行伪代码**，缺则作废 | 之前最容易糊过去的地方就是"怎么解"只剩一句话 |
| 3 | 家族定义必须是**可计算谓词** `family(f)=(tile_type,destination_wire)` + 一条 pandas/SQL 判定语句 + 反例 | 杜绝"家族就是一组 mux"这种循环定义 |
| 4 | 明确要求**"从零测一个新家族"的实验清单**（几个设计、改哪条 Tcl、diff 窗口、失败症状） | 让"能复现"落在纸面上 |
| 5 | 要求**论证 0 ambiguous 不是运气**，并给三种反例形态与判别信号 | 这是本项目最容易被质疑的结论 |
| 6 | 要求**位集→PIP 的判定伪代码**（一致性/歧义/联合求解/失败模式返回什么） | 把"方法"变成"算法" |
| 7 | **每个数字必须标来源**（表/脚本/实验） | 防止编数字，也方便复核 |
| 8 | 误区与自测题必须**针对解法链环节**，禁常识题 | 自测题要能测出"是否真会解复用" |
