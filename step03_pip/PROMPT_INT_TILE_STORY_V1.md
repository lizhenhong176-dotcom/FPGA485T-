【任务】撰写一份面向导师/学长/答辩听众的「INT tile 的 PIP 复用规律」实验讲解稿，听众关注三点：实验动机如何产生、最终获得哪些可复算结果、过程中遇到并修复了哪些真实问题。

【必须覆盖的三块内容，缺一不可】
1. 实验思路：说明为何选择当前切入点（约束条件为没有位库、没有源码、Vivado 是唯一真值支点）；按 8 步链逐步说明每一步「为什么做 / 如何排除其他可能 / 当时得到什么中间结论」，每一步都需给出可核查的依据或操作痕迹。
2. 最终结果：按分档给出数字（纯公式 77.5%、规则+小表 20.3%、表数据 2.3%，合计 97.7%）；对外部验证四条支路分别给出具体数字，并为每个数字标注可复算入口（脚本名或 SQL/命令）。
3. 中间遇到的问题：至少列出 10 个真实问题，每个问题按固定结构写「症状 / 根因 / 如何发现 / 如何修复 / 如果未发现会得出什么错误结论」；该部分是讲解稿重点，不得写成“顺利推进”的叙事。

【写作纪律（硬规则）】
- 三色标注：【硬件事实】/【数据事实】/【推断】不得混写；无法取得数据的项写「未测」。
- 每个数字必须能指向复算入口（脚本名或 SQL/命令）；给不出复算入口的数字标「未测」并降档为待核。
- 禁止使用「首次 / 唯一 / 完全」这类不可证伪措辞；改为「在 X 范围内、以 Y 为判据」的表述。
- 每个问题必须写出「错误结论」的具体表现（例如「会报某族 100% 检出」），不得写「可能出错」。
- 区分「我算错了」和「工具不提供」；后者需写清是哪个 API/工具、报了什么。
- 排版：每节 ≤60 行，表格优先于长段落；关键结论用粗体一句话表达。
- 输出 Markdown，10 节以内，总长 150–220 行。
