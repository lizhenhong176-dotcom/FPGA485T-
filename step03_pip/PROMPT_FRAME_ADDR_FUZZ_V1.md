请为我的 Virtex-7 (xc7vx485t) 位流逆向项目撰写一份技术讲解文档，主题覆盖「帧结构与寻址 + fuzz 实验流程 + 受控实验纪律 + PIP 复用规律」，并为每个模块配图解。文档面向新人上手培训，读者读完后应能独立完成一次 fuzz 实验并正确判读结果。

## 实测事实参照系（必须原样引用，不得修改任何数字）

1. 器件 485T：50,176 帧 × 每帧 101 个 32 位字 = 5,067,776 字；.bit 文件 20,273,538 字节；同步字 AA995566 位于字节偏移 150；字序为大端；配置区由单次 FDRI burst 写入。
2. 帧块模型：frame_blocks 共 1,038 块 / 36,260 帧 = 7 band × 5,180 帧精确闭合；块尺寸 36（CLB 列）/ 28（BRAM/DSP/接口）/ 72（IO）/ 30（边缘）/ 246（PCIE）。
3. 地址律：frame = block_base + frame_off；word = wof(Y) + parity，wof(y) = 2*(y%50) + (y%50>=25 ? 1 : 0)；bit = raw % 32；Y 取 tile 名的 Y。
4. 位空间：单侧 INT tile 26 帧 × 2 word × 32 bit = 1,664 位，1,598 位有主（96.03%）；172 个家族；每源 2 位（段族）或 5 位（IMUX/BYP/FAN/GCLK/CTRL/GFAN）。
5. 复用规律：家族 = (tile_type, 目标 wire)；同族内 N 个互斥源共享 k 个 cell，跨族零共享（1,598/1,598）；N = a×b、k = a+b；5 位族 = 1 位隐式组选 + 4 位显式成员选（成员四条全写，选中 1 其余 3 个明确 0），2 位族两级都隐式。
6. 受控纪律：单变量、同 LOC 只改一参、双位置交集、负对照、差分语义声明（PURE/XOR/FAM）、绝对态判读、大端自检 FDRI burst = 50,176×101、写回 864/864、DRC 豁免清单、locale 环境变量。

## 文档结构与格式要求

- 约 9 章，每章配图解（ASCII 图或表格）；全文至少 3 张 ASCII 结构图 + 1 张可渲染图。
- **每一章必须按「输入 → 操作 → 输出 → 判据」四段式组织**；其中「判据」必须写成"若 X 则判定失败"的可证伪形式。
- 每节用【实测】/【推断】/【未测】三色标注；**全文禁止出现没有三色标注的技术断言**。
- **全文禁止使用「通常/一般/大概」这类模糊词代替数字**；凡涉及数字必须给出明确数值。
- 每个数字标注出处（表名、报告编号或脚本路径）。
- **帧结构章必须给出完整手算示例**：给定 tile 名 `INT_L_X6Y11`、片内行号 Y=11、parity=1、bit=7，逐步算出绝对帧号/字号/位号，每一步标注三色并注明出处。
- **fuzz 流程章必须给出完整脚本骨架**（远端构建 + 差分 + 判读），并附「常见报错 → 根因 → 修法」表，至少 6 行。
- **复用规律章必须给出可复算公式**（N、k、a、b 的关系）与至少两个反例：一个"看似共享但实际不共享"、一个"看似 2 位实际 5 位"。
- 含「为什么这样设计能保证受控」证伪分析，列出会毁掉实验的 5 种做法（每条以"若 X 则判定失败"形式表述）。
- 含可操作的新人上手流程（环境准备 → 跑一次 fuzz → 判读），每步同样按四段式组织。
