> **三句话结论**
> - 别人做到哪：公开工作在「单个 PIP → 位」这一层有产物（prjxray 逐 PIP 枚举表），但 XC7VX485T 的该层产物在其导出里标注 missing；「哪个位被哪些 PIP 共用」这一层**没有公开产物**。
> - 我们能到哪：L1 能力（查/生成/对账/检出）已有分子分母，够写工具或数据集短文；正刊长文要过 L2 的四件事。
> - 论文怎么定位：写「复用结构 + 生成器 + 独立验证」这三件，不写「首次」「通用规律」；负面结果照写。

## 一、三句话结论
① 别人在「单个 PIP → 位」有产物（prjxray 枚举表），在「位 → 复用结构」没有公开产物；② 我们的查询/生成/对账/检出四项已有分子分母，L2 需【推断】10–15 人日、L3 需板卡；③ 论文写「复用结构 + 生成器 + 独立验证」三件，负面结果照写，不写通用性与功能验证。

### L2 短期（3–6 周，全本地）
- 效果：可以对外说「这套方法在一类 tile 上闭合，并给出可复算的验证协议」。
- 还差：长线 82 条闭合；再补 2 种 tile 类型（目标 `HCLK_CMT`、`CLK_HROW_*`）；artix7 同任务对照；误报标定流程化（当前 120/982 tile = 12.22% 需白名单）。
- 工作量：【推断】约 10–15 人日。
- **判定条件**（【推断】阈值）：82 条闭合到 ≥80，且新增 2 类型各有 ≥1 个可复算判据；否则只能说 L1。
### L3 需硬件 / 更长周期
- 效果：可生成可加载位流并上板跑通，够投正刊长文。
- 还差：校验字与帧地址耦合闭合（`ECC = L(data) ⊕ A(frame_addr)`，`A` 未定）。
- 工作量：【推断】5–7 人日 + 板卡。
- **判定条件**：生成的位流能被 Vivado 硬件管理器加载且回读一致。
### 能力矩阵

### 达不到的
- **不得写「通用跨家族规律」**：当前 2/115 tile 类型、单器件、跨器件 0/1。
- **不得写「能验功能一致性」**（【硬件事实】配置位只控制布线连接，不描述逻辑功能）：【数据事实】把 24 个 LUT6 的 INIT 全改后重生成位流，与真值差 1,092 位、落在建模区 **0** 个、982/982 个 tile 的连线集合相同、检测器 0 报警（`tamper/delta_init.json`）——这是方法的**结构边界**，不是实现缺陷。

## 四、论文写什么
### 三个备选标题
1. 数据驱动：*「XC7VX485T 互连 PIP 位库的复用结构与可复算验证」* —— 承诺数据与复算协议；不承诺通用性。
2. 工具/生成器：*「从复用结构生成互连位库：一个 6×10² 常数替代 8,900 条记录的方法」* —— 承诺压缩与生成器；不承诺解码歧义为零。
3. 方法学：*「如何证明你的位库不是抄来的：四类独立验证支路」* —— 承诺验证协议；不承诺覆盖全部 tile 类型。

### 与 prjxray 的差别是形式还是信息量
- 若只是**形式差异**：写成「把已有的逐 PIP 枚举表重排为常数表 + 生成器」，降级为工程整理，代价是不能声称方法学贡献，只能投工具/数据集短文。
- 若含**信息量差异**：必须拿出可比数字——【推断】prjxray 的 `segbits_int_l.db` 每行给一条 PIP 的位，行数等于 PIP 数；我们的表给 1,598 位 + 172 族参数，可由名字生成 3,634 条中的 3,456 条（95.1%），信息量的差别体现在「生成」而非「记录」。这条写法要求先完成 L2 的 artix7 同任务对照。

### 不能写的三类表述
（下表左列是**反例**，其中的「首次」「完全」仅作错误示范引用，不是本文断言。）
- ❌「这是首次给出 485T 的互连位库」→ 应写「在本地公开导出中该层标注为 missing」。
- ❌「完全覆盖全部 tile 类型」→ 应写「当前 2/115 类型，其余未测」。
- ❌「可验证电路功能正确性」→ 应写「只能判定结构合法性，功能篡改结构上不可见」。

**5 条审稿人最可能问 + 一句话怎么答 + 需要哪份材料**
1. 你的位库怎么证明不是从别人的表里抄的？——「四类独立支路：器件模型一致性 115/115、Vivado `get_pips` 1,155/1,263、全器件表外位 0（12,565 tile / 64,686 位）、改一个属性重生成 50,176 帧全等。」材料：`PIP_BIT_REUSE_REPORT.md` 的 E1–E8。
2. 单器件单类型凭什么叫规律？——「我们只声称该类型内成立；跨类型与跨器件在文中明确写为未测（2/115、0/1）。」材料：`PIP_PROGRESS_20261108.md` 缺口账。
3. 检不出功能篡改是否说明方法没用？——「适用域是布线结构；功能篡改不影响任何布线位，这是结构边界的必然结果，也说明这类检测必须另配功能级手段。」材料：`tamper/delta_init.json`。
4. 你的差异检测是否只是启发式？——「检测用两条可证伪不变量（槽位最多一热、码只取 {1,2,7,11}），在 231,656 个真实槽位上 0 违例。」材料：`tamper_localize.py --check`。
5. 95.1% 里有多少是自证循环？——「生成器只用族名与源名，输入不含位表；验证用真值与独立不变量。」材料：`gen_slots.py` 与 `_q_verify_pips_after.py` 的输入清单。
