# P1 级补强：12 个独立设计上的位级复现与真值对账（2026-11-15）

> 【数据事实】本文所有数字均由第 7 节命令在本机复算得出。
> 【硬件事实】标记物理结构（如开关盒内 mux 互斥、直通无选择位）。
> 【推断】标记尚无直接测量支撑的解释。

## 0. 一句话结论

**12 个结构互不相同的新设计、844 个活跃 INT tile**：用「位坐标 + 精确覆盖解码」重建的 PIP 集合
与 Vivado `get_pips` 真值对账 —— **精确率 100%（FP = 0）**、**可检出行召回 100%（5,940/5,940）**、
**844/844 tile 全部唯一解**。未检出的 1,400 行**全部**是结构上就没有配置位的行
（775 行扇入=1 直通、625 行常量源），**真漏 0**。

## 1. 为什么需要这一步

G2 只在**一个**设计（`tamper/ref/ref.bit`）上做过对账。审稿意见 P1-1 指出：单设计无法排除
"该设计恰好只用到模型覆盖到的那部分 mux"。本步用 12 个刻意拉开维度（规模 16→96 个 LUT、
布局单列→跨全部列、结构链/树/扇出/移位寄存器/累加器、密集与分散）的新设计来补。

## 3. 判据（与 G2 完全一致）

1. 位流 → 每帧 101 字；按 `word = 2·(Y%50)+parity`（≥50 则 +1，**跳过 word 50 的 ECC**）
   把位分给该列该行带的那一个 tile（**一帧被同一 `(band,col)` 的 50 个 tile 共享，必须按 word → row 分配**）。
2. 观测集 `obs` = 该 tile 的 `(frame_off, bit, parity)`；去掉 3 个已知标记格 `(1,0,0)/(1,1,0)/(0,16,1)` 得 `target`。
3. 候选 = 全部格都落在 `obs` 内的 feature（3,634 条模型）；穷尽枚举 `S ⊆ 候选` 使 `union(S) == target`；**恰 1 解**才算唯一。
4. 对账：解出的 `(dst, src)` 与真值集合比对，算 TP/FP/FN。

**唯一放宽（明示）**：`target` 中**任何候选都覆盖不到**的格（模型外位，实测全部落在 `frame_off 0..2`
的时钟字段区，属 GCLK 时钟网选择位）单列为 `outside_bits` 后从 `target` 剔除再求解。
合计 **164 个表外位**（只在 `d3_carry` 98、`d5_srl` 64、`d11_mix` 2）；不剔除时这些 tile 会判「零解」。

## 5. 那 1,400 行没检出的是什么（逐条归因，`out/p1_residual.json`）

| 类别 | 行数 | 为什么不占配置位 | 判定 |
|---|---|---|---|
| 扇入 = 1 直通 | 775 | 目的 wire 只有一个候选源，`pip_defs` 里是固定连接，**无选择位** | 【数据事实】G1 已证 44 条直通无位，本步在 12 个设计的实例级再次验证 |
| 常量源 | 625 | 目的 wire 由 `VCC_WIRE` / `GND_WIRE` 常量驱动，**没有可编程连接** | 【硬件事实】结构上不可检出 |
| **真漏** | **0** | — | — |

- 归因合计 775 + 625 = **1,400 = 全部 FN**，`misses` 列表为空。
- 因此 **可检出召回 = 5,940/5,940 = 100%**；表中 0.8093 是对「全部真值行」算的，
  分母含 1,400 行结构上无位的连接 —— 两个数必须分开报。

## 6. 这一步证明了什么、没证明什么

**证明了**（可复算）：
1. 【数据事实】同一套判据在 12 个不同结构的设计上**零误报**（FP = 0）；
2. 【数据事实】844 个活跃 tile **全部唯一解**，说明位集对源的区分能力不依赖单设计的运气；
3. 【数据事实】所有未检出行都能归因到「无位」而非「有位但解错」；
4. 【数据事实】连长线密集设计（`d10_long` 横跨最远列）与超高扇出（`d12_fanout2`）也零误报，
   这两个设计恰好压到了模型里最难的那几条族。

**没有证明**：
1. 仍是**单器件**（`xc7vx485tffg1761-2`）、**单类型**（INT_L/INT_R，2/115）——跨器件/跨类型仍是 0；
2. 真值是 Vivado 自己从网表与布线导出的，**不是硅片回读**；它只能证明「解码与工具一致」，
   不能证明「工具与硅片一致」（后者需上板回读）；
3. 表外 164 个位（GCLK 时钟选择）仍属未建模区，本步只是剔除并单独计数，没有解释其编码；
4. 12 个设计都是**小规模、单时钟、无 BRAM/DSP 实例**，不覆盖 block1 的资源。
