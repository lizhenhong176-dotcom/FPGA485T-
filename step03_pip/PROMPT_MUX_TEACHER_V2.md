- 每条控制措施对应的错误结论须具体到“会误判成什么”或“会漏掉什么”。

3）用了 Vivado 的哪些文件、为什么：必须给出一张表，列固定为「文件 / 谁产生 / 在这次实验里干什么 / 为什么必须用它 / 不用会怎样」。表中必须覆盖以下条目，且每条的“为什么必须用它”和“不用会怎样”不得为空：
