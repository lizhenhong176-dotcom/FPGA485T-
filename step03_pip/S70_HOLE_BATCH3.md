# S70 · 66 格第三批：CE/R 来源位与 latch/muxf7 归属（两位置交集）

日期：2026-11-12　远端 `/opt/lzh/step19/hc/`　差分脚本 `hdiff3.py` / `hdiff4.py`
基线：`plain_x10`(SLICE_X10Y20, wof=40) / `plain_x6`(SLICE_X6Y11, wof=22)，均 LUT6+FDRE

## 1. 结果（两位置完全一致）

| 设计 | 唯一变量 | 命中的 66 格 |
|---|---|---|
| `ce_port` | FDRE `.CE(ce)` 接端口（原为 `1'b1`）| **`(1,1,7)`** |
| `rst_port` | FDRE `.R(rst)` 接端口（原为 `1'b0`）| **`(1,1,3)`** |
| `fdce` | FDRE → `FDCE`，`.CLR(1'b1)` | `(0,1,16)(1,1,3)` |
| `fdpe` | FDRE → `FDPE`，`.PRE(1'b1)` | `(0,1,16)(1,0,7)(1,1,3)` |
| `muxf7` | 两 LUT6 → `MUXF7`（原直驱 FF）| `(0,1,16)(1,0,7)` |
| `latch` | FDRE → `LD` 锁存器 | `(0,1,16)(1,0,7)(1,1,19)` |

## 2. 归属判定

| 坐标 | 归属 | 依据 |
|---|---|---|
| `(1,1,7)` | **`CE_SOURCE_FABRIC`** | 只在 CE 从恒 1 改成 fabric 网时出现（4 个 FF 设计里唯一变化位）⇒ **S52 命名得证** |
| `(1,1,3)` | **`SR_USED`**（异步清/置被使能，不分常量或端口）| `rst_port`、`fdce`(CLR=1)、`fdpe`(PRE=1) 三者都命中；`plain`（R=1'b0）不命中 |
| `(1,1,19)` | **`CARRY4 或 LATCH 的组合路径标记`**【待细分】| 本轮 `LD` 命中、S69 `CARRY4` 命中；两者都绕过 D 触发器边沿 |
| `(0,1,16)` | **`SLICE_USED`（通用）** | 6/6 设计全命中 |
| `(1,0,7)` | **`LUT_OUT_USED`（通用）** | 用了 LUT 的 4 个设计命中；`fdce`（D 直接来自端口、无 LUT）不命中 ⇒ 与 S69 一致 |

## 3. 修正 S69

S69 把 `(1,1,19)` 记为「CARRY4 使用标记」**过窄**：本轮 `LD` 锁存器同样命中。正确表述是「**CARRY4 或 LD 这类非边沿组合路径在用**」。要区分二者需另做探针（例：CARRY4 只观察 COUT 不驱动任何 FF vs LD 的 Q 悬空），或接受“同类标记”的合并语义。

## 4. 剩余未归属（12 个已点亮坐标）

`(1,1,30)`（1,284 次，无任何探针命中）、`(1,0,31)`（192）、`(0,1,31)`（40）、`(1,1,15)`（93，= `C5FF`）、`(1,1,23)`（93，= `D5FF`）、`(1,1,11)`、`(1,1,19)`（已归属同类）、`(0,1,8)`、`(0,1,20)`、`(1,0,27)`、`(0,0,16)`、`(1,0,3)`。

- `(1,1,15)`/`(1,1,23)` 已有 CLB 表映射（`C5FF`/`D5FF`），缺 V7 实测；
- `(1,1,30)` 是全表最高频却无任何探针命中 ⇒ 与具体功能无关，可能是 bitgen 的固定填充或与“列位置/象限”有关（建议用同一功能、不同 X 列的两位置对比）。
