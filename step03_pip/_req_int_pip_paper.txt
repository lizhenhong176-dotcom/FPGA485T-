我要评估一件事，需要你做对抗式判断，不要给我鼓励。

背景：我在 XC7VX485T-2FFG1761（VC707）上做比特流逆向，只做 INT tile（INT_L / INT_R 各 26,550 个实例）的 PIP 选择位。
已经拿到的（都是可复算数据，不是设想）：
- 一个 INT tile 有 600 wire、3,737 条 PIP、216 个目的 wire；172 个目的 wire 扇入>1（3,693 条 PIP），44 条扇入=1 直通；3,634 = 3,693 − 59 个 VCC_WIRE 常量输入。
- 172 个「族」（= 一个目的 wire 的全部候选源），共 3,634 条 feature、1,598 个不同配置位，每 feature 平均 2.45 格、每格被 5.57 个 feature 共用。
- 七种列重谱型覆盖 172/172 族；乘积结构（组轴×码轴）在 163/172 族成立；族内每源 pattern 172/172 互不相同；族内严格子集对 1,632；跨族共享位只有 3/1,598。
- 生成器：mux 侧 64 族（24 源，6 行×4 码，合法码 {1,2,7,11}，16 种配置每种 4 族）64/64 位级 0 差异；BEG 侧 96 族（20 源，完全二分 K(5,4)/K(4,5)）96/96 位级 0 差异（含 32 个变体族的方向桶表 + 4 行长线表）。
- 到目前为止：公式档 3,456/3,634 = 95.1%；剩 96 条靠复合族组模型（表）、82 条（6 个长线族）未解。
- 地址侧：band = FAR 的 (block, top, row)，col = FAR column，frame = far_bands[(band,col)].start_frame + frame_off，word = 2*(Y%50)+parity（≥50 则 +1 跳过 word 50 的 ECC 字）；INT tile 的位池是 26 帧 × 2 parity × 32 bit。
- 独立验证：位流差分 1,536/1,536 PIP 一致；线长编码律 5,832/5,832 全中；解码器在真实设计上解出 1,155/1,263 = 91.45% 的真值 PIP。
- 公开对照：Project X-Ray / F4PGA 的 segbits 是逐 PIP 枚举表（形如 INT_L.<dst>.<src> 07_32 12_33，! 表示须为 0），且 vx485t 无公开 segbits（我自己的导出 manifest 里 missing 明写 needs fuzz results）。
