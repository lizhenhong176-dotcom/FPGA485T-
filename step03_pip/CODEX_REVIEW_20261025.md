## 1. 已立住结论的强度评分

| 条目 | 评分 | 反例风险 | 最小补证实验 |
|---|---|---|---|
| 帧 ↔ FAR 映射 | **强**（对已解析的 50,148 块） | 28 个未解析块可能含特殊帧；解析器若漏一次字对齐，后续映射整体偏移 | 用第二份独立 bitstream 重做解析，专核对 28 个开销帧、FAR 跳变与首尾帧 |
| PIP → bit（IMUX） | **强**（对已覆盖的 IMUX、INT_L/R 范围） | 864/864 主要集中在偶数列与已知 mux；未证明奇数列、其他 INT 形状、非 IMUX PIP | 在奇数列、不同 row、INT_L/R 各取未见过的 PIP 做单变体+写回比较，至少一半留作盲测 |
| 跨实例 / 跨类型 | **中** | 归一化可能掩盖列奇偶/方向/局部布局；已有 {19,21,22,24} 与 {17,21,24,25} 冲突 | 偶/奇各 2 列、L/R 各 2 实例、覆盖两个 row 带做完整形状交叉表；若两套形状则保留分支模型 |
| LUT6 INIT 位映射 | **强**（对 X10Y10 A6LUT） | 只有一个 BEL、一个位置；SLICEL/SLICEM、A/B/C/D LUT、不同列可能有独立排列 | 2 个 SLICEL + 2 个 SLICEM，覆盖 A/B/C/D LUT，每位置验低位/高位/跨 word，至少两个位置做完整 64 位复核 |
| 帧级 ECC | **强**（对当前帧格式与采样范围） | 54 位置拟合受变体分布限制；多 word 同时变化、边界 word、ECC 位自身变化未证 | 随机多 word 多 bit 组合，覆盖 word 0/49/99 与 ECC 附近，要求逐帧完全预测 |
| 块地址函数 | **弱**（只能证明 3 列上的局部规律） | 三点不足以定函数；有 row/region 跳变；LC/BRAM/DSP 很可能不同地址空间 | 建「列 × row 带 × tile 类型」FAR 锚点表，每 row 带与每 tile 类型至少一个；有跳变就改分段映射 |

结论：第 2、4、5 条可直接支撑局部编码器；第 3、6 条不能支撑器件级泛化。

## 2. CRC 新假设（按可证伪性排序）

| # | 假设 | 无 JTAG 判定方法 | 证伪条件 |
|---|---|---|---|
| 1 | 尾部两值是模板残留/工具元数据/固定哨兵，不是载荷 CRC | 多份逻辑不同、帧内容不同的 bitstream 比较两尾值；检查无逻辑变化的重复构建是否稳定 | 载荷变化时尾值稳定不变 → 基本证实；稳定随载荷变化 → 证伪 |
| 2 | CRC 覆盖完整配置 packet 而非裸 FDRI 数据 | 保持帧载荷不变，改 NOP/packet 分段/计数值/寄存器地址；再反向改载荷保持 packet 结构 | 只有载荷变化影响尾值、packet 结构无影响 → 证伪 |
| 3 | 两值属不同阶段：一个覆盖主体，一个覆盖收尾序列 | 分别只改前缀、FDRI 主体、第二个 CRC 写入前的尾部命令，看 crc1/crc2 是否分离响应 | 任意位置变化总同步改两个值 → 阶段划分不成立 |
| 4 | 这是 7 系列 CRC 寄存器状态，不是普通文件 CRC | 按 packet 顺序重放寄存器写入/FAR/FDRI/CRC reset/seed 与尾部写入；≥20 单点 + ≥10 多点变体差分验证 | 找不到固定 seed/位序/寄存器范围/更新时机，或盲测 1 个以上不匹配 |
| 5 | CRC 输入含 FAR、命令头与帧顺序 | 「改地址不改数据」「改数据不改 FAR」两组实验 | 仅数据变化且完全可解释 → 证伪 |
| 6 | 计算对象是压缩前/解压后的逻辑数据 | 同一设计开/关压缩生成 bitstream，比载荷、packet、尾值 | 尾值严格跟随物理 packet → 证伪 |
| 7 | crc2 依赖 crc1/packet 计数/前一个 CRC 写入 | 离线 packet 变体：只改第一个 CRC 的数据、计数值、填充区 | crc2 完全不敏感 → 证伪；呈稳定线性可继续建模 |
| 8 | 尾值是认证/签名/随机化，不是线性 CRC | 跨 bitstream 确定性、单 bit 差分稳定性、重复构建一致性、avalanche | 同输入不同输出或差分无稳定结构 → 停止 CRC 方向，标记「不可验证尾部」 |

关键提醒：现有「相邻帧增量不满足固定线性变换」只排除了**窄的普通位置型 CRC 模型**，不能排除 packet 状态机、FAR 状态、阶段性 reset 或 CRC 寄存器语义。

## 3. 两周分阶段计划

**D1–D2 证据冻结与可复现性**
产出：基准/变体/载荷/尾部哈希清单；packet–FAR–frame 三层解析表；六条结论的覆盖范围与盲测集合；远端目录时间线（标记可能被其他进程污染的数据）。
失败即停：864/864 或 64/64 基准无法重复；packet 边界/帧数/ECC 解析不确定；远端数据无法区分来源。

**D3–D4 CRC 快速判定**
产出：20–30 个成对变体；「载荷/packet/前缀/后缀/压缩/CRC1/CRC2」影响矩阵；可重复模型 或 明确的「不可解释」结论。
失败即停：30 个受控样本无模型；尾值对同输入不稳定；只能靠 JTAG 才能继续。此后 CRC 不作为硬门槛，改为「保留原尾值 + 离线标记未验证」。

**D5–D7 FAR 与块地址地图**
产出：列 × row 带 × tile 类型 → FAR 的分段映射；明确记录跳变点；INT/CLB/BRAM/DSP 各至少一个锚点。
失败即停：≥12 个受控锚点仍分不清 row 带；同实例重复解析 FAR 不同；只能依赖被污染的远端目录。

**D8–D10 PIP 泛化与奇偶列**
产出：偶/奇列、L/R 的分层形状模型；未见实例盲测；覆盖率与误差清单。
失败即停：两轮盲测后仍有多个未解释形状；归一化误差 >1 bit；变体常触发额外布局变化。此时保留多模型，放弃全器件统一公式。

**D11–D12 BEL 位图扩展**（顺序：FF INIT/SRVAL → CE/SR/CLK → CARRY → SLICEM 分布式 RAM）
产出：每类单点变体表；数据位/ECC 位分离规则；每类一个 holdout。
失败即停：关优化后单点改动仍引起不可控多资源变化；同 BEL 单点变体无法稳定复现；两轮 bit 位置不一致。

**D13–D14 集成与交付边界**
产出：逻辑改动 → 帧/word/bit/ECC 的端到端预测报告；CRC 三态（已解/保留/不可验证）；按实例、tile 类型、列奇偶、row 带的覆盖矩阵；下一阶段只保留能过盲测的项。
失败即停：任一「强」结论在盲测中系统性出错；局部改动引起无法解释的大范围变化；尾部处理破坏可比性。

## 4. 应放弃或严格限时

- 继续穷举常见 CRC-32 变体（已有充分负结果），只保留 packet 状态机与 CRC 寄存器两类结构化假设。
- 把 JTAG 可用性作为近期前提；所有结论限定为离线证据。
- 地址模型稳定前全面覆盖所有 tile 类型。
- 强行寻找统一跨列形状公式（已有奇偶列反例），改分层模型。
- 短期穷举所有 BEL 属性；先做 FF 与时钟控制等高复用项。
- 逆向 28 个开销帧的全部语义；能可靠跳过并保持帧边界即可。
- 承诺「任意逻辑改动都能预测」；两周目标收缩为经盲测的 INT/PIP、LUT、部分 FF 与明确地址范围。
