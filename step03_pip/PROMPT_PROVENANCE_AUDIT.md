# 提示词：位流原理的出处追溯与证据强度审计

> 生成流程：`optimize-user-prompt`(user-prompt-professional) → `iterate-prompt`(iterate, 7 条加固)
> 目的：回答"这些原理**来自哪里**、有什么**实验数据**支撑"，并强制把"凭记忆"与"可核验出处"分开，
> 产出可直接引用的证据台账（含置信度分级、可复算打分、反例实验）。

---

你是 FPGA 位流逆向的“证据审计员”。你的任务不是解释原理，而是对下列每一条原理/结论逐条做**出处追溯 + 证据强度定级**，并按指定结构输出审计结果。

【防编造条款（最高优先级）】
- 如果你不记得具体的 UG470 章节号或表号，必须写“章节号不确定，不可核”，并将该条置信度降为 E。
- 严禁编造一个看起来合理的表号、章节号、页码或文件名来填补空缺；宁可写“**不可核**”，也不得虚构。
- 任何被判定为编造的定位，一律按审计失败处理。

【审计对象：xc7vx485tffg1761-2 的 13 条陈述】
1. 同步字 0xAA995566
2. Type1/Type2 包头位域：[31:29]=type、[28:27]=op、[26:13]=寄存器地址、[10:0]=字数；type2 用 [26:0]=字数
3. 寄存器地址：0x00 CRC、0x01 FAR、0x02 FDRI、0x04 CMD、0x05 CTL0、0x06 MASK、0x09 COR0、0x0C IDCODE、0x0E COR1、0x10 WBSTAR、0x11 TIMER、0x18 CTL1
4. CMD 命令码：WCFG=0x01、LFRM=0x03、START=0x05、RCRC=0x07、AGHIGH=0x0A、SHUTDOWN=0x0D
5. IDCODE 0x03687093 = xc7vx485t
6. FAR 自增，因此整片配置可由一次 FDRI 突发写完（实测 5,067,776 字 = 50,176×101）
7. 7 系列一帧 = 101 字 × 32 位
8. 485T 共 50,176 帧
9. 块基址：CLB tile 占 36 帧、INT tile 占 28 帧、接口列 28 帧
10. 行内字规则 word = 2*(Y%50) + (1 if Y%50>=25 else 0) + parity
11. CLB 块内字段偏移：INIT 在 +32..35、FF 在 +30..31、IMUX 在 +16..25
12. INT 家族位池：1,598 cell / 172 家族 / 同族 3..18 源共享 / 跨族零共享
13. word 50 不是每帧 ECC（实测 50,176 帧中仅 157 帧非零）

【每条陈述必须区分两个归属栏】
必须分别标注属于：
- “485T 专属结论”：仅对 xc7vx485tffg1761-2 成立或仅由该器件实测得出；
- “7 系列通用结论”：对整个 7 系列（含 UG470 文档定义）成立。
若同时涉及两层，必须拆开说明；严禁把 485T 实测数据当作 7 系列通用结论引用。

【对每一条必须给出六项 A—F】
A. 出处：必须具体到 UG470 章节号+表号、prjxray 仓库路径+文件名、论文 DOI，或“本项目实测”；
B. 出处性质：厂商文档 / 开源项目实测 / 学术论文 / 博客论坛 / 无出处（凭记忆）；
C. 可核验定位：表号/文件名/页码/commit 至少一项；给不出必须写“**不可核**”（如适用，写明“章节号不确定”）；
D. 本项目支撑数据：具体数字 + 生成脚本路径或命令行 + 可证伪的失败条件；
E. 置信度：A=文档明确定义 / B=文档间接+实测吻合 / C=仅社区实测 / D=仅本项目实测无外部对照 / E=推断或未测（含任何“不可核”“章节号不确定”的条目）；
F. 反例检验：能推翻该条的最小实验，需可在无板卡机器上运行（写明输入、执行方式、判定阈值/现象，并写明所需工具：Vivado 版本 / Python 库及版本 / prjxray 命令）。

【证据强度打分规则（必须可复算）】
- 有具体表号/章节号/文件路径 + 与本项目实测吻合 = 5 分
- 有具体表号/章节号/文件路径但无实测、或文档间接+实测吻合 = 3 分
- 只有本项目实测、无外部对照 = 2 分
- 仅社区实测或推断 = 1 分
- 无出处/凭记忆/不可核 = 0 分
总判定表须**按分数从高到低排序**，并列出每条的得分组成，便于复算。

【输出结构：严格 7 部分】
① 总判定表（列：陈述 / 485T专属或7系列通用 / 出处 / 性质 / 置信度 / 证据强度得分 / 本项目证据强度 / 反例实验），按证据强度得分降序。
② 逐条展开（每条 ≤200 字，必须含可核验定位，给不出写“**不可核**”；同时标明归属栏）。
③ 出处冲突清单（文档与实测不一致处；无则写“无”）。
④ 记忆风险声明（逐条列编号：哪些无法给出可核验定位，并声明其置信度已降 E）。
⑤ 实验数据附录（本项目原始数字 + 产物路径，路径要能落到具体文件；附每条证据强度打分的分项口径）。
⑥ 证据缺口与补测清单（按“能推翻最多结论”降序，写明补测目标与预期影响）。其中**第 12、13 条为本项目独有结论，必须单列“外部对照缺失”说明并给替代验证途径**。
⑦ 结论（白名单：可直接引用的编号；灰名单：必须标“未核”的编号；并给出“如果只能补一个实验，补哪个”的一句话建议）。
