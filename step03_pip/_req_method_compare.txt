主题：为一篇「Xilinx 7 系列 INT tile 配置位复用规律」的研究，写一份「实验思路构建 + 与已有工作对比优势」的说明文（给导师/审稿人看）。

读者：懂 FPGA 但不熟悉比特流逆向的导师；以及可能质疑「这不就是 prjxray 做的事」的审稿人。

必须写清的两块：
1) 实验思路是怎么一步步构建出来的（不是罗列结果，而是：每遇到什么问题 → 设计什么受控实验 → 得到什么判据 → 下一步为什么这样走）。要包含关键的「差点走错」与自我更正。

必须遵守的硬规则：

可用素材（真实、已核实）：
- 器件：XC7VX485T-2FFG1761（VC707）；INT_L/INT_R 各 26,550 实例；每 tile 600 wire、3,737 PIP、216 个目的 wire，其中 172 个目的 wire 是多源 mux（3,693 PIP）+ 44 条直通。
- law_cells：每侧 172 族 / sense=1 8,900 行 / 3,634 feature / 1,598 个不同位格；2.45 位/连接、5.57 引用/位、2.27 连接/位（压缩比）。
- 复用四层：位级(1,598 格承载 3,634 连接) / 族级(6 行×4 码，合法码 {1,2,7,11}) / 跨族(3/1,598 共享) / 跨 tile(26,550 实例同一张表)。
- 地址链：frame = far_bands[(band,col)].start_frame + frame_off；word = 2*(Y%50)+parity（≥50 则 +1 跳过 ECC 字）；far_bands 1,078 行 = 7 band × 154 列。
- 生成器：gen_mux.py 64/64 族逐位 0 差异；gen_slots.py mux 64/64 + BEG 96/96（变体 32/32）+ 复合组模型 96/96 = 3,552/3,634 = 97.7%；剩 82 条（6 个长线族）判为逐族表数据。
- 外部校验：与 Vivado 真值 1,155/1,263 = 91.45%；不变量 231,656 槽位 0 违例；全器件扫描 12,565 tile / 64,686 位表外 0；FASM 重生成与 Vivado 产物 50,176 帧全等（只差时间戳与尾部 CRC）。
- 跨类型：INT（2 类，全族）、HCLK_CMT（结构：1 组槽位 + 2..4 码字，位池在相邻逻辑列块尾帧 minor 26..29）、CLK_HROW（32 个 GCLK 局部编码 19/32 实测 + 公式；30 个 CK_IN 源为默认通路，25 个设计零反例）→ 3/115 类型。
- 走错与更正（必须写）：①把 law_cells 的 sense=0 行混算，得出「70/172 族 4:1 合并、平均 3.35 格」，后按 sense=1 复核推翻（真值 172/172 族内唯一、2.45 格/连接）；②INT_R 覆盖率一度只有 63.6%，原因是左右侧线名不对称（IMUX_L40 vs IMUX40），归一化后 100%；③篡改检测器一度报「幽灵 mux 100% 检出」，原因是没减基线（120 个 tile 有两格标记位），修正后为 0/300；④「2 格歧义是信息论下界」被精确覆盖枚举推翻（1,066/1,066 tile 单解）；⑤far_bands 只有 128 列是因为导出代码把 10 位列字段截成 7 位，补成 154 列后覆盖从 45.25% 升到 54.49%。
- 对照工作：prjxray/F4PGA 的 segbits 是逐 PIP 枚举表（`<tile>.<dst>.<src> <frame_off>_<bit>`，`!` 表示须为 0），vx485t 无公开 segbits；RapidWright 提供器件模型/PIP 图（xc7vx485t_db.dat 3,625,305 B），不给配置位；Williams & Collier, NAECON 2023（5 页，识别比特流逆向的不确定性来源，无位库无编码律，未读正文）；Moraitis 等 ACM 2021（比特流修改，只知题名）。
