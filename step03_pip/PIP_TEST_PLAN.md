## 五、这套方案证明不了什么

1. **【推断】证明不了「能生成可加载位流」**：ECC 地址项未闭合（`ECC = L(data) ⊕ A(frame_addr)`，`A` 未定），所有关于「改完能烧」的说法都不成立。
2. **【推断】证明不了跨器件**：只有 485T 一个器件，跨器件 0/1。
3. **【推断】证明不了跨 tile 类型**：位库只覆盖 INT_L/INT_R（2/115 类型），按 PIP 数 21.3%。
4. **【推断】证明不了「抗真实攻击者」**：L4 的对抗层是针对「结构自洽」的检测；攻击者若重算 ECC、或只做 LUT 功能改动（实测 1,092 bit 全落在建模区外），本方案 0 报警。
5. **【推断】证明不了真值一致率可外推**：91.45% 来自 1 个设计、982 个 tile。
6. **【推断】证明不了源级唯一性在别的模型口径下成立**：1,066/1,066 依赖 3,634 feature 这一侧的模型；模型缺项会改变结论。
7. **【推断】证明不了与 prjxray 的差异**：同任务横评 0/1，只能从形态上说「它给枚举表、我给生成器」。
