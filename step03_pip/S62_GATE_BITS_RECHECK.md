# S62 · S52 门控位用「双位置交集法」复核

日期：2026-11-11　设备：xc7vx485tffg1157-3　方法：S61 确立的「同一 LOC 只改一参数 + 第二个 LOC 复跑取交集」

## 1. 实验组

三个成对实验，每个都做两组（`SLICE_X8Y11` base 31680 / wof 22；`SLICE_X10Y20` base 31716 / wof 40），
把结果归一化到 `(frame−block_base, word−wof(Y), bit)` 之后再求交集。

| 组 | A | B | 唯一变量 |
|---|---|---|---|
| **CE** | `CE=1'b1` | `CE=ce`（端口） | CE 来源 |
| **FF** | 纯 LUT6 → o | LUT6 → FDRE(CE=1,R=0) → o | 有没有寄存器 |
| **SR** | `FDRE R=1'b0` | `FDRE R=rst`（端口） | R 来源 |

## 2. 结果

### CE 组（交集 5 格）

```
(0, 0, 14)  (0, 0, 17)  (1, 1, 7)  (21, 1, 0)  (25, 1, 0)
```
- `(1,1,7)` = S52 命名的 **CE_SOURCE_FABRIC** ✓ **确认**（两组都出现）；
- `(21,1,0)`、`(25,1,0)` 在 offset 16..25 的 IMUX 区 ⇒ 是 **CE 网的 IMUX 选择位**；
- `(0,0,14)`、`(0,0,17)` 是 CE 通路上的**门控位**（S52 未命名）。

### FF 组（交集 23 格）

```
(0,0,27) (0,1,16) (1,0,7) (1,0,25) (1,0,26) (1,0,29) (3,0,8) (4,0,10) (4,1,10) (6,1,8)
(20,0,7) (21,0,15) (22,0,7) (24,0,7) (24,0,15) (25,0,7) (30,0,7) (30,0,10) (31,0,6)
(147,0,9) (147,1,9) (149,0,8) (149,1,8)
```
- `(0,1,16)` = S52 的 **FF_USED_IN_SLICE** ✓ **确认**；
- `(1,0,7)` = S52 的 **FF_D_BYPASS_A** ✓ **确认**；
- `(1,0,25/26/29)`、`(0,0,27)`、`(3,0,8)`、`(4,0,10)`、`(4,1,10)`、`(6,1,8)`、`(31,0,6)` = **AFF 的 ZINI/ZRST/AFFMUX 类配置位**（偏移 ≤6 区）；
- `(20..25,0,7|15)`、`(30,0,7|10)` = FF 时钟/数据输入的 IMUX 选择位；
- `(147/149, …)` **超出 36 帧 CLB 块**（31680+147=31827）⇒ 是相邻 INT 块里的布线位，**不属于该 slice**，必须在解码器里按块窗口过滤掉。

### SR 组（交集 1 格）

```
(1, 1, 3)
```
= S52 的 **SR_SOURCE_FABRIC** ✓ **确认**，且是**唯一**的位置无关位（其余 39 格全是位置相关的布线漂移）。

## 3. 对 S52 的修正

| S52 命名 | 本次结论 |
|---|---|
| `(0,1,16)` FF_USED_IN_SLICE | ✅ 确认（FF 组交集） |
| `(1,1,7)` CE_SOURCE_FABRIC | ✅ 确认（CE 组交集） |
| `(1,1,3)` SR_SOURCE_FABRIC | ✅ 确认（SR 组交集，且唯一） |
| `(1,0,7)` FF_D_BYPASS_A | ✅ 确认（FF 组交集） |
| `(1,1,15)` CE_SR_CONST_MARK_A | ❌ **推翻** —— 三个实验的交集里都不出现，是单次差分噪声 |
| `(1,1,23)` CE_SR_CONST_MARK_B | ❌ **推翻** —— 同上 |
| `(1,0,19)` FF_MULTI_OR_FABRIC_D | ⚠️ 未在 FF 组交集出现（FF 组里是 `(1,0,25/26/29)`）⇒ 降级为【未定】 |

**结论：S52 的 7 个命名位中 4 个经双位置交集确认，2 个被推翻，1 个降级。**

## 4. 顺带得到的结构事实

1. **CE/SR 从端口来 ⇒ 只翻 1 个门控位**（`(1,1,7)` / `(1,1,3)`），另需 CE 网的 IMUX 选择（CE 组多出 2 格）。
2. **加一个 FF ⇒ 23 个位置无关位**，其中 2 个是“有 FF”标记，其余是 AFF 配置 + FF 输入选择。
3. **解码器必须按块窗口过滤**：FF 组里有 4 个格落在 base+147/149（相邻 INT 块），若按“该 slice 的块”取会误判。
