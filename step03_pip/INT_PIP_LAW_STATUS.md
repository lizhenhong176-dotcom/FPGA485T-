## 一、一句话结论

【数据事实】**规律是"公式 + 表"的混合体，不是全闭式**：纯公式可生成 **2,816/3,634 = 77.5%** 的 feature；再加 32 个 BEG 变体族的逐族列归属表达到 **3,456/3,634 = 95.1%**；再加 6 个复合族的组模型达到 **3,552/3,634 = 97.7%**；剩余 **82/3,634 = 2.3%**（6 个长线族）仍无规律、只有逐族表。

三档分计（严格按 V2 纪律，三档之和 = 3,634）：

| 档 | feature 数 | 占比 | 含义 |
|---|---:|---:|---|
| **公式生成**（无需查表） | 2,816 | 77.5% | 给定族名 + 源名即可算出全部应置位 |
| **逐族表**（每族一张常数表，含组模型） | 736 | 20.3% | 640 条 BEG 变体 + 96 条复合族组模型 |
| **未解**（只有原始单元格记录） | 82 | 2.3% | 6 个长线族 |

## 五、可发表的定位（一句可反驳的断言 + 三条攻击路径）

**断言**：在 XC7VX485T 的 INT tile 上，mux 与 BEG 两类族（占 172 族中的 160 族）的 PIP 选择位可由「每族 3 个数值 + 16 条配置 + 32 张变体列表」直接生成，对 **3,456/3,634 = 95.1%** 的 feature 做到**位级 0 差异重建**；否证条件是——出现任一 feature 无法由该表生成，或生成结果与实测位集相差 1 位。

审稿人会攻击的三点：
1. **泛化性**：只在一个器件（485T）、两个 tile 类型（INT_L/INT_R）、sense=1 口径上成立；96 个 20 源族虽然结构同构，但"几何类别"这一轴有 32 族要查表，说明结构并非普适闭式。
2. **循环风险**：`law_cells` 本身若由同一套假设导出，则"0 差异重建"是自证。必须讲清 `law_cells` 的独立性来源（T3 的 1,536/1,536 verify 来自位流实测差分）。
3. **压缩比口径**：95.1% 里 640 条其实依赖"逐族表"，若把它们算作"规律"会高估；真正的闭式只有 77.5%，且有 82 条（2.3%）完全未解。
