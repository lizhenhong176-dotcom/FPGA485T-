## 五、可发表定位（可反驳断言 + 三条攻击）

**断言**：在 XC7VX485T 的 INT tile 上，160/172 族的 PIP 选择位可由「每族 3 个数值 + 16 条配置 + 32 张变体列表」生成，对 **3,456/3,634 = 95.1%** 的 feature 做到位级 0 差异重建；否证条件 = 任一 feature 无法生成，或生成结果与实测位集相差 1 位。

攻击 1｜泛化：单器件、单 tile 类型（INT_L/R）、sense=1 口径；BEG 有 32 族要查表说明结构非普适闭式。
攻击 2｜循环：`law_cells` 若由同一套假设导出则 0 差异是自证；须引 T3 的 1,536/1,536 位流实测差分作为独立性来源。
攻击 3｜压缩比：95.1% 中 640 条实为逐族表；真闭式只有 77.5%，且有 82 条未解。
