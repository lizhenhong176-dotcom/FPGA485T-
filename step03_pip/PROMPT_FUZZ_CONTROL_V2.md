主题：撰写一篇说明文，针对「Xilinx 7 系列 INT tile 配置位复用规律」研究，正面回答审稿人/导师的尖锐质疑：「多位是共用的，你不可能每次只改一个位，那你的 fuzz 实验到底怎么算受控？」读者为懂 FPGA 的导师与审稿人，他们预设「位共享 ⇒ 单变量法失效 ⇒ 结论不可信」，全文须直接消解这一预设。

必须讲清的核心论点（全文骨架，逐条展开，不得绕开）：
1) 明确实验单位为「一条连接（或一个属性）」而非「一个位」；说明一次受控构建产出的是一组位（2–6 个格），并给出该组位的来源与判定方式。
2) 解释位共享导致「逐位翻」不可行：改一位往往不构成合法配置（解码为别的 PIP 或非法码），故逐位在此类编码中既不可构造、也无物理意义；须举具体解码/编码层面的理由。
3) 界定「受控」的控制对象是输入变量（网表/属性/摆放/版本/环境），而「位」是被测的输出集合；明确区分自变量与因变量。
4) 说明从「多个受控构建的位集合」到「复用规律」依赖集合运算而非逐位隔离：交集给公共位、差集给该源独有位、列重给共用度、一热/叉积检验给「组 × 码」结构；每种运算须给出判据定义。
5) 诚实交代覆盖度：一个族若有 N 个源，原则上需 N 条受控构建才能完全确定；明确本研究哪些族做满、哪些仅做部分并靠公式外推，并说明外推假设与风险。

必须给出的可操作清单（每条按「做法 / 为什么 / 不做会误判成什么」三栏写全）：
- 单一变量：同一 .v，只改一个属性或一个 LOC
- 显式 -part + 回读断言（防止镜像器件或默认器件串入）
- LOCK_PINS（管脚名必须用 get_bel_pins 实测，不许猜）
- DONT_TOUCH（防常量传播/优化把逻辑合并掉）
- 差分语义声明：PURE / XOR / FAM 三选一，并写清该语义下哪些差异属噪声
- 集合级自证 missing=0 extra=0（禁抽样）
- 负对照：同参数重跑，差异必须为 0
- 交叉自证：用工具自己的答案（.pips）核对「改了哪条连接」
- 校验字单列：word 50 是校验，会随数据重算，必须单独计数并排除
- 环境固定：locale、行尾、传输方式

集合运算部分须给出真实判据与实测数字（每个数字带分子/分母与出处）：
- 交集法：#sources 条差分逐位取交集 → 公共位（如 24 源族里每源 5 格中的 4 个公共位）
- 列重法：每格被多少源引用 → 直方图 → 二分（最轻档为组选择位）
- 一热检验：每个源恰含 1 个组格；每（族,码）列里组格一热
- 叉积检验：组 × 码完全叉积、无缺失无重复
- 实测：列重 1→4、2→5、3→26、4→909、5→384、6→134、12→12、18→128（合计 1,602 族-格对）；叉积 163/172 通过；9 例外是复合族与长线族
- 预算：64 个 24 源族理论需 1,536 条构建；实际用 19 条（GCLK 子空间 19/32）+ 公式外推；BEG 96 族靠既有 fuzz 池 3,270 条观测
- 生成器回归：3,552/3,634 = 97.7% 逐位 0 差异
