## 背景：我在做什么

我在对 Xilinx Virtex-7（器件 `xc7vx485tffg1761-2`，50,176 帧 × 101 字）做**从比特流逆向到网表**的完整流水线，不依赖 Vivado 的综合/布线语义，只用「差分探针 + 静态拓扑 + 约束求解」自建位数据库。当前已闭环的部分：

- 帧寻址：`frame = block_start(col, region) + frame_off`，`word = 2*(Y%50) + parity`（半带 ≥25 时 +1 避开 ECC 字），`bit = raw % 32`；
- CLB 语义：LUT6 的 64 位 INIT、四只 LUT、FF（AFFMUX/ZRST/ZINI/FF 类型位）、F8/F7 mux、PRECYINIT、SLICEM 的 RAM/SRL 属性位、pin-swap 置换；
- IMUX：CLB 内部 48 个输入选择 mux，用「位表 + CSP 联合消歧」解到唯一解（与 Vivado ROUTE 真值 6/6 逐 token 一致）；
- INT 布线：181 条可选 PIP 候选、全芯片解码 + 反向/正向走线，9 条网（6 输入 + 3 输出）与 Vivado 真值对账；把恢复出的网表重新综合后与原比特流比对，单元配置区 **0 字差异**。

## 我要问的核心：PIP 配置位「复用」

在这个器件上，我把 INT tile 的配置位域做了穷举统计（每侧 INT_L / INT_R 数字完全对称），得到如下事实：

| 量 | 值 |
|---|---|
| feature 定义 | 一条 PIP 类型 `(family, src_wire)`，family = PIP 的目的 wire（mux 名 / BEG 名） |
| feature 总数 | 3,636 |
| family 总数 | 172 |
| 不同配置 cell 数 | **1,598**（cell = `(frame_off, parity, bit)`） |
| cell → family 归属 | **1,598 / 1,598 独占**：没有任何一个 cell 被两个不同 family 使用（含 sense=0 的格也算） |
| 单个 cell 被多少个 feature「置 1」 | 3 .. 18，均值 **5.57** |
| 单个 feature 平均置位 | **2.45** 个 cell |
| family 位域大小 | 7..10 个 cell（众数 9） |
| family 源数 | 12..24（众数 20） |
| 家族内编码唯一性 | **172 / 172**：同一 family 内不存在两个源共用同一 0/1 pattern |
| 位域填充度 | mux 区 **640/640 位满装**，全 tile 26 帧 × 2 字 × 32 位 = 1,664 位里 1,598 被占（96%） |
| 「域大小/源数」组合 | 只有 **5 种**：`(9,20)×96`、`(10,24)×64`、`(8,16)×6`、`(7,12)×4`、`(9,18)×2` |

也就是说：**复用只发生在同一个 family 内部**（多个源共享同一组 cell，靠不同的多位置位组合区分），**跨 family 无共享**。我把这个规律做成了查表规则（给定差分位集 ⇒ 反推是哪条 PIP），并用 3,270 条实测观测做了零反例校验；另外用「写位 + 回环」验证了 864/864 位（含 ECC）可写回。

我给这个现象起的内部叫法是「PIP 复用（reuse）」，但我不确定学术/工程界对它的标准叫法（可能是 bit sharing / mux encoding aliasing / cell aliasing / multi-source mux encoding）。这可能正是我需要你纠正的地方。
