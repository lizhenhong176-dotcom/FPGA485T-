可用素材（真实、已核实，写作时按需引用并带出处）：
- 器件：XC7VX485T-2FFG1761（VC707）；INT_L/INT_R 各 26,550 实例；每 tile 600 wire、3,737 PIP、216 个目的 wire，其中 172 个目的 wire 是多源 mux（3,693 PIP）+ 44 条直通。
- law_cells：每侧 172 族 / sense=1 8,900 行 / 3,634 feature / 1,598 个不同位格；2.45 位/连接、5.57 引用/位、2.27 连接/位（压缩比）。
- 复用四层：位级（1,598 格承载 3,634 连接）/ 族级（6 行×4 码，合法码 {1,2,7,11}）/ 跨族（3/1,598 共享）/ 跨 tile（26,550 实例同一张表）。
- 地址链：frame = far_bands[(band,col)].start_frame + frame_off；word = 2*(Y%50)+parity（≥50 则 +1 跳过 ECC 字）；far_bands 1,078 行 = 7 band × 154 列。
- 生成器：gen_mux.py 64/64 族逐位 0 差异；gen_slots.py mux 64/64 + BEG 96/96（变体 32/32）+ 复合组模型 96/96 = 3,552/3,634 = 97.7%；剩 82 条（6 个长线族）判为逐族表数据。

- 跨类型：INT（2 类，全族）、HCLK_CMT（结构：1 组槽位 + 2..4 码字，位池在相邻逻辑列块尾帧 minor 26..29）、CLK_HROW（32 个 GCLK 局部编码 19/32 实测 + 公式；30 个 CK_IN 源为默认通路，25 个设计零反例）→ 3/115 类型。
