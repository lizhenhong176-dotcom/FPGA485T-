# S57 · MMCM MULT / CLKOUT_DIVIDE 分段码实测（37 设计）

日期：2026-11-11
站点：`MMCME2_ADV_X0Y0`（帧对 **32638/32639**，帧号相对 = f0/f1）
基线：`m08_p100`（MULT=8, CLKOUT0_DIVIDE_F=8, CLKIN 100 MHz, VCO=800 MHz）

## 0. 一句话结论

MULT 与 DIVIDE **都不是二进制位域**，是**分段码**：同一个值可能对应若干位组合，
相同位组合可能出现在不同值上（如 DIVIDE 4 与 12 共用 `f0.w29=0x90000000`）。
**解码必须查表**；编码只落在两组字：MULT → `(f0.w25, f0.w26, f1.w25, f1.w26)`，
DIVIDE → `(f0.w29, f1.w29)`。

## 1. 干净的控制实验：CLKIN1_PERIOD 不编码

| 对照 | MULT | CLKIN | VCO | 4 字签名 |
|---|---|---|---|---|
| m07_p200 | 7 | 200 MHz | 1400 | `78047d00 10100000 18859d00 52009292` |
| m07_p100 | 7 | 100 MHz | 700 | **完全相同** |
| m12_p100 / m12_p50 | 12 | 100/50 MHz | 1200/600 | **完全相同** |
| m14_p100 / m14_p50 | 14 | 100/50 MHz | 1400/700 | **完全相同** |
| m16_p100 / m16_p50 | 16 | 100/50 MHz | 1600/800 | **完全相同** |

⇒ 四组独立对照，`CLKIN1_PERIOD` **不产生任何配置位**（只影响时序分析）。
这条同时说明：**同 MULT 不同 VCO 的位流在位级完全一致**，所以后续必须用 MULT 值本身做索引，不能用 VCO。

观察（可写成“结构性质”，不等于“代数公式”）：

1. `f0.w25` 低字节在 3–10 段是 `7b/7d/79/7f` 四种之一，在 11–32 段**恒为 `7f`**；
   高字节从 `0x78` 出发，在 11–32 段变成一组“滑动窗口”值
   `18/68/f8/78/d8/28/30/10/c0/60`（相邻 2–5 位为 1 的窗口）。
2. `f1.w25` 高字节从 3–10 段的 `0x18` 跳到 11 段以后 `48/a8/50/60/00/b0/78/28/78/48`。
3. `f0.w26` 只在 bit20/bit27/bit28/bit30/bit31 一带取值（`0x10100000`/`0x80100000`/`0x48000000`/`0x90000000`/`0xd8000000`），
   即**一条 5 位的 coarse 位线**；同一个 coarse 值可对应不同 MULT（`0x48` ↔ 16 与 24），
   说明 coarse 只是**分段编号**，精确值靠 w25 的细码组合。
4. 结论：MULT 是 **(coarse 段号, fine 段内码)** 两级编码，与 INT/BRAM 的“分级 one-hot”同一设计哲学，
   但段内码不是 one-hot 而是紧凑位串 ⇒ 只能查表。

结构性质：

1. `f0.w29` 只出现 7 个值：`0/0x10100000/0x00100000/0x80100000/0x90000000/0x90100000/0x48000000/0xd8000000/0x24000000`，
   且**同一值覆盖多个 DIVIDE**（`0x90000000` = 4/6/12；`0x48000000` = 16/24/48；`0` = 1/2/8/10/32）。
2. `f1.w29` 高字节承载段内码（`12/02/4a/26/52/82/92/da/ca/92`），低 16 位**恒为 `0x9010`**（除 DIVIDE=1 的 `0x9010` 同）。
   ⇒ DIVIDE 的“单位”是 1（`f0.w29` 段号 + `f1.w29` 段内码），与 MMCM 内部“分频比存储为 1/比值”的写法吻合（【推断】）。
3. `f1.w29` 最低位段的 `0x9010` 与 `0x1010`（DIVIDE=1）差 bit19 ⇒ DIVIDE=1 有专门的“旁路”位。
4. 与 S55 的观察一致：DIVIDE 8→6 时 `(29,30)` 只在新值出现，说明是 code，不是 binary。

## 4. 复现配方（37 设计，6 并发约 12 分钟）

```
设计：BUFG 反馈 + MMCME2_ADV_X0Y0（CLKOUT0_DIVIDE_F / CLKFBOUT_MULT_F / DIVCLK_DIVIDE=1）
      8×FDRE @SLICE_X8Y11，clk=AL31（时钟脚），d[0..7]/q[0..7] 各钉 8 个 bonded pin
tcl：synth → set_property CFGBVS GND [current_design] / CONFIG_VOLTAGE 1.8 [current_design]
     → 综合后 LOC（FD* → SLICE_X8Y11；MMCME2_ADV → MMCME2_ADV_X0Y0）
     → create_clock -period $env(PER) → opt/place/route
     → 豁免 NSTD-1 / UCIO-1 → write_bitstream
环境：export LANG=C LC_ALL=C HOME=/root XIlinx license
解析：大端，取第一段 FDRI（count 掩码 0x7FFFFFF），自检 50,176×101
```

约束边界：VCO 必须 600–1600 MHz（`DRC PDRC-34` 会拦），所以 MULT 宽扫必须同时改 CLKIN 周期，
本轮用 200/100/50 MHz 三个档覆盖 3–32。
