# 提示词：确定一个 tile 在 .bit 中的地址（V1）

> 经 `optimize-user-prompt`(user-prompt-professional) 加工；按 AGENTS.md 提示词纪律存档。

## 角色

Xilinx 7 系列 FPGA 位流逆向工程师，具备 .bit 帧结构、帧地址映射、LOC 约束与语料统计分析的实操经验。

## 任务

产出一份「确定一个指定 tile 在 .bit 文件中的精确地址」的完整可复现方法说明文档。地址定义为四级定位：

1. tile 所属帧块基址 `block_base`
2. 块内帧号 `frame = base + frame_off`
3. 帧内字号 `word = wof(Y) + parity`
4. 字内位号 `bit`

文档须使另一名具备同等背景的工程师**仅凭文档**即可对任意给定 tile 复现出同一 `(帧, 字, 位)` 三元组。

## 必须包含（六部分，附约束）

### 1. 四级定位的定义与依赖关系

- 逐级给出数学定义、输入变量及物理含义。
- 明确标注每一级「与 tile 位置无关（可全片复用）」还是「随 tile 位置变化」，并给判定依据。
- 给出四级之间的依赖链。

### 2. 至少 4 种独立定位方法

须覆盖：语料帧占用统计、LOC 地面真值、Y 差分实验、结构推导/预算闭合。每种按四段式：

- **输入**：具体文件、数据或实验条件
- **操作**：可复现的步骤序列
- **输出**：具体产物形式
- **失效判据**：写成「若 X 出现则该方法失效」的断言式，至少 1 条

并说明四种方法的**独立性来源**（为何一种方法的结论不依赖另一种的假设）。

### 3. 失效模式清单

每条包含：症状（可观测现象）、为什么看起来正常（误导来源）、如何区分（可操作判据），并关联到第 2 部分受影响的方法。

### 4. 完整手算例子

选定一个具体 tile，逐位演算至最终三元组，每步写出代入数值与来源，须覆盖四级。

### 5. 交叉验证矩阵

表格：行 = 证据链，列 = 四级定位结果及置信依据；明确标注「哪条能证明哪一级、不能证明哪一级」与证明力边界。

### 6. 措辞与出处规范

- 全文禁止「通常 / 一般 / 应该」，出现即不合格。
- 每个数字标注来源文件路径（精确到文件名，必要时到行号或字段）。
- 未知或未验证项必须显式写【未测】。

## 验收门

- [ ] 随机抽 3 个 tile，文档能算出与数据库一致的 (frame, word, bit)
- [ ] 至少一条失效模式说明「为什么它能骗过简单验证」
- [ ] 交叉验证矩阵中不存在「所有链都声称能证明同一级」的情况
