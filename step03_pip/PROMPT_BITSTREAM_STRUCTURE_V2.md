# 提示词：比特流配置结构 + tile 帧空间分配

> 生成流程：`optimize-user-prompt`（user-prompt-professional）→ `iterate-prompt`（iterate，7 条加固）
> 用途：把「位流到底长什么样」与「不同 tile 如何分配帧空间」两问一次问到底，且强制可证伪。
> 配套实测数据：`PHYS_BITSTREAM_DEEP.md`（同目录）。

---

你是 FPGA 位流（bitstream）结构专家，同时熟悉 Xilinx 7 系列配置架构与开源逆向项目（prjxray / Trellis / IceStorm）的实测口径。请回答以下两个问题，并严格按指定结构输出：

(1) 7 系列比特流的配置结构从文件头到帧内字段的完整层次是怎样的；
(2) 不同类型的 tile（CLB/INT/BRAM/DSP/IO/CMT/GTX/PCFG 等）在位流中如何分配帧空间。

【口径声明（强制）】
- 全文必须显式区分“7 系列通用口径”与“仅 xc7vx485tffg1761-2 实测口径”两类陈述；凡属 485T 专属的数字、帧数、行型分布、地址跨度等，必须标注“仅 485T 实测”，并明确声明不得外推到其他 7 系列器件。
- 禁止把 485T 实测结论写成 7 系列通用结论；反之亦然。

【项目背景（xc7vx485tffg1761-2，已实测，均属“仅 485T 实测”口径）】
- 帧 50,176 × 字 101 × 位 32 = 20,257,472 有效位；文件 20,273,538 B。
- CLB tile 块 = 36 帧；INT tile 块 = 28 帧；BRAM/接口列块 = 28 帧。
- 每 clock region 带跨度恰好 5,180 帧；带起始 pitch 5,246；band 间空 66 帧；7 带共 36,260 帧；fabric 止于 36,688，其后 13,488 帧属 IO/GTX/CFG 侧。
- 行型不统一：225 行有 111 个 CLB 列，100 行 105 个（PCIE 行），25 行 99 个，15 行 0 个。
- 行内字规则：word = 2*(Y%50) + (1 if Y%50>=25 else 0) + parity；parity = 位号//32。
- slice 内字段偏移：INIT 在 base+32..35，FF 在 base+30/31，IMUX 在 base+16..25。
- 已实测 172 个 INT 家族位池（1,598 cell）、181 个 PIP 0 ambiguous、位流→网表 2 个 slice 并做了重综合位级验证。

【内容要求】
1. 分开陈述「文档已公开」与「项目实测」两类事实；凡不确定必须显式标注，禁止用“通常/一般/应该是”替代证据。
2. 必须给出：文件头/同步字/包类型/命令表（含 FAR、FDRI、MFWR、IDCODE、CRC、MASK、CTL 等）与位序、CRC 算法位置、帧内 ECC 字的位置与宽度。
3. 必须给出 tile 类型 → 帧数的完整对照表，且该表必须为六列：tile_type / 帧数 / 字段段构成 / 485T 实例数 / 证据来源 / 是否已用本机数据验证。并解释为什么 CLB 是 36 帧而 INT 是 28 帧（从字段构成差异说明），同时说明该 36/28 结论是 485T 实测还是 7 系列通用。
4. FAR 位域切分（block/row/column）必须写成“假设 + 验证方法”的形式，不得直接当作定论。必须解释 5,180 与 5,246 这两个数字的关系；若无法推导出 50,176 的整齐公式，必须明确写出“无法由此得出”，禁止硬凑。
5. 必须给出一段可运行的解码骨架伪代码（读 .bit → 取 FAR → 定位帧 → 取字段），并对每一步指出其失败模式（同步字错位、FAR 解析越界、帧索引错算、字段偏移越界等）。
6. 必须补充“读回路径 / ECC 覆盖范围 / MFWR 多帧写”三个易漏点，并逐条说明其属于【UG470】文档所述、还是本项目未测/已测。
7. 必须给出“给定一个新设计的 .bit，如何逐层拆到 tile 字段”的可执行步骤，精确到命令级（含所用工具、命令与参数）。
8. 输出严格分为 10 节：① 一句话总览 ② 文件层结构 ③ 命令层 ④ 帧层与 FAR ⑤ 帧内字段布局 ⑥ tile 类型分配表 ⑦ 为什么不同 tile 尺寸不同 ⑧ 未解问题清单（每条含测法）⑨ 常见误解 ≥8 条 ⑩ 自测 6 题。
9. 每个数字必须标注来源：【UG470】/【prjxray】/【本项目实测】/【推断】/【未测】；并同时标注口径（“7 系列通用”或“仅 485T 实测”）。
10. ⑨ 常见误解中必须包含“帧数 = 列数×行数”和“每帧都是 101 字”这两条，并说明其为何错误。
11. 结尾给出“如果要证伪本回答，应跑哪三个实验”，每个实验写明目的、输入、步骤与判定标准；且三个实验必须能在一台无板卡机器上执行（Vivado + Python 即可），不得依赖实际硬件。
