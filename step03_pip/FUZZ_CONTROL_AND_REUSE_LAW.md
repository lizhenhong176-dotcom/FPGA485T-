# 多位共用时，fuzz 实验怎么算受控（主线：PIP 复用规律）

> 本文只讨论一条主线：**PIP 复用规律**（复用发生在哪几层、规律是什么、能否反过来生成）。篡改定位、ECC、可加载闭环属旁支，本文不涉及。
> 三色标注：【硬件事实】【数据事实】【推断】；每个数字带分子/分母与出处；无数据写「未测」。

## 一、一句话回答

【数据事实】受控的是**输入侧变量**（同一网表只改一个属性），不是位；一次受控构建产出的是**一组位（2–6 格）**，规律来自多个集合的交集/差集/列重/一热运算。例：GCLK 子空间用 19 条受控构建定出 32 槽中的 19 个（19/32），公式在未参与拟合的 k=2 上独立复现（`step03_pip/_remote_words16.py`）。

## 二、为什么「每次只改一个位」在这里做不到

**位是共享的**
- 【数据事实】3,634 条连接只占 1,598 个位格（2.27 条连接/格），一个 PIP 的位集是 2–6 格（`step03_pip/gen_slots.py` 的规模输出）。
- 【硬件事实】mux 族的选择字段是 10 位：6 个行选择位 + 4 个列码位；**列码只允许 {1,2,7,11}**（`PIP_REUSE_STRUCTURE.md` §11）。

**只翻一位会落到非法码或别的源上**
| 原始列码 | 只翻最低位 | 结果 | 是否合法 |
|---|---|---|---|
| `1` (0001) | `0` (0000) | 空码 | 非法（无源） |
| `7` (0111) | `6` (0110) | 其他族用到的码 | 该位属于别的源的编码 |
| `11` (1011) | `10` (1010) | 空码 | 非法 |

⇒ 孤立翻一位，要么让该 mux 进入不存在的选择（不可加载/不可解释），要么点亮另一条 PIP 的码位。所以「逐位 fuzz」在这类编码里**既不可构造，也没有物理意义**。

**可行的实验单位**
- 一次构建改一个**属性/一条连接/一个站点**，读出的是一组位；
- 「受控」体现在：除被测变量外，其余输入（网表、器件、管脚、器件版本、环境）全部固定并可复现。

## 三、受控实验清单

| 控制项 | 做法 | 不做会误判成什么 |
|---|---|---|
| 单一变量 | 同一 `.v`，只改一个属性或一个 `LOC` | 差异里混入优化器连带改动 |
| 显式器件 | 命令里写死 `-part xc7vx485tffg1157-3` 并回读断言 | 默认器件串入，帧数/位位置整体错位 |
| 锁管脚 | `LOCK_PINS`，管脚名用 `get_bel_pins` 实测 | 引脚自由重排，同一设计三次三张表 |
| 防优化 | `DONT_TOUCH`、`KEEP` | 常量传播/逻辑合并把被测量的逻辑删掉 |
| 差分语义 | 显式声明 PURE / XOR / FAM（同源同参只差一处 / 两版异参 / 族内多源） | 把 XOR 差当绝对位置，形状随 CLB 变 |
| 集合自证 | 反读自证 `missing=0 extra=0`（禁抽样） | 漏掉的连接被当成「没有该位」 |
| 负对照 | 同参数重跑两遍，差异必须为 0 | 噪声被当成位 |
| 交叉自证 | 用工具答案 `.pips` 核对「改了哪条连接」 | 位差分落到了没打算改的连接上 |
| 校验字单列 | `word 50` 是校验位，随数据重算 → 单独计数并排除 | ECC 变化被当作数据位，凭空多出 12–20 个「位」 |
| 环境固定 | `LANG/LC_ALL=C.UTF-8`、LF 行尾、禁 scp | Vivado 2017.2 locale core dump / 脚本被 CRLF 破坏 |

## 四、从多个位集合到复用规律：四条集合运算

**① 交集 → 公共位**
24 源族每个源 5 格；24 条（同族不同源）差分的**交集**给出 4 个公共位（`frame_off 22..25`），这 4 位被全族 24 个源共用，无法区分源。
【数据事实】`IMUX_L40`：24 源 × 5 格 = 120 条记录，每源 = 4 公共位 + 1 独有位（`law_cells`）。

**② 差集 → 该源独有的组位**
每源那 1 个独有位就是「选哪一行」的组选择位；【数据事实】`frame_row = 16 + r`，384/384 行格无例外（`step03_pip/_q_row_law.py`）。

**③ 列重 → 二分结构**
把「每个位被多少源引用」做成直方图，最轻档恰是组选择位（每源各 1 个）。
【数据事实】列重 1→4、2→5、3→26、4→909、5→384、6→134、12→12、18→128，合计 1,602 个族-格对（去重 1,598 格）；4–5 档占 1,293/1,602 = 80.7%（`step03_pip/_q_reuse_structure.py`）。

**④ 一热 + 叉积 → 「组 × 码」结构**
判据：每源恰 1 个组格；每（族,码）列里组格一热；组 × 码完全叉积。
【数据事实】163/172 族通过；维度 (6 组,4 源,4 码)×64、(5,4,4)×96、(6,3,3)×2、(4,3,3)×1；9 个例外正是复合族与长线族（`step03_pip/_q_grid_is_real.py`）。

## 五、实验预算：理论需要多少条 vs 实际做了多少

| 族类 | 理论需要（源数×族数） | 实际受控构建 | 结论来源 |
|---|---|---|---|
| mux 24 源 64 族 | 1,536 | **19**（GCLK 子空间 19/32） | 公式外推 + k=2 独立复现 |
| BEG 20 源 96 族 | 1,920 | 0 条新构建（用既有 fuzz 池 3,270 条观测） | 完全二分 + 列归属规则 640/640 |
| 复合 6 族 | 96 | 96（组模型逐源） | 96/96 源 0 差异 |
| 长线 6 族 | 82 | 82（观测） | 无公式，判为逐族表数据 |

【推断】这就是审稿人最该攻的点：**19 条构建被用来支撑 1,536 条连接**。兜底手段不是再堆构建，而是**逐位回归**：生成器重建 3,552/3,634 = 97.7% 逐位 0 差异，且与 Vivado 真值一致 1,155/1,263 = 91.45%（`gen_slots.py`、`_q_verify_pips_after.py`）。若某条规律是错的，回归会立刻在该族暴出差异。

## 六、这套控制的失效条件

| 可观测现象 | 说明 |
|---|---|
| 同参数重跑差异 ≠ 0 | 环境/工具噪声，全部差分不可用 |
| 集合自证 `missing` 或 `extra` ≠ 0 | 差分或图不完整，位集合不可信 |
| `.pips` 与位差分对不上（改了 A 出现 B 的位） | 优化器被迫改了别的，变量不单一 |
| `word 50` 计数随数据变化却被算进数据位 | 校验字混入，位集合虚增 |
| 生成器 0 差异率掉到 <95% | 规律不稳，必须逐族复核 |
| 跨类型 0 差异率 <50% | 「结构可迁移」判断作废 |
| 同一族两条不同源的位集合完全相同 | 该族存在不可分辨的源（等于「复用但不可解码」），必须如实标注 |

**最后一条注意**：以上全部结论都在「模型口径」内成立（172 族、3,634 条连接、除 3 个跨族共享格外无未解释位）。模型之外的位（CLB/BRAM/DSP 数据位、校验字、未被解释的标记位）**未测**，不在本文主张范围。
