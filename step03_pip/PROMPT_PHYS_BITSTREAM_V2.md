## 正文

你是同时具备 Xilinx FPGA 物理实现（floorplan、布局布线、位流生成）与位流逆向经验的工程师。请针对 Xilinx Virtex-7 `xc7vx485tffg1761-2`，围绕以下四部分做一份"物理结构—位流编码—逆向可解性"一体化说明：四部分必须相互引用、相互校验，禁止各写一段互不关联；正文中须以"见第 X 部分第 Y 项"的形式显式交叉引用至少 6 处，且每条物理结构描述都必须给出"对应的位流可见证据"，禁止把物理结构与比特流结构写成互不引用的两张表。所有断言必须带【硬件事实】/【数据事实】/【推断】标注；无数据处写"未测"并为每个未测项给出定位/测量方法（用什么脚本、看哪张表、预期看到什么），不得只写"未测"；严禁编造帧偏移、cell 位置或数量；禁止用"通常/一般/大多数"替代数字；命名先于概念；BEG→END 的 tileconn 落点不得称为 mux；家族不得冒称 Xilinx 官方术语。术语首次出现时必须给出英文原文与中文，禁止只用缩写。

背景事实（项目实测，可直接采信，不得篡改）：器件 xc7vx485tffg1761-2，150,380 tile、86,022 fabric site、1,760 package pin、14 clock region；SLICEL 43,200 + SLICEM 32,700 = 75,900 slice，每 slice 4×LUT6 + 8×FF + 2×MUXF7 + 1×MUXF8 + 1×CARRY4；位流 50,176 frame × 101 字 × 32 bit，每 config row 末 2 帧为 OVERHEAD 不属任何用户块；定位 cell = (block_base + frame_off, word, bit)，word = 2*(Y%50) + parity（Y%50 ≥ 25 时 +1），bit = raw % 32；帧块大小不等：CLB 36 帧、INT 列块 26 帧、接口块 28 帧，缺列处有 28 帧夹缝块；单个 INT tile 位池 1,664 位，其中 1,598 位被 3,636 条 PIP feature 覆盖、66 位未覆盖；1,598/1,598 cell 只属一个家族（0 例跨族共享）；族内 3..18 源/cell（均值 5.57，最大 18），每 PIP 占 1–4 cell；形状 5 类 (9,20)×96、(10,24)×64、(8,16)×6、(7,12)×4、(9,18)×2；已确认两级 one-hot：(9,20)=4 组×5 成员，位宽 4+5=9 而非 ceil(log2 20)=5；全芯片解码 181 PIP / 181 家族 / 0 ambiguous；写位回环 864/864；未解：CARRY4 CY0 族、CE/SR/CLKINV mux、(8,16)/(10,24) 的 4 位编码、BRAM/DSP/IO 跨族独占性、长线 LV/LVB 选择位。

命名地基（先讲再展开）：PIP feature 名格式 `<tile_type>.<目标 wire>.<源 wire> <frame_off>_<bit>`，`!` 前缀表示该位须为 0；本项目记法 `TILE/TILE_TYPE.SRC->>FAM` 等价；家族 = 同一 tile_type 下目标 wire 相同的那组互斥 PIP；wire 名 `<方向><长度>BEG<n>/END<n>`，方向 N/S/E/W 与 NE/NW/SE/SW，长度 1/2/4/6，LV/LVB 长竖线、GFAN 全局扇出、ER/R 短线、LOGIC_OUTS CLB 输出、IMUX/BYP/CTRL/CLK 输入侧 mux 输出；禁止把 BEG→END 的 tileconn 落点称为 mux（无配置位的固定连接）。

请按以下四部分展开，并满足各自验收要求：

**1. 物理架构分配**（五项，每项说明"结论如何从数据/手册算出"，并给出对应的位流可见证据）：① die 分区图：14 个 clock region 如何切分、每 region 行数列跨度、边界特殊 tile（VBRK/VFRAME/BRKH_*）；② 列序列：CLB/INT/BRAM/DSP/IO/时钟列的类型排列、CLBLL 与 CLBLM 为何交替、SLICEM 只出现在哪些列且规则须可判定；③ 数量与分布：INT_L/INT_R 各 26,550、CLB 合计 37,950、BRAM_L 480 + BRAM_R 550、DSP_L 770 + DSP_R 630、LIOB18/RIOB18 各 168、IOB18S/IOB18M 各 336，并说明这些数字如何互相校验（如 DSP tile×2 = DSP48E1 site 数）；④ 时钟网络：BUFGCTRL 32、BUFHCE 168、BUFR/BUFIO 各 56、BUFMRCE 28、MMCM/PLL 各 14 落在哪些 tile、服务哪个 region，HROW 如何贯通左右半区；⑤ IO 与硬核：IO bank 排列、为什么 die 中央也有 IO（LIOI 出现在中部）、GTX_CHANNEL 56 / GTX_COMMON 14 / PCIe 8 tile / XADC 3 tile 的物理位置。验收：读者能凭描述在 tile 表里定位到 tile_type 与大致坐标，无法定位的写"未测"并给定位/测量方法。

**2. PIP 复用难点矩阵**（≥8 条，每条须含五列：难点/物理原因/数据表现（带数字）/后果与验证办法/最小判定实验（可直接照做的一步，含明确输入与判据）；缺少"最小判定实验"列或该列无输入/判据的行作废），须覆盖：位级共享（为何 N 源共用 k 位、分级 one-hot 的电路原因）、反解多对一（为何位集→feature 多对一、何时唯一）、歧义 aliasing（何时 |F(o)|>1、本项目 0 ambiguous 是运气还是必然）、覆盖不全（66 位未覆盖含义、"1,598/1,598"分母的局限）、多 PIP 同时激活（单条查表为何失效、需要什么联合求解）、sense 反转（位为 0 表示选中如何颠覆直觉、如何从数据区分）、跨实例/跨 tile_type 迁移（位模式能否跨 tile/band/列/slice 复用、边界在哪）、写入方向更难（读只要一致写还要 ECC/CRC、写错一位后果）、基线盲区（差分法盲点如何暴露与补）。必须明确回答难在可判定性还是计算量，分单 PIP / 同 tile 多 PIP / 全芯片 181 PIP 三种情形，并说明把"家族内位池互斥"当公理后复杂度怎么变。

**3. 物理结构自下而上**（逐层讲清并给"如何体现在位流里"的对应位流可见证据）：配置 SRAM 单元（一位=一个 pass transistor 栅极）、pass transistor 与 mux 树（N 源→N 开关→一个目标 wire，栅极如何被编码）、switch box（为何一个 tile 有 172 家族、3,636 条 PIP）、布线通道与线段（NN/SS/EE/WW、NE/NW/SE/SW、长度 1/2/4/6 的物理含义）、CRAM 行列组织（为何一帧=一列的 101 字、帧号沿列递增、每行 50 帧+2 OVERHEAD）、由此推出的两条硬约束（半带 +1 的来源、CLB 36 帧 vs INT 26 帧）。

**4. 比特流结构**：帧/字/位构成（101 字×32bit 的划分，前 50 字数据+第 50 字 ECC 是否成立，不成立写未测，位序与字节序）、地址（FAR 字段 block type/row/column/minor，50,176 如何由 region×行×列推出）、命令层（sync word、Type-1/Type-2 包、WCFG/FDRI/GRESTORE/DESYNC、写一帧完整序列）、CRC 与 ECC（覆盖范围、ECC 如何算、为何改位必须同步改 ECC/CRC）、读回与部分重配置（读回顺序、MFWR 作用、PR 地址约束）、资源↔帧偏移（CLB 的 LUT/FF/IMUX 在 off 32–35/30–31/16–25，INT 的 PIP 在 off 0–15，并说明这些偏移如何被测量出来）。每个"未测"项同样须给出定位/测量方法。

四个咬合问题必须回答：① 物理→位流：CRAM 行列组织如何直接导致"半带 +1"（用列扫描顺序解释，不许只说实测如此）；② 编码→位池密度：分级 one-hot 如何导致 INT 位池 96% 被占且 cell 只属一个家族；③ 复用→难度：去掉独占公理后还能否解出 181 PIP、需要什么额外证据；④ 写入→验证：为什么"写位回环 864/864"比"读完能对上"更强、排除了哪类错误。

**退化分析**一节必须回答：如果只拿到 .bit、没有 DCP 和任何真值，哪些结论会退化——明确列出退化项、每项退化为哪类不确定性，以及可用的替代证据链（例如位流统计、已知约束反推、外部公开数据比对等）。

输出严格按以下九段顺序，不可增删或调序：① 物理架构分配 ② 难点矩阵 ③ 可判定性 vs 计算量判定 ④ 物理结构自下而上 ⑤ 比特流结构 ⑥ 四个咬合问题 ⑦ 误解纠正 ≥6 条 ⑧ 6 道自测题+答案（≥2 题跨物理↔位两层）⑨ 仅 .bit 无真值时的退化分析。交付前逐条勾选自检清单（10 项：四部分互相咬合且见第 X 部分第 Y 项式交叉引用 ≥6 处；难点矩阵 ≥8 条且每条带数字与最小判定实验列；明确回答可判定性并分三情形；讲到 SRAM 与 pass transistor 层；比特流含 FAR+命令层+CRC/ECC+读回；三色标注齐全；每个未测项均有定位/测量方法；每条物理结构均给对应位流可见证据；术语首现含英文原文与中文；无编造），任一未满足必须显式声明并说明原因，自检结果须在正文中体现。
