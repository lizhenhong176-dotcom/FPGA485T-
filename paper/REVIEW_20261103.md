## 4. 十二问快答

1. **科学问题**：*7 系列配置位的地址空间是否存在可闭式表达的生成结构，其可逆性边界在哪里？*
   （现在的写法是"逆向 485T"，必须换。）
2. **生成式定律 vs per-bit 表**：参数化后 64 个 family 只需 `(网格尺寸, 位对, parity, phase)` 四元组 +
   一张 24 槽位置换表；表侧是 1,536 条 `(family,src)→cells`。压缩比 ≈ 1536/88 ≈ **17×**，
   但**槽位置换仍是数据**（`T3:69`），所以真实压缩比要打折，且必须在论文里给出这个折扣。
3. **"law" 这个字撑不撑得住**：160/172 family 生成化（`T3:219`），剩 12 个是时钟/控制复合码；
   而"源→槽位"全部是数据。诚实的说法是"**编址体制是定律，编码内容是数据**"。
4. **2 格歧义能否定理化**：能，且很容易。同族 24 个源、2 格取自 k 格池，
   跨族时位池可能重合 → 给定 2 格集合的候选数可精确枚举。把 `C(k,2)` 与冲突族的组合数算出来，
   给出"2 格 pattern 的互信息上界 < log2 24"，就从缺陷变成定理。**这是当前性价比最高的一件事。**
5. **ECC 是否已够做**：不够，但方向已对。§32 证明 `ECC = L(data) ⊕ A(addr)`，
   现有 739 个非零帧给了 615 条方程、秩 143——**秩不够是地址项没建模**，不是数据不够。
6. **S14/S15 覆盖多大空间**：2 个 slice、64 组输入、1 个设计（`STATUS.md:803-815`）。
   统计上不能外推，必须补一个多级设计。
7. **39.9M 边表是科学还是工程**：工程副产品，但它支撑了"tile_block 四级规则"与 S13 的
   6/6 token-exact（`STATUS.md:786-796`）。论文里应作为**基础设施**一段，不作为贡献点。
8. **为什么没有与 prjxray 同任务对比**：其实**有**——`PRJXRAY_COMPARE.md` 做了六 tile 覆盖率
   （INT_L 3629/3737、CLB 伪 PIP 146/151）与 13/13 逐字节等价。缺的是"**同任务精度/耗时**"
   （解码时间、精确率、召回），这个补起来只要一张表。
9. **多次自我证伪是加分还是减分**：加分，且是本文最稀缺的品质。但要在论文里写成
   "we report four refuted hypotheses"，否则读者只看到散落的 §18/§30/§31。
10. **只保留一个贡献点**：保留"**生成式编址 + 可逆性边界**"。它同时解释"为什么是 64"、
    "为什么 2 格不可判"，是唯一不能被"这只是移植"一句话打掉的。
11. **最强单点证据 / 最弱一环**：最强 = `PRJXRAY_COMPARE.md:140` 的 13/13 逐字节双向等价
    （跨 region、跨 word-50 跳变）；最弱 = 无硬件加载/回读（`REUSE_RULES.md:234-235`）。
12. **换个故事线（验证/检测）**：可行且更值钱。"解码→重综合→位级 diff"天然是
    **比特流篡改定位器**（S15 全芯片 53 字差异就是定位精度的现成数据）。

## 6.4 三条故事线

**线 1（定律为主角）**
标题：*Why 64? Generative Encoding of Virtex-7 Interconnect Configuration Bits*
摘要：7 系列配置位长期以查表形式存在（prjxray 每 tile 数千行）。我们在 XC7VX485T 上证明：
INT tile 的 172 个 PIP family 中 160 个的位集合可由 `(网格, 位对, parity, phase)` 四参数生成，
且 16×2×2=64 与 family 数严格一一对应；帧 2–7 的 32 族构成 K(4,5) 完全二分图。
1,536 条 `(family,src)` 逐位命中 0 例外，跨 INT_L/INT_R 通用。
目标：FPL 短文。需新增：**同任务压缩比与预测精度对比表**（`§6.5-2`）。

**线 2（闭环 + 边界为主角）**
标题：*Closing the Loop, and Where It Breaks: Decoding and Re-encoding Virtex-7 Bitstreams*
摘要：从 `.bit` 到网表再到重综合位图的闭环在 2 个 slice 上 0 差异、全芯片 53 字差异；
写入方向 9/9 tile 清空重建 0 差异。我们进一步量化读出侧的信息论边界：
2 格 pattern 的候选数超过族内源数，误命中率 10.8%，min-cells=4 时精确率 100% 但召回仅 19.7%。
目标：FCCM 短文 / TRETS。需新增：**歧义下界定理**（`§6.5-1`）。

**线 3（检测视角，我认为最有胜算的方向）**
标题：*Bitstream Forensics for Virtex-7: Localizing Modifications via Decode–Resynthesize Diff*
摘要：因为能解码到网表并重综合回位图，任何对配置位的非授权修改都会在
"重综合位图 vs 实际位图"的差分中定位到具体 frame/word/bit。在真实设计上，
该差分把 20,273,538 B 的位流压缩为 53 个字的候选集。
目标：IEEE HOST / AsianHOST / DATE（安全 track）。需新增：**注入式篡改实验**
（改 1 位、改 1 条 PIP、改 LUT INIT，测检出率与定位精度），这是全新的、便宜的一组实验。

## 6.5 必补实验 Top 3

### 1. 把 2 格歧义证明成下界（堵 D2 与 D9 两条杀招）
- 目的：把"10.8% 误命中"从缺陷变成**定理**
- 做法：对 172 个 family 枚举 `(格池 k, 源数 n, 2 格组合 C(k,2))`；
  再跨族求"同一 2 格集合的全局候选数"。判据：存在 `候选数 ≥ 2` 的结构性下界，
  并给出"仅当 family 已知时可判"的充要条件
- 成功判据：给出闭式上界 `I(2 cells; pip) < log2 n` 的证明 + 与实测 10.8% 的一致性
- 工作量：**1–2 人日，纯分析，不需要 Vivado**（`T4:46-50` 已有雏形）

### 2. 与 prjxray 的同任务对比表（堵"这只是移植"）
- 目的：给出"生成式表示 vs 查表表示"的量化优劣
- 做法：在 **artix7 自己的 segbits**（`prjxray_ref/artix7/segbits_*.db`）上跑同一套
  `pip_reuse_law.py --verify`，测：①定律命中率 ②参数行数 vs 表行数 ③解码耗时
  ④2 格歧义比例。V7 与 artix7 各一列
- 成功判据：一张 4 行 × 2 列的表 + 一句"定律在 artix7 上同样成立/不成立"
- 工作量：**2–3 人日，纯数据，不需要 Vivado**。这一项同时解决 D2 与 D10

### 3. ECC 地址项闭合（堵"不能生成可加载 bitstream"）
- 目的：把 `ECC = L(data) ⊕ A(addr)` 的 A 测出来
- 做法：用 §32 已定位的 4 个"同数据不同 ECC"样本（`STATUS.md:1213-1226`，差值为
  0x9B3/0x9B4/0x9B5 一族）+ 造"同一逻辑放不同 slice/row"的成对设计，
  解 A 对 `(block, minor/col, row)` 的依赖；再回到 GF(2) 解 L
- 成功判据：留出 bitstream 上 ECC 逐帧 0 不符；给出 `ecc_model.py`
- 工作量：**5–7 人日，需远端 Vivado**（约 10–20 次 bitgen）

## 6.8 三条结构性风险（补了实验也可能被拒）

1. **同构风险**：V7 INT 位库 = artix7 位库（13/13 逐字节）。这不是靠补实验能消除的，
   只能靠**换问题**（定律/边界/检测）来绕开。若坚持"我们逆向了一个新器件"，必被拒。
2. **器件过时风险**：2026 年审稿人第一反应是"为什么不做 UltraScale/UltraScale+/Versal"。
   需要一句硬回答（例如：7 系列仍在产线大量部署；V7 是唯一有 207M PIP 规模可做规模效应研究的器件）。
3. **无硬件闭环风险**：所有 `.bit` 都是自己生成的（`REUSE_RULES.md:234-235`），
   最坏情况下审稿人会说"你证明了与 Vivado 的字节一致，但没证明器件接受"。
   缓解：把主张严格限定为"bit-exact re-encoding vs 参考实现"，并在 limitation 里写死。
