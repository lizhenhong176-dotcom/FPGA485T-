                       摘       要

  现场可编程逻辑门阵列（Field Programmable Gate Array，FPGA）作为可重构
计算体系的代表器件，被日益广泛地应用于航空航天、高性能计算等领域。伴随
着 FPGA 的大规模应用，针对 FPGA 芯片的攻击手段也层出不穷，其中硬件木马
是 FPGA 芯片使用面临的最大威胁。值此背景下，学界也已开始关注 FPGA 产品
的使用安全，提出了一系列从网表或设计代码层面进行硬件木马检测方法。但是
在现实场景下, 用户只能获得配置 FPGA 的位流文件，这将大大限制硬件木马检测
的进行。因此，本文针对 FPGA 逆向工程技术进行研究，旨在从位流文件中恢复
设计信息以帮助进行木马检测。本文具体内容如下：
 （1）提出了一种针对 FPGA 引脚资源的逆向技术
  本文提出了一种针对 FPGA 引脚资源的逆向技术。首先，阐述了 I/O 模块的
映射测试方法，并搭建了一个自动化测试工具用于构建器件映射和位流映射数据
库。然后，提出了一种无需完整网络逆向就可以解决单元多值问题的新型逆向方
法，用于还原引脚使用及功能配置。实验结果表明，引脚逆向工具对 Spartan-6 系
列 FPGA 芯片有效，支持单端和差分两类引脚配置且逆向准确率可达 100%。
 （2）FPGA 逆向工程应用：引脚功能操控
  本文在引脚资源逆向工程的基础上，研究了两种引脚功能操控方法，包括可
编程逻辑操控和可编程连线操控，用于在位流层面直接对引脚的输入/输出信号
进行操控。后续实验表明，引脚操控工具可以实现目标引脚的功能操控，揭示了
FPGA 系统的脆弱性。
 （3）提出了一种针对 VersaTile 架构 FPGA 的逆向技术
  本文提出了一种针对 VersaTile 架构 FPGA 的逆向技术，包含位流映射测试、
逻辑器件特征提取和位流逆向三个方面。首先，基于抽象模型实现了一个自动化位
流映射测试工具，用于获取可编程器件和 UFL 连线控制位。其次，针对 VersaTile
物理特征变化的特点，提出了一种基于控制位变化的逻辑器件特征提取方法。最
后，实现了一个位流逆向工具，用于完成位流到网表的还原。实验表明，逆向方
法对 ProASIC3 系列 FPGA 芯片有效，可精准恢复器件配置和 UFL 网络信息。
  经验证，本文提出的逆向方法对多种架构类型的 FPGA 芯片有效，能够精准
地恢复位流中的设计信息，为后续硬件木马检测和位流重配置等应用提供支撑。


关键词：逆向工程，位流，FPGA，硬件安全

                                     ABSTRACT

     As a representative device of reconfigurable computing system, Field Programmable
Gate Array (FPGA) is increasingly widely used in aerospace, high-performance comput-
ing and other fields. With the large-scale application of FPGA, the means of attacking
FPGA chips are endless. Among them, hardware Trojans are the biggest threat to the use
of FPGA chips. In this context, the academic community has also begun to pay attention
to the use security of FPGA products and proposed a series of hardware Trojan detection
methods from the netlist or design code level. However, in real scenarios, users can only
obtain the bitstream file that configures the FPGA, which will greatly limit the detection
of hardware Trojans. Therefore, the thesis studies FPGA reverse engineering technology,
aiming to recover design information from the bitstream file to help Trojan detection. The
specific contents of this paper are as follows:
     (1) A reverse engineering technology for FPGA pin resources is proposed
     The thesis proposes a reverse engineering technology for FPGA pin resources. First,
the mapping test method of I/O modules is explained, and an automated test tool is built to
build device mapping and bitstream mapping databases. Then, a new reverse method that
can solve the unit multi-value problem without complete network reverse engineering is
proposed to restore pin usage and function configuration. Experimental results show that
the pin reverse engineering tool is effective for Spartan-6 series FPGA chips, supports
single-ended and differential pin configurations, and the reverse engineering accuracy can
reach 100
     (2) FPGA reverse engineering application: pin function manipulation
     Based on the reverse engineering of pin resources, the thesis studies two pin function
manipulation methods, including programmable logic manipulation and programmable
connection manipulation, which are used to directly manipulate the input/output signals
of the pins at the bitstream level. Subsequent experiments show that the pin manipulation
tool can realize the functional manipulation of the target pins, revealing the vulnerability
of the FPGA system.
     (3) A reverse engineering technology for VersaTile architecture FPGA is proposed
     The thesis proposes a reverse engineering technology for VersaTile architecture FPGA,
which includes bitstream mapping test, logic device feature extraction and bitstream rever-

sal. First, an automated bitstream mapping test tool is implemented based on the abstract
model to obtain programmable devices and UFL connection control bits. Secondly, based
on the characteristics of the physical feature changes of VersaTile, a logic device feature

tool is implemented to complete the restoration of bitstream to netlist. Experiments show
that the reverse method is effective for ProASIC3 series FPGA chips and can accurately

     It has been verified that the reverse method proposed in this paper is effective for
FPGA chips of various architecture types and can accurately restore the design information

1.1 研究背景与意义
  近年来，随着工业控制、网络通信、人工智能等新一代信息技术的快速发展，
FPGA 因其高性能和灵活性，被越发广泛地用于航空航天、通信、高性能计算等各
个领域。例如，由于 FPGA 在速度及并行处理上的优势，被广泛用在基站天线的
收发器中完成多通道信号波束成形的功能[1] ; 一些深空探测器和卫星使用 FPGA 芯
片来完成图像处理和导航功能，如我国的嫦娥五号探测器等[2] ; 在高性能计算领域，
微软的 Catapult 项目通过使用基于 FPGA 的服务器方案，将数据中心的性能在传
统架构方案的基础上提升了 95%[3] 。

  伴随着 FPGA 使用的日益广泛，针对 FPGA 芯片进行攻击的手段也层出不穷，
其使用安全性面临着巨大的威胁。从 FPGA 设计开发流程上来看，FPGA 产品的开
发主要经历两个阶段。阶段一可以看作是 FPGA 芯片的制造，在该阶段国内外的
制造厂商基于自身开发的 FPGA 架构方案和技术路线对 FPGA 芯片进行设计，然
后交给代工厂进行生产和测试，最后将生产的 FPGA 芯片投放到市场。阶段二可
以看做是 FPGA 芯片功能的配置，在阶段二中设计开发人员需要根据产品功能需
求使用 EDA 软件对 FPGA 芯片功能进行设计，最终得到可使用的 FPGA 产品。这
种分工协作的开发方式使得 FPGA 产品在构建的各个阶段容易受到来自恶意攻击

者的威胁。据研究表明，在目前使用的攻击手段中，硬件木马是 FPGA 芯片面临
的最大攻击手段，其可以通过植入非法逻辑造成 FPGA 产品的功能更改甚至瘫痪。
例如：文献 [4] 中提出了一种工具来预测映射到 FPGA 上的功能设计所引起的老化
退化量，并指出 FPGA 器件的老化与加载的设计有关，据此恶意攻击者可以通过改
变 FPGA 加载的设计达到加速硬件老化的目的；Chakraborty 等人提出了在 FPGA
配置位流的未使用部分插入 TYPE-I 型硬件木马的方法，并成功在 AES-128 标准电
路中插入环形振荡器用于提高设备运行的温度，达到降低设备寿命的目的[5] ;2020
年，Ender 等人提出了一个框架用于对配置位流进行操作，以达成替换 FPGA 中查
找表资源（LUT）的代数表达式和设置/取消单个连线资源的目的[6] 。图1-1展示了
FPGA 产品在设计开发工程中受到的硬件木马威胁。
   针对硬件木马的检测，也一直都是国内外学者研究的重点。硬件木马检测方
法大致可分为两种，一种是通过侧信道信息，如功耗，电磁等物理信息来对芯片进
行木马检测[7, 8] 。利用芯片在植入硬件木马后运行时物理场信息发生变化的特性，
将待检测芯片的侧信道信息与正常芯片进行对比可以判断芯片是否含有木马电路。
使用侧信道信息的检测方法容易受到背景环境噪声的影响，同时大部分的侧信道
检测方法依赖于无木马电路的“黄金电路”。另一种针对硬件木马的检测方法是基
于逻辑分析的检测方法，利用木马电路具有隐蔽性的特点，通过对设计的硬件描
述语言（Hardware Description Language，HDL）或者网表的分析，识别 RTL 代码
中难以被执行的部分和网表中未用的电路逻辑，可以检测电路中潜在的木马[9, 10] 。
相较于第一类的木马检测方法，第二类采用逻辑分析的木马检测无需“黄金电路”，
且对于小型木马更加敏感，能够更加准确的识别设计中隐藏的硬件木马。
   虽然上述介绍的基于逻辑分析的木马检测方法能够很好地对芯片和设计进行
木马检测，但是这种检测方法的输入必须是 RTL 代码或者网表。而在实际场景中，
FPGA 产品用户只能获得由二进制 0 和 1 组成的配置位流，并且由于 FPGA 制造
厂商出于安全考虑对于位流生成细节的故意隐藏，配置位流对于普通用户而言并
不具备可分析性，所以难于在位流层面进行直接的木马检测。要对 FPGA 的配置
位流进行木马检测，一种行之有效的方法就是将位流文件转化为可以检测的网表
文件然后再进行木马检测。
   要实现位流文件到可进行木马分析的网表文件的转化，需要借助于 FPGA 逆
向工程。同时，研究人员在逆向工程的帮助下可以更清楚地探究芯片内部结构，了
解功能设计细节。因此，逆向工程也可用于 IP 的盗版及检测。另一方面，逆向工
程中对于器件和位流映射的测试, 可以实现位流层面的部分重配置，将大大缩短
FPGA 重配置时间。除此以外，研究 FPGA 芯片架构、位流编码方式和反向设计技

   本文的主要工作内容就是从 FPGA 芯片底层结构出发，获取内部可编程器件

设计信息，从而为后续硬件木马检测等应用提供支撑。


1.2 国内外研究现状
   逆向工程技术一方面可以帮助检测网表中的 IP 是否存在盗版及为硬件木马检
测提供支撑，另一方面又可为恶意攻击者窃取他人设计和恶意木马植入提供便利。
在过去的十多年里，随着研究人员对逆向技术研究的深入，目前对复杂位流的操
纵和逆向工程已日益成为现实。
   对 FPGA 配置位流进行研究的工作可以追溯到 2001 年，由 Horta 等人提出了
一个名为 PARBIT 的工具用于在 FPGA 内部定义部分可重构区域并对位流进行部
分重构[11] ；2006 年，由德国的 Ziener 等人展开的针对 Xilinx Virtex-II 位流文件的
逆向工作揭示了 FPGA 逆向工程的可行性。他们在文献 [12] 中提出了一种方法来
提取 FPGA 位流中使用的 LUT 资源位置信息及配置，并介绍了一种基于查找表分
析的 IP 核识别方法，用以进行 IP 保护；2008 年，Note 等人提出了一种获取网表配
置和比特流之间相关性的方法，并对多个系列的 FPGA 芯片建立了映射数据库。在
此基础上还推出了针对 Xilinx 公司 FPGA 芯片的逆向工具——Debit[13] 。但是该工
具仅能恢复部分 PIP 且无法从比特流中重新生成完整的 XDL 文件；2012 年，Benz
等人引入汇总 FPGA 所有内部器件的资源数据库来对 Debit 工具进行改进，开发
了更加完善的 BIL 工具[14] 。BIL 工具使用资源数据库作为映射数据库的测试来源，
大幅提升了映射数据库的完整性；2017 年，Pham 等人开发了一个名为 BITMAN
的工具。该工具不仅能从 FPGA 位流中提取使用的器件资源位置，还支持模块位
置移动和复制，路由修改及 LUT 设置等位流操作功能[15] 。2018 年，Yoon 等人在
Debit 和 BIL 工具的基础上开发了更加完善的逆向工具——BRET 系统[16] 。其通过
恢复所有的可编程连线和查找表资源可以将任意位流逆向为网表，除此之外系统
还具备硬件木马检测的能力；2021 年，Yu 等人提出了一种基于最新的 Vivado 设
计套件环境的 FPGA 逆向工程方法[17] 。该方法通过结合来自可编程逻辑资源的数
据和从比特流中提取的可编程连接来恢复完整的电路，并在 ARTIX-7 系列芯片上
对 3 位加法器电路进行了逆向工程且取得了不错的效果；2022 年，Kashani 等人实
现了一个自动化映射收集工具——Bitfiltrator[18] 。它使用系统算法来定位逻辑资源
控制位在比特流中的精确位置，并在 34 个 UltraScale 和 UltraScale+ 系列 FPGA 上
使用 Bitfiltrator 工具来定位 LUT 初始值的配置位、LUTRAM 和 BRAM 内容以及

寄存器值。2023 年，Zhang 等人提出了 BitFREE 方法[19] ，该方法利用 FPGA 架构
和配置内存映射之间的相关性，将配置帧分解为更细粒度的片段进行智能并行分
析，大大缩短了映射测试的花费时间。除了上述介绍的完整针对 FPGA 配置位流

不是逆向工程的工具，但它为网表文件的转换、映射、放置、路由和位流文件的
解析、操作和导出提供了便利，大大方便了逆向工程的开展。
   除了上述针对 Xilinx FPGA 芯片的研究之外，研究人员还对其他厂商的 FPGA
芯片进行逆向技术研究。例如，Icestrom 是一个针对 Lattice ice40 系列 FPGA 比特
流进行逆向的开源项目[22] ，其使用 Icebox_vlog 工具将配置位流逆向到 RTL 设计
文件；2018 年，Celebucki 等人对 LATTICE ECP3 系列 FPGA 芯片的逆向展开研究
工作。在文献 [23] 中，他们重点对 FPGA 内部的输入/输出块和查找表资源进行了
映射测试，在此基础上提出了一个位流分析工具用以还原位流中输入/输出块的
配置信息和查找表的逻辑功能。文献 [24] 中指出 Altera 提供的 QUIP 程序接口可
以帮助完成特定网表创建，设备架构和关键时序信息访问，逻辑元件的位置和路
由指定等功能[25] ，据此可以帮助实现针对 Altera 的逆向工具。但是 QUIP 仅支持
Quartus II 系列 FPGA 芯片，这大大限制了针对 Altera FPGA 芯片的逆向工程的发
展。2021 年，韩国的 Kim 等人针对 Microsemi 厂商的 ProASIC3、IGLOO2、Fusion
三个系列的 FPGA 芯片逆向工程进行研究[26] 。他们提出了一个分析模型用于构建
芯片内部核心逻辑的映射数据库，在此基础上研究了一种逆向方法用于还原电路
中的逻辑门。但是该分析工具无法将位流还原为网表结构，将会使其后续应用大
打折扣。
   伴随着 FPGA 芯片的大规模应用，国内的学者也开始关注 FPGA 的使用安全，
针对 FPGA 逆向工程的研究也是国内学者研究的重点。早在 2013 年，上海交通大

中使用测试样本数据已知（Position Known:PK）和测试样本数据未知（Position
Unknown：PUK）的分析方法来构建完备、准确的映射数据库，同时结合偏移量公

工具证明了逆向代码的功能等效性[28] 。但是该逆向工具针对网表的逆向时间较长

1.3 论文研究内容与结构安排
  本文主要对基于不同架构的多家厂商的 FPGA 芯片逆向工程技术进行研究。
研究从这些 FPGA 芯片的结构特点出发，采取了不同的方法完成位流映射收集，
并在此基础上针对性的提出了相应的逆向方法用于实现位流到器件资源和网表的
还原。本文还进一步提出了多种直接在位流层面进行引脚功能操控的方法，并在
有关 FPGA 设备上进行了实验，揭示了 FPGA 系统的脆弱性。
  本文一共分为五个章节，以下是论文的章节安排：
  第一章首先介绍了在 FPGA 大规模应用背景下可能面临的来自恶意攻击者的
安全问题，并指出当前木马检测方法对于位流文件的局限性，从而引出了逆向工
程的意义。其次对国内外逆向工程的研究进展进行了梳理。最后总结了本文的工
作内容和结构安排。
  第二章对当前主流的 FPGA 芯片工艺类型进行了着重介绍并对比分析了各自
的优缺点。接着说明了 FPGA 芯片一种典型的体系结构，然后对逆向工程涉及的
各种文件进行介绍。最后是对逆向工程的整体流程进行概述，以简单分析逆向工
程的基本原理。
  第三章主要是对基于 SRAM 架构的 Xilinx 厂商 FPGA 芯片引脚资源开展逆向
研究。首先对引脚模块结构和功能进行了详细阐述，然后提出了一种器件映射测
试方法用于获取器件间的使用耦合关系。其次阐述了位流映射测试和偏移量测试
的原理，用于对 I/O 模块资源和连线资源进行位流映射测试。接着对现有的逆向算
法进行分析，在此基础上提出了一种无需完整网络逆向的引脚逆向方法以减少逆
向时间开销。除此以外，本章还提出了多种引脚操控方法用于在位流层面直接对
引脚功能进行操控。最后通过实验说明了相关方法的有效性和准确性。
  第四章主要是对基于 FLASH 架构的 Microsemi 厂商 FPGA 芯片开展逆向研
究。首先介绍了针对核心逻辑 VersaTile 和 UFL 连线资源的的位流映射测试方法，
然后将测试方法进一步推广用于其他类型器件测试。接着，基于器件间的偏移量
规律引入偏移量测试以加快映射数据库构建。对于逻辑器件在不同功能配置下的
特征变化，提出了一种基于控制位测试的自动化特征提取方法。在此基础上，基于
映射数据库和特征数据库，提出了一个逆向框架用于实现位流到网表的还原。最
后，通过实验对相关方法进行了验证。
  第五章总结了全文的主要工作内容，并提出了后续的工作展望。

2.1 FPGA 芯片工艺类型
  FPGA 芯片相较于其他计算芯片最大的特点是其可编程特性，这种可编程特
性依赖于底层的可编程开关实现。现代 FPGA 芯片中常用的可编程开关实现技术
包括 SRAM、FLASH 和反熔丝三种类型，对应地可将 FPGA 芯片划分为这三种工
艺类型。本小节中对这三种 FPGA 芯片工艺类型进行介绍。
  SRAM 型 FPGA 芯片又称静态存储器型 FPGA 芯片，是当前市场上主流的
FPGA 芯片类型[29] ，市场占比最大的两个芯片厂商——Xilinx 和 Altera 都采取了
SRAM 工艺进行 FPGA 芯片的设计制造。静态存储单元的结构如图2-1所示[30] 。两
个传输晶体管和两个反相器构成的触发器组合在一起共同实现了静态存储器单元。
静态存储单元通过双稳态触发器存储数据，数据的写入通过对传输晶体管的控制
完成。具体来说，通过字线（WRITE）控制传输晶体管导通后，数据可由数据端
口（DATA）写入。在传输晶体管关断时，存储单元值将保持不变，据此可以实现
对 SRAM 单元的编程。

   XDL 网表由设计信息、实例信息、网络信息三部分组成。设计信息包含当前
模块设计名、使用芯片型号等信息。
   实例信息代表了当前设计使用的所有底层器件资源。实例信息通常由若干个
实例块构成，每个实例块包含实例名、器件类型、器件位置和内部逻辑元件的配
置状态等信息。
   网络信息代表了实例资源之间的连接关系。每个网络包含一个驱动网络的输
出端口（outpin）和多个接受信号的输入端口（inpin）。同时网络还包含连接端口
的路由所使用的 PIP 等信息，而对于网络使用的固定连接信息将不在 XDL 中进行
展示。
   在将设计经综合和实现过程得到 NCD 网表后，设计人员可以继续执行位流生
成过程以获得最终用于配置 FPGA 芯片的位流。位流文件采用二进制形式进行存
储，包含对 FPGA 芯片的配置命令和配置数据。在进行配置时，由 FPGA 芯片内
部的寄存器执行这些配置命令以将配置数据写入。整个位流文件分为头部信息区、
配置命令字段、配置数据字段、尾部校验区四个部分。
   头部信息区：包含工程名、生成时间和同步字等信息。同步字是 32 位序列，
用于使配置数据与内部配置逻辑保持一致，以提醒 FPGA 配置命令的开始，在同
步字之前配置接口上的任何数据都将被忽略。对于不同的 FPGA 芯片型号同步字
可能会存在差异，较常使用的两种同步字序列为 0xAA995566 和 0xAA9930A1。
   配置命令字段：用于向 FPGA 内部的配置寄存器写入命令，以完成配置选项
的设定。例如可以通过 COR1 和 COR2 寄存器写入对应数据实现禁用 CRC 校验的
功能。
   尾部检验区：包含位流文件的 CRC 值和一些写入配置寄存器的命令，如向
FPGA 芯片内部的 CRC 寄存器写入 CRC 值的命令。
   配置数据字段：用于配置芯片内部的可编程器件，是位流的主要部分。配置
数据按帧进行划分，每帧为 1 位宽，高度不固定与 FPGA 内部资源行数有关。配
置同一类型器件的帧构成帧组，数据区包含 CLB、IOB、BRAM 等类型帧组。针
对不同类型的资源所需配置帧宽度不同，以 Virtex5 系列 FPGA 为例，CLB 列需要
36 帧进行配置而 IOB 列则需要 54 帧[42] 。

2.3 FPGA 芯片逆向流程
     FPGA 芯片逆向工程的主要目的是将配置位流还原为网表文件以方便后续应
用。而在正式进行逆向环节之前，逆向工具通常还需要完成位流预处理和位流映
射收集两个过程。
     位流预处理环节的主要目的是将输入位流转化为可进行逆向的位流，这个环
节是一个可选的环节。目前的逆向工程只能对非加密非压缩的位流进行逆向，而
对于一些压缩和加密的位流还需要进一步处理才能被逆向工程使用。学界对于位
流解密和解压缩这些先导工作的研究也如火如荼的进行，并提出了一系列相应的
方法。例如文献 [45] 中介绍了一种基于压缩位流放置技术的并行解压缩方法，用
于实现位流解压缩。文献 [46] 中提出了一种针对高版本 FPGA 芯片的位流解密方
法，该方法利用 FPGA 的设计缺陷通过对内部特殊寄存器进行操作来读取解密内
容。
     位流映射收集的主要目的是为了获取位流和 FPGA 内部资源间的映射关系。
出于安全考量，FPGA 厂商并不会公开位流和器件资源间的映射关系。所以在进行
逆向工程之前，还需要获取这种“非公开”的关系并存储下来以形成数据库。这
种映射收集方法的基本原理主要是通过修改网表中器件的配置并对比位流来获得。
可以说位流映射数据库是逆向工程基石，逆向工程只有建立在准确完备的数据库
基础上，才能实现逆向的高精度。
     位流逆向则是逆向工程的目的和核心，旨在将位流还原为网表以为后续进一
步应用提供方便。整体来看位流逆向环节可分为位流比对和信息处理与整合这两
个主要环节。位流对比环节主要是将位流与映射数据库进行比对以获取其中使用
的器件资源，包括实例资源和连线资源。信息处理与整合环节则是对上述得到的

分散器件资源做进一步的处理以实现网络构建和器件功能配置的最终判定，最后
按照相应网表格式规则输出出来。

        第三章 SRAM 型 FPGA 芯片引脚逆向与应用

  针对 Xilinx 厂商 SRAM 型 FPGA 芯片逆向工程的研究，是当前学界对于 FPGA
安全的关注重点。适用于 Xilinx FPGA 芯片的逆向工具有很多，但是大部分的逆向
工具都重点关注核心逻辑资源如 SLICE、LUT 的逆向。而 I/O 模块作为和外部电
路连接的关键部分同样也应受到重视，但是专门用于 I/O 资源的逆向工具目前较
少。同时，大部分逆向工具引脚逆向时间花销大且支持配置有限。基于此，本章
针对 FPGA 芯片的 I/O 资源进行逆向研究，涉及 I/O 资源映射数据库构建和引脚逆
向工具实现两个方面。在此基础上，将逆向工程技术进一步运用，提出了多种引
脚操控方法用于在位流层面操控引脚的输入/输出行为。


3.1 FPGA 芯片 I/O 模块映射数据库构建
  在 SRAM 型 FPGA 芯片配置中，上电后 FPGA 芯片会使用专用配置接口从外
部非易失性的存储器件（如 FLASH 存储器等）中读取配置位流，并将配置位流按
照一定的帧结构划分用以完成 FPGA 内部器件资源的划分。所以要进行 I/O 模块
逆向工程的前提就是获取 FPGA 内的 I/O 模块在位流中的控制值，本文把这种网
表和位流的互关性称为器件-位流映射关系，下称位流映射关系。I/O 模块除了熟
知的 I/O 引脚外，还与 FPGA 内部的 I/O 逻辑资源配合以完成完整的信号传输过
程。由于 I/O 模块信号通路的固定性，I/O 引脚和这些 I/O 逻辑资源在使用上存在
对应关系，本文把这种关系称为器件映射关系。
  本节将首先介绍 I/O 模块结构，然后从 I/O 结构特点出发介绍器件映射关系的
测试方法，最后分别针对两种 I/O 模块配置方式——单端 I/O 和差分 I/O 提出相应
的位流映射测试方法。

3.1.1 I/O 模块介绍
  I/O 模块通常位于 FPGA 芯片的边缘区域，作为芯片与外部电路的接口，对外
负责在不同电气特性下驱动与匹配输入/输出信号，对内则是通过寄存器实现输入
延迟和数据速率的调整。在 Spartan-6 系列 FPGA 芯片中，I/O 模块包含 I/O 引脚和
I/O 逻辑资源两种类型结构，二者相互配合以完成完整的信号传输过程，如图3-1是
I/O 模块结构示意图。
  I/O 引脚部分主要完成信号输入/输出、进行差分计算和控制电气特性的功能，
结构相对简单；而 I/O 逻辑资源是 I/O 引脚和 FPGA 内部处理逻辑之间连接的桥梁，

输入/输出信号在 I/O 逻辑资源的处理下得以满足时序要求，同时其还兼备串并转

OSERDES、IODELAY。ILOGIC 逻辑即输入信号处理逻辑，用于对外界输入的信
号进行处理。其结构中包含了多个数据选择器和一个双倍速率的寄存器，该寄存

同步串行信号转换成内核逻辑需要的并行数据；OSERDES 即输出并串转换器，用

3.1.2 I/O 模块器件映射测试
  FPGA 芯片的 I/O 模块在用户逻辑设计中扮演着重要的角色，是 FPGA 芯片和

3.1.3 I/O 模块位流映射测试
   研究人员想要完成逆向工程，前提就是要获得网表中可编程点与位流文件的
映射关系。为了对位流映射测试过程进行更清晰的阐述，首先给出如下的定义。
   定义 3.1：FPGA 芯片中的可配置资源统称为可配置点（Configurable Point，
  ，其可以分为可配置互连点（Programmable Interconnection Point，PIP）和可配
CP）
置逻辑点（Programmable Logic Point，PLP）。可配置逻辑点除了关闭状态外至少
                                               。
还有一种设置选项，将这些设置选项称为可配置选项（Configuration Option，CO）
可编程逻辑点的所有配置选项构成的集合称为可配置集（Configuration Collection，
CC）。
   定义 3.2：FPGA 中的可编程点在位流文件中都由若干个数据位进行表征，每
一个单个的数据位都是该可编程点的控制位（Control Bit，CB）。
   定义 3.3：控制位在位流中的位置使用控制位地址（Control Address，CA）进
行表征。控制位地址由字节地址和位地址构成，字节地址表示当前控制位所在字
节数和同步字的距离，而位地址代表位于该字节中的地址。其中，字节地址也称
主地址，位地址也称副地址，二者共同构成了控制位在位流中的唯一表征。
   定义 3.4：将可编程点的所有控制位按照控制位地址递增的顺序排列，构成的
有序集称为控制位集合（Control Bit Set，CBS）。
   定义 3.5：位流中控制位地址上的二进制值数据 0 或 1 称为控制值（Control
Value，CV）。控制位集合对应的所有控制值称为控制值集合（Control Value Set，
CVS）。
   基于上述定义，可以将位流映射关系的测试抽象分为两类，一是获取 PLP 的
可配置集下的每一个可配选项在位流中的控制集合和控制值集合，二是获取每一
条 PIP 在位流中的控制位集合和控制值集合。

3.1.3.3 可编程连线位流测试

   FPGA 芯片中器件之间的连接依靠可编程连线（PIP）完成，在完成器件布局
后，EDA 工具将通过路由算法决定使用那些 PIP 构成信号传输的网络。在 Xilinx
FPGA 芯片中，PIP 按照分布位置可分为位于交换盒内的 PIP 和交换盒外的 PIP。
交换盒外的 PIP 大部分都是连接器件端口的 PIP，这类 PIP 的起点和终点都相对唯
一，不存在一对多或多对一的情况。逆向时，可以通过器件端口或前后级 PIP 判
断其使用情况。而交换盒内的 PIP 情形与之相反，起点和终点都不唯一，逆向时
需要进行位流比对以恢复。同时，交换盒内的 PIP 按其流向又可分为单向 PIP 和
双向 PIP 两类。单向 PIP 在 XDLRC 文件中使用符号“->”进行表征，信号只能从
符号左边的连线传输到右边的连线。双向 PIP 使用符号“=-”进行表征，信号传输
可以从符号左边流向右边又可从符号右边流向左边，在网络中具体的流向由前后
级 PIP 控制。
   PIP 的位流映射测试简单来说就是通过将使用该 PIP 的位流和未使用 PIP 的位

3.3 逆向工程应用：I/O 模块操控
  设计用户在 FPGA 芯片上实现的功能，最终会映射到内部的可编程逻辑和可
编程连线上。所以理论上，通过修改位流中这些可编程点的控制位，可以达到在
位流层面直接修改设计功能的目的。
  本节基于 I/O 位流映射数据库和逆向信息，提出了一种用于 I/O 引脚功能操控
的工具，实现的功能包括引脚禁用、高输出和低输出三种。工具支持两类操控方
式，分别是针对可编程逻辑和可编程连线的操控，这两种操控方法的流程也将在
本节进行阐述。最后对这两种操控方式的特点进行了比较。

3.3.1 可编程逻辑操控
  可编程逻辑操控即是在位流层面对目标 PLP 的配置属性进行修改。可编程逻
辑操控的流程大致可分为控制位更改和 CRC 规避两个步骤，下面对这两个步骤进
行详细阐述。
  步骤一，控制位更改。这个阶段首先进行 PLP 数据库的遍历，以获取目标 PLP
及其配置属性的控制位，然后在位流中修改对应控制位以完成 PLP 属性更改。
  步骤二，CRC 规避。为了对 FPGA 芯片进行保护，ISE 等工具在生成位流时
会在位流中嵌入一个 32 位 CRC 值来对位流进行校验。同时所有 Xilinx FPGA 都
包含 CRC 电路，用于在加载配置位流时从配置数据包中计算出一个 CRC 值。在
完成配置数据帧加载后，配置位流向 FPGA 发出 CRC 检查指令，同时给出期望的
CRC 值。如果 FPGA 计算的 CRC 值与比特流中存储的 CRC 值不匹配，那么 FPGA
将终止配置。所以仅对配置帧数据修改将无法得到可重配置的位流。为了获得可
执行的位流，一种方法是对更改位流重新计算 CRC 的值，另外一种方法就是通过
修改位流的命令配置部分和 CRC 值来禁用 CRC 检查。
  上面介绍了可编程逻辑操控的整体流程。下面结合信号通路，给出针对输出
引脚的操控方法，输入引脚禁用方法与之类似这里将不再赘述。针对输出引脚的
可编程逻辑操控，主要是对输出信号通路中的上下拉电阻操控和寄存器属性进行
操控。两种操控方式的示意图如图3-14所示。

3.3.3 操控方式比较
  可编程连线操控和可编程逻辑操控是针对 FPGA 芯片内部资源的两种常用操
控方式，可以实现位流层面的直接木马植入，是当前 FPGA 产品安全面临的一大
威胁。同时两种操控方法还可根据具体器件特征结合使用，以达到更大的灵活性
或者更多的功能。本小节对这两种操控方式进行对比，以阐述各自的优缺点。
  可编程连线操控是一种更加通用的操控方式，由于所有资源逻辑都需要可编
程连线完成路由，其可以不受具体可编程逻辑内部结构的影响。此外，可编程连线
攻击还可以用于实现内部信号的观察，结合一定的路由算法和逆向分析，用户可
以重新配置路由网络以将节点的信号传输到观察窗口（I/O 引脚、ChipScope 工具
等）上进行观察。可编程连线操控的缺点也很明显，一是容易对其他后级 PIP 造成
干扰，二是需要测试逻辑资源的器件映射关系或进行逆向分析以获取操控的 PIP。

  关于可编程连线操控的干扰性如图3-16所示。这种干扰发生的前提就是操控
的 PIP 除了驱动该逻辑器件外还驱动其他器件。当对该 PIP 进行重新设置后，目
标器件操控的目的达成，但是其他节点的输入信号也将发生更改进而对其他器件
的工作造成影响。综上所述，可编程连线操控是一种一对多的操控方式。
  可编程逻辑操控的通用性较差，主要体现在两个方面，一是由于不同逻辑资
源内部信号通路和属性不同，对于不同逻辑资源的操控方法需要结合相应的 PLP
进行使得操控的 PLP 不尽相同；二是信号端口操控失效，可编程逻辑操控依赖于
信号通路中的 PLP（如 MUX 等），而部分逻辑资源器件的端口并不与任何 PLP 相
连，此时端口操控将无效。干扰性上，可编程逻辑操控只会对目标器件和其输出
造成影响而不会对其他同级器件造成影响，可控性更好。最后是在器件映射关系
上，某些可编程逻辑操控只需确定操控的逻辑位置和 PLP 属性，可以无需进行器

  为了评估数据库和逆向方法的正确性，实验时首先输入测试样本电路并通过

Rate，IR）和准确率（Accuracy Rate，AR）两个指标，指标定义如下。
  完整率是指逆向出的引脚资源占实际使用引脚资源总数的比例。例如，针对

资源总数为 𝑇𝑖𝑜 ，则逆向完整率记为，

                          𝐼𝑅 = 𝑅𝑖𝑜 /𝑇𝑖𝑜                     (3-2)

              第四章 FLASH 型 FPGA 芯片逆向

     FLASH 型 FPGA 芯片因其高可靠性和低功耗的特点，被广泛应用在航空航天
和国防等高端应用场景。按理说这类 FPGA 芯片的安全更应受到重视，但是学界
对于 FLASH 型 FPGA 芯片逆向工程的研究还处于起步阶段，大多数学者的精力主
要还是集中在针对 Xilinx FPGA 芯片的逆向上。同时，当前的逆向工具暂不支持位
流到网表的还原，将使后续应用受限。
     针对这种现状，本章将对 Microsemi 厂商的基于 VersaTile 架构的 FLASH 型
FPGA 芯片进行逆向研究，研究按照映射数据库构建、器件特征提取、网表逆向的
步骤进行。映射数据库构建环节主要是获取芯片中可编程器件和位流之间的非公
开关系并存储下来，由于 Microsemi 中可编程器件“黑盒”的特点，采用了一种基
于功能逻辑测试的方法来进行控制位提取。一个 VersaTile 可以配置成多达百种组
合和时序逻辑，这么多功能逻辑的实现依赖于内部的功能开关配置和器件端口的
变化，器件特征提取环节则是对不同功能逻辑配置下的 VersaTile 的端口特征进行
分析。网表逆向则是本章要实现的最终目的，用于将位流还原为网表。


4.1 FPGA 芯片位流映射测试
     本节主要研究 FPGA 芯片的映射提取方法，用于获取可编程器件在位流中的
控制位并存储下来以形成映射数据库，进而为后续逆向提供支撑。本节将首先阐
述了一种通用的可编程逻辑映射测试方法，用以构建包含多种逻辑器件的位流映
射数据库。然后针对可编程连线中的一类连线资源——UFL 连线进行了映射测试。
最后针对不同位置器件控制位间存在整体偏移的特点，采用了偏移量测试方法来
加快映射数据库构建过程。
     在正式进行位流映射测试之前，首先给出如下猜想，后续会通过实验进行证
明。
     猜想 4.1：FPGA 芯片中的每个可编程开关对应于位流中的 1 个控制位。可编
程开关在导通状态时控制值为 1，关闭状态控制值为 0。

4.2.1 完整性特征提取
    逻辑功能的完整性状态不能简单的从实现逻辑获得。例如 OR3 门从功能上来
讲虽然无需对输出进行取反，但是根据实验结果来看，OR3 门等价于 NAND3C
门，其也是非完整状态逻辑。从 VersaTile 结构进行分析或许是一个值得尝试的方
法，但是 VersaTile 内部结构复杂，分析起来也存在一定难度且相对费事费力。一
种可选的方法就是非完整逻辑的实现形式入手。
    如图4-5展示了非完整逻辑对后级电路的影响。完整逻辑无需借用后级 NDS

关系会进一步反映到位流中，而这也正是基于完整性的 NDS 的测试原理。基于此，
本节提出了一种基于控制位变化的自动化完整性特征提取方法。

4.2.2 输入反转特征提取

10     end
11 end

4.2.3 端口映射特征提取
  图4-1给出了时序逻辑的逻辑端口和物理端口间的对应关系。但是对于组合逻
辑的端口间对应关系，官方技术文档并没有给出。并且结合实验来看，不同组合
逻辑功能的逻辑端口和物理端口之间的对应关系并不固定。而 EDN 网表中的端口
使用的是逻辑端口，要想逆向出正确的网表，就必须在获得物理端口连接的基础
上进一步推断出逻辑端口。为此，本节将给出一种确定组合逻辑虚拟端口和物理
端口映射的方法，以提取端口映射特征为后续逆向提供支撑。
  改变组合逻辑功能的逻辑端口使用状态，对应的物理端口的控制位将在位流
中发生变化。基于这个特征，采取一种基于控制位的自动化端口特征提取流程，
流程大致分为物理端口控制位获取、逻辑端口控制位获取、控制位匹配三个步骤。

4.3.3.3 物理网络映射

   如前所述，网络逆向的结果使用 VT(X1,Y1)-OutPin->VT(X2,Y2)-InPin 的形式
进行表征，其中的端口 Pin 为物理端口, 而 EDN 网表中的合法网络使用逻辑端口
间的连接进行表征。所以需要在得到物理连接网络的基础上，将其进一步映射成
为使用逻辑端口的网络，才能输入到 EDN 网表中以形成正确的网络。
   物理网络到逻辑网络的映射，需要借助端口映射数据库完成。物理网络映射
流程如下：
   Step1：获取位置为 VT(X2,Y2) 的 VersaTile 逻辑功能恢复结果（记为 Func)。
   Step2：在端口映射数据库中查询逻辑功能 Func 下的端口对应关系，然后将网
络中物理端口使用逻辑端口进行替换。
   Step3：在得到所有网络连接关系后，将来自同一起点的网络进行合并，整合
成一个网络输出到 EDN 网表中。

4.5 本章小结
  本章主要的工作是对 Microsemi 的 FLASH 型 FPGA 芯片逆向技术进行研究，
主要工作可分为位流映射测试、逻辑器件特征提取、逆向算法研究三个方面。在
位流映射测试上，首先基于 VersaTile 分析模型，设计了一个自动化的位流映射测
试工具用于对 VersaTile 的控制位进行测试。此后又将分析模型进一步推广用于其
他器件资源的位流测试。除此以外，本章还对一种连线资源——UFL 连线的结构
进行了分析，并根据连线特点提出了对应的位流映射测试方法。在此基准上还发
现了器件控制位间存在偏移量关系，并采用了基准测试和偏移量测试的方法来优
化映射提取过程。对于逻辑器件特征的提取，受制于 VersaTile 内部开关配置组合
复杂难于通过分析方法获取的问题，采取了一种基于控制位的自动化分析方法来
进行特征提取，包括对完整性特征、输入反转特征和端口映射特征的提取。在逆
向算法研究上，本章提出了一个逆向工具或者说是逆向框架用于实现将位流还原
为网表文件和约束文件。本章最后，通过实验对相关方法进行了验证。实验表明，
本文提出的位流映射构建方法、逻辑器件特征提取流程、逆向算法是有效的。

               第五章 全文总结与展望

5.1 全文总结
  本文主要针对多种架构类型的 FPGA 芯片进行位流逆向工程技术研究。主要
的工作可以分成两个方面，一是针对基于 SRAM 架构的 Xilinx FPGA 芯片进行引
脚资源的逆向研究，二是针对基于 FLASH 架构的 Microsemi FPGA 芯片开展位流
逆向工作。前者用于精准地还原位流中使用的引脚资源，并为后续的引脚操控提
供方便；后者则提供了一个逆向框架用于实现位流到网表的还原。全文的主要工
作如下：
 （1）阐明 FPGA 逆向工程的研究背景与意义，梳理了国内外对于逆向工程的
研究进展。介绍了逆向工程涉及的网表和位流文件，对比了基于不同类型工艺架
构的 FPGA 芯片特点，概括了 FPGA 芯片结构和逆向工程流程。
 （2）发现了 I/O 模块中引脚资源和逻辑资源间的器件耦合关系，阐述了一种器
件映射关系的测试方法。介绍 I/O 模块位流映射数据库构建过程，实现对单端引脚
和差分引脚控制位的提取。针对可编程连线资源抽象出一个测试模型，并基于该
模型研究了一种准确收集其位流映射的方法。
 （3）研究现有的一些逆向算法，在此基础上针对 I/O 引脚资源的逆向提出一种
无需完整网络逆向就可以解决单元多值问题的逆向方法。将逆向工程进一步应用，
搭建了一个自动化的引脚功能操控工具，用于在位流层面对引脚功能进行操控。
最后通过实验证明了映射数据库构建方法、逆向算法和引脚操控方法的正确性。
 （4）以 Microsemi 基于 VersaTile 架构的 FPGA 芯片为目标，搭建一套自动化
的位流映射收集工具，工具可以实现对可编程器件资源和 UFL 连线资源的位流
映射测试，并在测试过程中引入偏移量规律来加快映射数据库构建过程。针对
VersaTile 在实现不同逻辑功能时物理特征不固定的特点，提出了一种基于控制位
变化的特征提取算法来构建逻辑器件的物理特征数据库。
 （5）针对基于 VersaTile 结构的 FPGA 芯片，提出了一个逆向框架用于实现位
流到网表的还原。重点阐述了一种针对输入/输出反转特征耦合的解决方法，整个
解耦过程分为输入级解耦、输出级解耦、固定特征解耦和滑动窗解耦四个环节。最
后逆向实验验证了逆向算法的有效性和准确性。

5.2 后续工作展望
  本文主要围绕 FPGA 逆向工程进行研究，涉及 SRAM 类型和 FLASH 类型两
种架构，分别实现了针对 Xilinx FPGA 的 I/O 引脚资源逆向方法和针对 Microsmei
FPGA 的位流逆向工具。但是本文的研究内容还有若干需要解决的问题，主要分为
如下几点：
  （1）本文对于 SRAM 型架构和 FLASH 型架构的 FPGA 进行逆向研究，每种
架构挑选一个主要 FPGA 厂商进行，而对于其他厂商的 FPGA 芯片尚未确定本文
的逆向方法有效。
  （2）本文第三章提出的位流映射测试方法虽然可以完成 FPGA 芯片可配置点
的控制位提取，但是在测试过程中并没有引入位流文件的具体帧信息。在后续研
究中，可以对位流文件的帧信息进行研究，有利于梳理 FPGA 位流配置机理，从
而加快位流映射测试过程。
  （3）本文第四章提出的自动化位流映射测试工具只支持 UFL 连线，受制于
开发工具原因暂不支持其他类型连线资源的测试，而这也是导致逆向工具只支持
UFL 网络恢复的原因。后续将对其他类型连线资源的测试方法和逆向方法进行研
究，以获得更加完善的逆向工具。
